# Design and Implementation of an Edge AI\-Based Smart IoT System for Real\-Time Environmental Monitoring and Intelligent Decision Making

**Autores:** Ms\.V\. Revathy; Mrs\. Megha U\. Vakani; Dr\. S\. Sivakumar; Mrs\. Palak Modi; Ms\. Pooja Vora; Ms\. Ami Patel

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

Environmental monitoring supports public health, industrial safety, agriculture, and sustainable development\.Conventional IoT monitoring systems often transmit sensor readings to remote servers for analysis, creating dependence on network availability and potentially delaying alerts\.This paper proposes an Edge Artificial Intelligence \(Edge AI\)\-based smart Internet of Things system for real\-time environmental monitoring and intelligent decision\-making\.The architecture integrates environmental sensors, an embedded edge controller, a lightweight machine learning model, wireless communication, and a remote dashboard\.Temperature, relative humidity, particulate matter, and suitable gas\-related measurements are acquired, validated, and processed locally\.An anomalydetection module identifies unusual patterns and supports local alert generation, while cloud connectivity enables historical storage and remote visualization\.The design also considers sensor faults, temporary network outages, data buffering, and secure communication\.A practical evaluation plan is defined for detection performance, processing latency, communication overhead, energy use, and operational reliability\.The proposed framework offers an implementable basis for smart\-campus, building, industrial, and urban monitoring\.Quantitative performance claims require validation through a working prototype and documented experiments\.
