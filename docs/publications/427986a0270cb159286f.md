# An Initial Study of Physiological Markers for Deepfake Speech Detection

**Autores:** Vojtěch Staněk; Michal Frič; Kamil Malinka; Anton Firc

**Data:** 2026-10-13 · **Tipo:** preprint

## Resumo

Conventional deepfake speech detectors primarily target synthesis artifacts and often degrade under unseen attacks or recording conditions\. Human speech, however, contains physiological markers associated with respiration, phonation, and temporal coordination arising from the speech\-production system that synthesizers may not reproduce faithfully\. This motivates the hypothesis that deepfake speech can be detected by identifying inconsistencies in these patterns, which we test using 36 handcrafted physiological markers organized into respiratory, vocal, and temporal categories\. We evaluate the marker vectors with logistic regression and SVM classifiers on pooled English recordings\. The best in\-domain system achieves a 21\.40% equal error rate \(EER\), while logistic regression achieves 32\.77% on the out\-of\-domain dataset pair\. Since the markers describe specific speech\-production properties, the logistic\-regression coefficients indicate whether higher marker values push the classifier toward bona fide or deepfake speech\. These results provide initial evidence that physiological markers offer a useful, interpretable signal for deepfake speech detection\.
