# Perancangan Sistem Informasi Manajemen Posyandu Berbasis Web dengan Metode Agile \(Studi Kasus : Desa Kabasiran\)

**Autores:** Sabilah Endah Warni; Gusmayeni Gusmayeni

**Data:** 2026-10-11 · **Tipo:** article

## Resumo

Posyandu merupakan salah satu layanan kesehatan masyarakat yang berperan penting dalam pemantauan kesehatan ibu hamil dan balita\. Pada Posyandu Desa Kabasiran, proses pencatatan data masih dilakukan secara manual menggunakan buku atau arsip kertas, sehingga menyebabkan pencarian data membutuhkan waktu lama, data berisiko hilang atau rusak, serta proses rekap laporan menjadi kurang efisien\. Selain itu, perhitungan status gizi dan stunting anak masih dilakukan secara sederhana, sehingga berpotensi menimbulkan kesalahan dalam analisis data kesehatan\. Penelitian ini bertujuan untuk merancang dan mengimplementasikan Sistem Informasi Manajemen Posyandu berbasis web dengan menggunakan metode Agile\. Metode pengumpulan data dilakukan melalui observasi, wawancara, dan studi pustaka\. Sistem ini dirancang untuk mengelola data bidan, balita, ibu hamil, imunisasi, vitamin dan laporan\. Pengembangan sistem menggunakan PHP, MariaDB/MySQL, Apache XAMPP, serta Bootstrap sebagai pendukung tampilan antarmuka\. Hasil penelitian menunjukkan bahwa sistem informasi manajemen Posyandu berbasis web dapat membantu menggantikan pencatatan manual menjadi pencatatan digital yang terintegrasi, menyediakan akses data secara terpusat sesuai hak akses pengguna, serta membantu kader dalam pengolahan data penimbangan dan penentuan status gizi maupun stunting secara lebih akurat dan terstruktur\. Dengan adanya sistem ini, pengelolaan data Posyandu diharapkan menjadi lebih efektif, efisien, dan mudah digunakan
