# NerAxom\-MGF: Leveraging Multi\-Granularity Fusion for Assamese Named Entity Recognition

**Autores:** Punam Sarmah; Manash Pratim Lahkar; Shobhanjana Kalita; Utpal Sharma

**Data:** 2026-10-17 · **Tipo:** article

## Resumo

We introduce MGF\-NER, a multi\-granularity fusion architecture that integrates character\-level, subword\-level, and entity\-span\-level representations for the same task using NerAxom dataset\. NerAxom comprises 102,857 tokens across 4,178 sentences annotated under the BIO scheme with seven entity categories: Person, Location, Organization, Date, Number, Occupation, and Work\-of\-Art\. MGF\-NER combines a Character\-level Convolutional Neural Network that captures morpheme\-level cues attenuated by subword fragmentation, a pre\-trained MuRIL transformer for cross\-lingually pretrained contextual semantics, an Entity Span Attention module for multi\-word boundary detection, and a Conditional Random Field decoder that enforces valid BIO transitions\. Under a seeded five\-run evaluation protocol on the NerAxom test set, MGF\-NER achieves a mean micro\-averaged F1 of 85\.45 ± 0\.46, outperforming the strongest single\-encoder baseline MuRIL \(83\.88±0\.79\) by 1\.57 F1 points; the improvement is statistically significant under a paired sentence\-level Wilcoxon signed\-rank test \(p = 0\.005\)\. We benchmark MGF\-NER against nine baselines spanning traditional feature\-based sequence labelling \(CRF\), a recurrent baseline \(BiLSTM\-CRF\), language\-agnostic multilingual transformers \(mBERT, XLM\-RoBERTa base and large, DistilBERT\-multi\), a script\-similar Bangla\-specialised transformer \(Bangla\-BERT\), and Indic\-specialised transformers \(IndicBERTv2\)\. Single\-component and compound\-component ablations, together with per\-category ablation, decompose the gain across the four architectural components, and error analysis characterises the residual error profile\.
