# DESIGN A SECURE CLOUD STORAGE FOR DATA PRIVACY USING ARTIFICIAL INTELLIGENCE

**Autores:** VIKAS GAUND; VINAY KUMAR; Richa Pandey

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Storing information with an outside cloud vendor gives users flexible, pay\-as\-needed capacity, yet it also puts privacy, confidentiality, integrity and access control at risk\.This paper describes the design of a cloud storage platform that pairs cryptographic protection with machine intelligence to keep user files safe\.The planned architecture is built from six tiers: the user interface, authentication and authorization, activity monitoring, AI\-based detection, encryption with storage, and a security response tier\.Every file is encrypted before it is saved and is decrypted only once the requester passes authorization\.A machine learning module studies how users behave, labels each session as normal or suspicious, and raises alerts or demands extra verification when something looks wrong\.The work follows an experimental design\-and\-development approach in which the AI model is trained and tested on its own prior to integration\.The intended result is a functioning prototype that shows encrypted storage together with AI\-driven threat detection\.
