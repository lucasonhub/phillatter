# Observation Window Design Outweighs Architectural Complexity in Deep Learning for Sepsis Mortality Prediction

**Autores:** Irawan Irawan; Siti Nurmaini; Rossi Passarella; Jasmir Jasmir

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

Deep learning models for predicting sepsis mortality often obscure which design choices genuinely improve performance\.We developed a sequential model using 19,902 Sepsis\-3 patients from the Medical Information Mart for Intensive Care IV \(MIMIC\-IV\), processing hourly physiological sequences via convolutional and bidirectional recurrent layers alongside static patient features\.Under matched conditions, sliding\-window augmentation improved discrimination by 0\.033 in area under the receiver operating characteristic curve \(AUROC\), of which repeated training examples accounted for the larger share\.The static feature pathway contributed 0\.061, whereas the convolutional block had no measurable effect\.On a held\-out test set the model reached an AUROC of 0\.902; gradient boosting, a bidirectional long short\-term memory network, and a Transformer encoder reached 0\.865, 0\.855, and 0\.851 under an identical protocol and tuning budget\.When all features were restricted to the information available at each prediction time, discrimination fell to 0\.807 at six hours and 0\.839 at twelve, so shorter horizons carry a substantial cost\.These results suggest that in this task, input representation and observation length mattered more than architectural complexity\.
