# Bitcoin Price Prediction Using Machine Learning Technique

**Autores:** Sujith V\.; Sree Yogeswari S\.; Subha Sri R

**Data:** 2026-10-17 · **Tipo:** article

## Resumo

Bitcoin price forecasting is challenging because of nonlinear market behaviour and rapid price fluctuations\. This study presents an integrated machine\-learning framework for one\-step\-ahead Bitcoin price prediction using Random Forest \(RF\), Support Vector Machine \(SVM\), and XGBoost\. The framework incorporates preprocessing, comparative model evaluation, prediction fusion, and directional trend classification within a unified predictive workflow\. Model performance is assessed using MAE, MSE, RMSE, and R², while an equal\-weight fusion mechanism combines the individual prediction outputs\. A separate RF classifier generates UP, DOWN, and NEUTRAL market\-direction states\. Experimental results demonstrate that XGBoost provides the strongest predictive performance, achieving a reported accuracy of 96\.5% and an R² of 0\.94, with lower prediction errors than the other evaluated models\. The complete framework is deployed through a Flask\-based web application supporting interactive prediction, graphical visualization, trend analysis, and prediction\-history management\.
