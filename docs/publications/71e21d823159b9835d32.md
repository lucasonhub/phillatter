# Reference Authenticity and Citation Validity in AI\-Generated Medical Writing

**Autores:** Ahmet Aykut

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

This letter highlights the distinction between reference authenticity and citation validity in AI\-generated medical writing\. Although verifying whether a generated reference exists is essential, a real reference may still fail to support the specific claim to which it is attached\. Future evaluations should therefore move beyond bibliographic verification and include claim\-level assessment of contextual relevance and evidentiary support\.
