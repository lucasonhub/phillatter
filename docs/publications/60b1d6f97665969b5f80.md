# Enhancing Web Monitoring Systems with Improved Service Availability Checks, Web Defacement Detection and Rule\-Based Threat Classification and Alerting: A Case Study National Cybersecurity Authority Rwanda

**Autores:** Paul Mutabazi; Bosco Musabe

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

This study developed and evaluated an integrated cyber threat monitoring system to improve web defacement detection and service availability monitoring in Rwanda\. The system combined automated monitoring, rule\-based threat classification, and Natural Language Processing techniques to detect suspicious website activities in English, French, and Kinyarwanda\. A mixed\-methods approach was used to evaluate system performance and user feedback\. The platform monitored 45 critical websites at the National Cybersecurity Authority over five months\. The results showed significant improvements in detection speed, false positive reduction, and threat classification accuracy, while maintaining high system reliability\. The findings demonstrate that integrated monitoring systems can strengthen cybersecurity operations in resource\-constrained environments\.
