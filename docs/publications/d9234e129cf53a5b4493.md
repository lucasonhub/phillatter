# TOGAF\-Guided Microservice Architecture for Scalable and Interoperable Madrasah Learning Portals

**Autores:** Andi Nailah Mashfufah Sulfa; Muhammad Faisal; Titin Wahyuni; Jufri Jufri; Titik Khawa Abd Rahman; Nurnawaty

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Purpose – This study aims to design and evaluate an integrated madrasah learning portal by combining The Open Group Architecture Framework \(TOGAF\) with microservice architecture to improve the scalability, modularity, and interoperability of academic information services\. Methods – The study employed selected TOGAF Architecture Development Method phases to align business, data, application, and technology requirements\. The proposed architecture decomposed academic functions into User, Learning, and Assessment Services connected through REST APIs\. Academic datasets representing students, teachers, subjects, classes, attendance, assignments, and assessments were used for proof\-of\-concept implementation\. The architecture was evaluated through workload\-based backend processing, cross\-service identifier consistency, simulated workload iterations, and exploratory comparisons with monolithic architectural scenarios\. Findings – The proposed architecture successfully integrated core academic services through modular service decomposition and standardized communication mechanisms\. The workload evaluation demonstrated stable processing behavior under lower workloads, while larger workloads required increased execution time\. Cross\-service data relationships maintained consistent identifier references across the evaluated academic datasets\. The exploratory architectural comparison also indicated that the Microservice \+ TOGAF configuration provided more efficient backend processing behavior than the evaluated monolithic configurations within the controlled environment\. Research Implications – The proposed model provides a reference architecture for educational institutions seeking structured, modular, and interoperable academic information systems\. Originality – This study integrates TOGAF\-guided enterprise architecture with microservice\-based academic service decomposition and evaluates the resulting architecture through scalability and interoperability analyses in a madrasah learning context\.
