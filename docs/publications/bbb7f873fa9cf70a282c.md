# AutismLearn\-LLM: Explainable AI and Evidence\-Grounded Educational Recommendation Framework for Autism

**Autores:** Waleed Mahmoud Ead

**Data:** 2026-10-11 · **Tipo:** book

## Resumo

This repository provides the research code, Jupyter notebooks, experimental workflows, and supporting datasets for AutismLearn\-LLM, an explainable and evidence\-grounded artificial intelligence framework integrating autism phenotypic prediction, explainable machine learning, retrieval\-augmented generation \(RAG\), and personalized educational recommendation design\. The framework was evaluated using the ABIDE I phenotypic dataset, comprising 770 participants from 18 research sites\. It implements Support Vector Machine \(SVM\), Logistic Regression, Random Forest, and XGBoost classifiers, together with SHAP\-based explainability, bootstrap statistical analysis, and leave\-one\-site\-out validation\. The selected SVM achieved 71\.55% accuracy, an F1\-score of 0\.7027, and a ROC\-AUC of 0\.7588\. An exploratory adaptive\-functioning experiment using Vineland ABC scores achieved an MAE of 6\.905 and R² of 0\.393 with Ridge Regression\. The repository also provides the proposed AutismLearn\-LLM educational recommendation architecture, comprising five configurations \(C1–C5\) that progressively incorporate student profiles, teacher\-derived instructional rationales, and retrieved educational guidance\. A supplementary proof\-of\-concept dataset contains 100 illustrative recommendation sets and 300 instructional strategies developed from 20 fictional student profiles\. The repository includes reproducible Python scripts, Jupyter notebooks, model evaluation procedures\.
