# A Hybrid Handcrafted\-Transformer Framework for Multiclass AMD Classification with Efficient Downstream Recalibration

**Autores:** Leonardo Petra Refialy; Sri Hartati; Sigit Priyanta; S Supanji

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

This study proposes a hybrid handcrafted\-transformer framework for three\-class age\-related macular degeneration classification from color fundus photographs\.The model combines 32 macula\-centered color and texture descriptors with frozen ViT\-B/16 embeddings, followed by principal component analysis and RBF\-kernel support vector classification\.Evaluation used 594 unique duplicate\-controlled images from four repositories with five\-seed nested cross\-validation and leave\-one\-dataset\-out testing\.The framework achieved 93\.27% ± 0\.43% accuracy, 91\.67% ± 0\.54% macro\-F1, and 91\.23% ± 0\.54% balanced accuracy, improving the handcrafted baseline by 4\.51, 4\.97, and 4\.99 percentage points, respectively, based on the underlying unrounded five\-seed means\.Leave\-one\-dataset\-out performance decreased to 81\.38% ± 0\.49% accuracy and 80\.59% ± 0\.53% macro\-F1, indicating a meaningful crossrepository generalization gap\.Full ViT fine\-tuning remained predictively stronger \(94\.71% ± 0\.73% accuracy; 93\.45% ± 0\.83% macro\-F1\)\.In the synchronized computational benchmark, Hybrid cold\-start construction required 55\.01 s per fold\-seed versus 446\.70 s for full fine\-tuning; after a one\-time 53\.53\-s feature cache, downstream Hybrid recalibration required only 0\.52 s with a 0\.763\-MiB per\-run model bundle in the matched computational benchmark\.These results support a compact performance\-efficiency trade\-off for repeated downstream recalibration using reusable frozen representations\.
