# AI\-Powered Sound\-Based Wildlife Monitoring System for Real\-Time Detection and IoT Alerting

**Autores:** Shantha Kumar S Kamaleshware P; Ms\. P Rohini Dr\. S Mohana

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

This paper presents an AI\-powered wildlife monitoring system designed for early detection of wildlife activity using acoustic sensing, convolutional neural network \(CNN\)\-based intelligence, GPS localization, and Internet of Things \(IoT\) communication\. A high\-sensitivity LM393\-based sound sensor connected to a NodeMCU ESP8266 monitors ambient events and provides the trigger for intelligent analysis\. The project architecture also documents a camera\-to\-PC CNN inference path, allowing visual verification and emergency assessment in addition to the sound\-based detection concept\. When a positive wildlife event is obtained, the system acquires geographic coordinates using a GPS module, displays status locally through a 16x2 LCD and I2C interface, transmits event information to an IoT platform such as Blynk or ThingSpeak, and sends an SMS alert to the forest department\. Reported experiments achieved more than 92% classification accuracy in a controlled environment and approximately 85% in semi\-outdoor conditions\. GPS localization was reported within 5\-10 m, while alerts were received within 5\-10 s of detection\. The system operated for several hours of continuous testing and across multiple days of field simulation, although weak Wi\-Fi caused occasional cloud transmission failures\. The results indicate that a low\-cost, non\-invasive, and automated sensing architecture can support proactive wildlife monitoring while highlighting the need for larger real\-world datasets, robust noise handling, and alternative communication paths for deployment in connectivity\-constrained regions\.
