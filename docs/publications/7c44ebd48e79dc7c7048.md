# Explainable Random Forest Framework for Multi\-Class Lifestyle Disease Risk Prediction Using BRFSS Data

**Autores:** Prema P\.; Nivetha P\.; Nagasakthi N\.

**Data:** 2026-10-17 · **Tipo:** article

## Resumo

With the increase in lifestyle diseases globally, there is a need for an effective machine learning approach to predict people who are at risk\. In this research, a machine learning framework for multiclass prediction of risk of lifestyle disease using the BRFSS 2024 dataset is developed\. There are six risk groups: Healthy, Diabetes Risk, Hypertension Risk, Obesity Risk, Heart Disease Risk, and Kidney Disease Risk\. Data preprocessing in the proposed framework is done by treating missing values, converting categorical variables into numeric variables, eliminating duplicate and inconsistent entries, normalizing using the Z\-score method, and correlation\-based feature selection\. Synthetic Minority Over\-sampling Technique \(SMOTE\) is implemented to solve the problem of class imbalance\. There are five classifiers tested using the 80/20 ratio for training and testing\. They include Logistic Regression, SVM, KNN, Decision Tree, and Random Forest\. The analysis reveals that the Random Forest performs well with an accuracy rate of 94\.8%, and thus, is selected as the final model for predicting the diseases\. Age, smoking, and sleep time have also been identified as important features using feature importance analysis that play an important role in predicting the risk of developing lifestyle diseases\.
