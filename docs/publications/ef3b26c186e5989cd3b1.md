# ИҚЛИМ ЎЗГАРИШИ ШАРОИТИДА СУВ ТЕЖОВЧИ ТЕХНОЛОГИЯЛАРНИ МОЛИЯВИЙ РАҒБАТЛАНТИРИШНИНГ РАҚАМЛИ МОНИТОРИНГ МЕХАНИЗМЛАРИ

**Autores:** Отабек Толибович Жумаев

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

Мақолада иқлим ўзгариши ва сув тақчиллиги шароитида сув тежовчи технологияларни жорий этган фермерларга бериладиган субсидия ва имтиёзли кредитларнинг мақсадли ишлатилишини масофавий назорат қилиш масаласи ўрганилади\. Ўзбекистонда 2026 йилда қабул қилинган сув тежаш чоралари ва уларнинг мониторинг элементлари расмий манбалар асосида таҳлил қилинган\. Сунъий йўлдош ва геоахборот технологияларидан фойдаланишнинг халқаро ва минтақавий тажрибаси кўриб чиқилган\. Тадқиқотда масофавий назоратнинг иқтисодий самарасини баҳолаш учун соддалаштирилган модел таклиф этилади\. Хулосада тўловни босқичларга бўлиш ва рақамли тасдиқлаш механизмларини бирлаштириш тавсия қилинади\.
