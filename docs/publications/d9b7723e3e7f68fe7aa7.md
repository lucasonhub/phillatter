# FAST AND ROBUST ELECTROMAGNETIC MODELING AND OPTIMIZATION FROM DC TO LIGHT: BRIDGING FIRST\-PRINCIPLES PHYSICS AND MACHINE LEARNING

**Autores:** Runwei Zhou

**Data:** 2026-10-13 · **Tipo:** dissertation

## Resumo

The rapid advancement of semiconductor technology demands electromagnetic \(EM\) solvers that are both accurate and computationally efficient, while artificial intelligence \(AI\) offers new opportunities for accelerating physics\-based modeling and optimization\. This work develops robust numerical solvers, physics\-informed machine learning methods, and deterministic global optimization techniques to enable scalable, data\-free, first\-principles EM solutions from DC to light\.An exact correction framework is first proposed to correct singular operators in discrete Maxwell systems, producing well\-posed formulations across all frequencies and feature scales\. The approach is extended from finite\-difference grids to finite element methods \(FEM\) on structured and unstructured meshes\. Rank deficiency is explicitly characterized through element connectivity and a spanning tree of the dual graph, while preserving algebraic equivalence to the original system\. A data\-free physics\-informed neural network framework is then developed for three\-dimensional frequency\-domain Maxwell equations with arbitrary boundary conditions, achieving guaranteed convergence and accuracy\. A physics\-informed nueral network method for parametric EM analysis is further introduced through a dielectric\-conductor separation formulation, enabling numerical Green&\#x27;s functions and design\-dependent metallic layouts to be treated independently\. The resulting framework provides instant, first\-principles field prediction for design\-space exploration with trustworthy accuracy\. Finally, an error\-controlled rank\-revealing \(ECRR\) method is proposed for deterministic high\-dimensional nonlinear global optimization, outperforming conventional stochastic approaches in both convergence speed and accuracy\.Together, these contributions establish robust, fast, and scalable EM simulation and optimization frameworks, advancing intelligent, physics\-driven EDA and next\-generation design automation\.
