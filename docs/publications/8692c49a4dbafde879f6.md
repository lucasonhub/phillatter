# Pengaruh Kualitas Sumber Daya Manusia, Dukungan Organisasi, dan Ketepatan Teknologi pada Implementasi Sistem Informasi Manajemen terhadap Kepuasan Pengguna di Klinik DHM Center

**Autores:** Hetik Fatonah; A Rohendi; Mira Veranita

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

This study examines the effects of human resource quality, organizational support, and technology suitability on user satisfaction with the Clinic Management Information System at DHM Center Clinic, using the Human, Organization, and Technology Fit \(HOT\-Fit\) framework\. This quantitative study used a descriptive\-associative design and included all 35 active system users through total sampling\. Data were collected using a five\-point Likert\-scale questionnaire and analyzed using multiple linear regression\. The findings indicate that human resource quality, organizational support, and technology suitability each positively and significantly affect user satisfaction, both individually and jointly\. Human resource quality is the strongest predictor, followed by technology suitability and organizational support\. These findings support the relevance of the HOT\-Fit framework for evaluating information system implementation in primary healthcare facilities, a context that has received less empirical attention than hospitals\. Practically, improving user satisfaction requires simultaneous efforts to strengthen user competencies, organizational governance, and system performance\.
