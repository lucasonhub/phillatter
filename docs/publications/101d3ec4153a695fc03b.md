# Optimalisasi Code Mixing dan Code Switching dalam Pembelajaran pada Program Studi Non\-Bahasa Inggris

**Autores:** Rimma Sianipar

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Penelitian ini mengeksplorasi bagaimana code mixing dan code switching memengaruhi proses belajar mahasiswa dalam lingkungan kelas multibahasa\. Berdasarkan hasil survei terhadap 100 mahasiswa, sebanyak 72% responden atau 72 mahasiswa melaporkan bahwa penggunaan bahasa Inggris dan bahasa Indonesia secara bersamaan membantu mereka memahami materi perkuliahan dengan lebih mudah, terutama ketika menghadapi gagasan yang kompleks atau istilah yang belum familiar\. Selain itu, sebanyak 80% responden atau 80 mahasiswa menyatakan merasa lebih nyaman ketika dosen sesekali menggunakan bahasa ibu sebagai sarana penjelasan, sedangkan aspek kepercayaan diri diukur melalui indikator yang berbeda\. Pada aspek partisipasi, sebanyak 68% responden atau 68 mahasiswa melaporkan bahwa mereka merasa lebih leluasa untuk berkontribusi dalam diskusi kelas dan mengajukan pertanyaan\. Temuan ini menunjukkan bahwa mahasiswa mempersepsikan penggunaan strategi kebahasaan yang fleksibel sebagai salah satu bentuk dukungan dalam memahami materi dan berpartisipasi dalam pembelajaran\.
