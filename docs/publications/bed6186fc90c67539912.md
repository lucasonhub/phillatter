# Code and locked outputs for &quot;Context\-Aware Machine Learning for Thermal Sensation Prediction in Intelligent Buildings&quot;\.

**Autores:** S\. Hadi Ghoddusifar

**Data:** 2026-10-16 · **Tipo:** book

## Resumo

Code, locked outputs and supplementary results for: &quot;Context\-Aware Machine Learning for Thermal Sensation Prediction in Intelligent Buildings: A Study\-Grouped Benchmark Against Fanger PMV and Adaptive Models Across Ventilation Strategies&quot; \(submitted to Intelligent Buildings International\)\. Summary\. The study benchmarks a context\-aware LightGBM model against recomputed ISO 7730 PMV and a fitted adaptive model, using 10,691 observations from the ASHRAE Global Thermal Comfort Database II \(v2\.01\) under pre\-specified, study\-grouped cross\-validation\. Contents code\_release/: analysis notebook \(Thermal comfort v3\.ipynb\), requirements\.txt, manifest\.json, PROVENANCE\.json, README\.md, SHA256SUMS\.txt and amendment log\. This package was frozen before amendments A9 to A12\. locked/: the time\-stamped analysis plan \(IBI\-R1\-v1, hash aefd4868d9a22430\), locked out\-of\-fold predictions, locked main results and the current amendment log \(amendments\_current\.json, including A9 to A12\)\. results/: result files \(JSON\) and supplementary tables \(table\_S\*\.csv\) reported in the paper\. additional\_analyses/: final figures \(R14\), post hoc study\-level bias \(R16\), age\-handling sensitivity \(R19\), and exploratory analyses \(R20 to R22\)\. Not included\. The ASHRAE Global Thermal Comfort Database II is not redistributed\. It is available from the original source \(Földváry Ličina et al\., 2018, https://doi\.org/10\.1016/j\.buildenv\.2018\.06\.022\) and Kaggle \(https://www\.kaggle\.com/datasets/claytonmiller/ashrae\-global\-thermal\-comfort\-database\-ii\)\. Place the file as described in the README to rerun the notebook\. Software\. Python; LightGBM 4\.6\.0; pythermalcomfort 3\.3\.0 \(full list in requirements\.txt\)\. Integrity\. SHA\-256 checksums are provided in SHA256SUMS\.txt and SHA256SUMS\_upload\.txt\. Note\. The analysis plan was time\-stamped but not registered externally\. Paths in some JSON files are local to the author&\#x27;s machine\.
