# Finite‐Time Synchronization of Delayed Coupled Memristive Neural Networks via Intermittent Pinning Control

**Autores:** Wanli Zhang; Long Pan; Hongfei Li

**Data:** 2026-10-11 · **Tipo:** article

## Resumo

ABSTRACT This work investigates finite‐time synchronization \(FTS\) of coupled memristive neural networks \(CMNNs\) with time delays by intermittent pinning control \(IPC\)\. It resolves the problem that delayed memristive neural networks \(MNNs\) cannot achieve FTS via intermittent control\. By using interval matrix analysis and matrix norm estimates, the impact of state‐dependent parameters is overcome in CMNNs\. An IPC is designed, which includes a pinning control \(PC\) scheme and an intermittent control \(IC\) scheme as its special cases\. By using some novel Lyapunov functionals, the FTS results were established using the designed IPC\. In addition, FTS results were also separately achieved using the designed PC scheme as well as the designed IC scheme\. Finally, numerical simulations demonstrate the validity of the proposed results\.
