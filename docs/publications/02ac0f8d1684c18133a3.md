# Robust Federated Learning with Integrated Access Control for Distributed Edge Cloud Big Data Systems

**Autores:** Vinod K\. Barupati; Shivshankar M Nagrik

**Data:** 2026-10-18 · **Tipo:** article

## Resumo

Federated learning is a distributed machine learning paradigm in which participating devices or edge nodes train a shared model without transferring their raw data to a central repository\. This property makes federated learning attractive for edge cloud big data environments where data are geographically distributed, continuously generated, heterogeneous, and subject to privacy requirements\. However, decentralization also introduces security and governance challenges\. An attacker may impersonate a participant, submit poisoned model updates, exploit weak permissions, infer private information from model updates, or compromise an edge node\. Robust federated learning therefore requires more than an aggregation algorithm; it requires coordinated access control, privacy protection, participant validation, secure communication, and resilience against malicious behavior\. This review examines the integration of federated learning with access control for distributed edge cloud big data systems\. It discusses the foundations of federated learning, edge intelligence, role based and attribute based access control, threat models, robust aggregation, secure aggregation, privacy preservation, communication efficiency, scalability, and application requirements\. The review also compares major security mechanisms and identifies research directions for adaptive authorization, decentralized trust, privacy preserving identity management, resource aware robustness, and explainable security decisions\. An integrated architecture is proposed in which identity, role, attributes, device state, data sensitivity, and training behaviour are jointly considered before model updates are accepted\. Such an approach can provide a practical security layer for collaborative learning while retaining the principal benefit of federated learning: keeping sensitive data close to their source\.
