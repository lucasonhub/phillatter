# A Lightweight Hybrid Machine Learning Framework for Parameterized Human Behavior Classification

**Autores:** Jyoti Gupta; Brijesh Kumar \-; Ashish Pandey

**Data:** 2026-10-18 · **Tipo:** article

## Resumo

Human\-behavior modeling is commonly approached through video, sensor, handwriting, or textual signals, yet many practical settings require a lightweight model that can operate on structured behavioral responses\. This study develops a hybrid supervised\-learning framework that combines logistic regression with transparent rule\-based decision logic for binary classification of parameterized behavioral\-response patterns\. The experimental dataset described in the source study contains 500 questionnaire\-derived instances represented by ten behavioral attributes, including responsibility, gratitude, patience and listening, positive attitude, respectfulness, confidence, humility, kindness and compassion, honesty, and justice and integrity\. A stratified 90:10 train\-test protocol was used, supplemented by five\-fold cross\-validation\. The source confusion matrix for the 50\-instance hold\-out set contains 24 true negatives, 24 true positives, one false positive, and one false negative, corresponding to 96% hold\-out accuracy, precision, recall, F1\-score, and specificity\. Five\-fold cross\-validation is reported at 97\.00 ± 0\.63%, while ROC\-AUC is reported as 0\.985\. The proposed approach is computationally simple and interpretable, but its outputs must be treated as probabilistic decision\-support signals rather than deterministic judgments about individuals\. The study therefore emphasizes human oversight, privacy safeguards, external validation, and bias auditing before any real\-world deployment\.
