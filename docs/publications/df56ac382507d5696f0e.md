# An XGBoost Approach for Phishing URL Detection and Cross\-Dataset Generalization Analysis

**Autores:** Rutuja Dhanwate, Prof\. P\. V\. Gaikwad, Dr\. H\. B\. Jadhav

**Data:** 2026-10-11 · **Tipo:** article

## Resumo

Phishing URLs can direct users to fraudulent websites designed to capture credentials, financial details, and other sensitive information\. Machine\-learning models can detect suspicious links by analysing URL characteristics\. However, strong performance on one dataset does not necessarily transfer to a different URL population\. This paper presents an analysis of an XGBoost\-based approach for phishing URL detection, focusing on cross\-dataset performance, feature stability, model efficiency, and browser\-oriented deployment\. The reported study evaluates a custom dataset containing 75,738 URLs, the Gram Beddings dataset, and a feature\-compatible subset of PhiUSIIL containing 47,103 URLs\. The reported accuracy is 90\.72% on the custom test set, 70\.65% on Gram Beddings, and 72\.16% on PhiUSIIL, with an average accuracy of 77\.84% across the three evaluation datasets\. These results illustrate how differences between datasets can affect model performance and why independent evaluation is necessary\. The analysis also highlights variations in feature importance and the trade\-off between classification performance and computational efficiency\. The findings support the importance of cross\-dataset validation when developing practical phishing detection systems\.
