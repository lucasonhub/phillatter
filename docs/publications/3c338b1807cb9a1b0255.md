# A Multi\-validation Benchmark of Selected SNP Representation\-model Configurations for Maize Genomic Prediction

**Autores:** Rizki Darmawan; Heru Agus Santoso; Abdul Syukur; Affandy

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

Maize genomic prediction can accelerate breeding by estimating phenotypic performance from genomewide markers, but conclusions can depend on the paired choice of learning model, SNP input, phenotype construction, and validation design\.This study benchmarks selected model\-representation configurations rather than estimating independent representation effects\.The initial Genomes to Fields \(G2F\) genotype resource contained 5,733 hybrids and 2,156 SNPs, while the primary pollen days\-after\-planting \(DAP\) benchmark used 4,767 phenotype\-matched hybrids\.Eight representation families generated nine evaluated feature matrices because PCA100 and PCA300 were treated as distinct inputs, and all 1,945 planned runs were completed\.Across ten common 80/20 holdouts, RF\-PCA100 achieved the lowest mean RMSE of 2\.3982 \(R2 = 0\.6411; Pearson = 0\.8019\), but corrected resampled tests with Holm adjustment found no significant RMSE difference from RF\-additive, RF\-MAF\-weighted, or RF\-recessive\.A fixedeffect phenotype sensitivity analysis changed the ranking: GBLUP\-additive led on adjusted BLUEs \(RMSE = 1\.0282;R2 = 0\.8516\), demonstrating sensitivity to target construction\.Mean R2 was negative for every evaluated parentdisjoint configuration\.HGB genomic\-plus\-environmental prediction achieved positive R2 in only 6/10 held\-out years, 17/41 locations, 64/217 location\-years, and 2/5 climatic regimes\.On the same 2024 yield test records, a historicallocation mean baseline \(R2 = 0\.0761; unseen hybrids = 0\.0700\) outperformed the best learned configuration \(\-0\.0244 and \-0\.0451\)\.These results support configuration\-level claims and emphasize phenotype sensitivity and distributionshift validation before operational use\.
