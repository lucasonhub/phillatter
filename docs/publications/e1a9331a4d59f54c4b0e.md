# Groundwater quality parameter weighting using hybrid machine learning and SHAP\-game theory based on Sentinel\-2 data \(Case Study: Khorramabad, Iran\)

**Autores:** Mozhgan Yarahmadi; Ali Haghizadeh; Leila Ghasemi

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Monitoring groundwater quality is essential for sustainable water management in semi\-arid regions, particularly in Iran, where water scarcity is severe\. Traditional field sampling is costly, time\-consuming, and limited in spatial and temporal coverage\. This study presents an integrated framework for predicting and weighting groundwater quality parameters by combining field data \(ten parameters: EC, TDS, TH, pH, Na%, Cl, SO₄, Na, Ca, Mg\), Sentinel\-2 multispectral imagery \(eight bands, five indices\), and ERA5\-Land climatic variables \(precipitation, temperature\)\. We analysed 56 samples from five stations in Khorramabad \(2015–2024\) using nine machine learning models: five base models \(Random Forest, XGBoost, SVR, MLP, Linear Regression\) and four hybrid models \(RF\+XGBoost, SVR\+MLP, Voting, Stacking\)\. Hybrid models consistently outperformed base models\. The Voting Ensemble achieved the highest accuracy for sodium \(R² = 0\.986\) and EC \(R² = 0\.974\), while SVR\+MLP reached R² = 0\.900 for TDS\. We used SHAP combined with game theory \(Shapley values\) for parameter weighting\. Results showed EC \(50\.47%\) and TDS \(32\.40%\) as the most influential parameters, followed by TH \(7\.87%\) and Na% \(7\.56%\)\. Seasonal analysis revealed that TH weight increased markedly in summer \(21\.15%\)\. Bootstrap uncertainty analysis \(1,000 iterations\) confirmed weight stability, and cross\-validation supported model reliability \(R²: 0\.35–0\.74\)\. Optically active parameters \(Na, EC, TDS, Cl\) were accurately predicted using Sentinel\-2, while non\-optical parameters still required field measurements\. This cost\-effective framework enables prioritisation of groundwater quality parameters in monitoring programmers\. Dominance of EC \(50\.47%\) and TDS \(32\.40%\) in the weighting results provides a basis for prioritising these optically active parameters in monitoring programmers\. Seasonal increase in TH weight \(from 17\.12% in spring to 21\.15%\) supports an adaptive approach to seasonal monitoring\. The framework enables spatial prediction of optically active parameters in ungauged areas, making it a cost\-effective approach for groundwater management in Iran, where groundwater supplies more than 55% of total water consumption\.
