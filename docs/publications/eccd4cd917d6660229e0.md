# Do you &quot;see&quot; what I &quot;see&quot;? A Multi\-panel Visual Question Answer Dataset for Large Language Model Chart Analysis

**Autores:** Daniel J\. Evans; J\. P\. Naiman; JooYoung Seo; J\. Stephen Downie

**Data:** 2026-10-09 · **Tipo:** preprint

## Resumo

Digital libraries increasingly host scientific publications whose figures encode primary research findings, yet making this visual content searchable, accessible, and reusable remains an open challenge\. Large language and multimodal models \(LLMs/LMMs\) provide the possibility to automate many figure parsing tasks such as determining data trends or extracting data from plots\. In this work, we consider if these models can reliably support task\-oriented visual data analysis when presented with synthetic, but realistic, scientific figures that contain multiple charts\. Our Visual Question Answering \(VQA\) process scaffolds our tasks along a four\-level description model from basic conceptual answers to interpretive and analytical understanding\. Additionally, we outline our process for synthetically generating our single and multi\-panel \(charts in which there are multiple panels present\) plots and testing the data with various LMMs using quantitative analysis\. In general, we find LMMs become less accurate with increasing figure complexity as the number of panels, number of plot elements, and difficulty of questions increase\. Finally, because LMM accuracy is expected to change rapidly, our analysis also considers cost relative to performance as a metric to inform future user decisions\. We provide the detailed question\-answer pairs used in this analysis, along with the code used to generate random plots, question\-answer pairs and detailed bounding\-box metadata for chart elements\. The code and data are available at https://github\.com/ReadingTimeMachine/LLM\_VQA\_MultiPanel and https://huggingface\.co/datasets/ReadingTimeMachine/visual\\\_qa\\\_multipanel
