# Modern Object Classification Techniques in Automotive Applications

**Autores:** Dominciuc

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

Automotive radar sensors have become a key component of Advanced Driver Assistance Systems \(ADAS\) due to their robustness under adverse weather conditions\. This project presents an object classification approach based on radar point clouds and the analysis of the RadarScenes dataset\. The proposed methodology involves extracting features from radar point cloud data, followed by classification using supervised machine learning\. A Light Gradient Boosting Machine \(LightGBM\) model was trained and evaluated on real\-world radar measurements to distinguish between multiple road user categories, including vehicles, pedestrians, and two\-wheeled vehicles\. The results demonstrate the potential of automotive radar as a reliable perception sensor for intelligent transportation systems and autonomous vehicles\.
