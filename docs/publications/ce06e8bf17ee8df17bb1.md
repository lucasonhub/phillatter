# Vision\-Based Indoor Navigation System for Assistive Applications Using Deep Learning

**Autores:** Shrikant Kharode; Paras Ghime; Rucha Anil Jichkar; Swati Paraskar; Laxman Thakre; Prof\. Swati Patil; Leena Sharma

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

Significant amounts of work have been devoted to the development of indoor navigation systems due to GPS deficiencies in indoor navigation\. In this paper, the analysis and application of the smart indoor navigation system have been described\. The suggested system is capable of working with video feeds and uses machine learning algorithms\. The proposed methodology is based on computer vision algorithms, sensor fusion, and machine learning algorithms, such as convolutional neural networks \(CNN\)\. It solves issues concerning weak signals, obstacles, and the dynamic nature of the environment\. It is a reliable methodology that applies CNNs\. The system has been developed by using the Python programming language, OpenCV, and TensorFlow/Keras libraries\. The application of the proposed methodology was carried out in various indoor environments, such as corridors, laboratories, and hospitals at universities\. The test results showed improved accuracy of 0\.60 against 0\.24 during ten training sessions\.
