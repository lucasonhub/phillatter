# SEFRQO\-Plus: a self\-evolving query optimizer via large language models and retrieval\-augmented generation

**Autores:** Hanwen Liu; Q\. Zhang; Ryan Marcus; Ibrahim Sabek

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

Abstract Query optimization is a crucial problem in database systems that has been studied for decades\. Learned query optimizers \(LQOs\) can improve performance over time by incorporating feedback; however, they suffer from cold\-start issues and often require retraining when workloads shift or schemas change\. We initially proposed SEFRQO, a Self\-Evolving Fine\-tuned RAG\-based Query Optimizer, which leverages fine\-tuned LLMs to address these challenges and uses in\-context learning to achieve continuous evolution\. However, its system design relies on the assumption of repetitive query workloads, requires executing queries statically upon their first encounter \(incurring extra overhead\), and utilizes only partial feedback from the best historical records \(insufficient feedback design\)\. In this paper, we present SEFRQO\-Plus, which resolves the above limitations\. First, we design a feedback\-oriented vector database with query structure\-aware embeddings to support effective similarity search, and we incorporate multi\-layered histories as references to enrich the feedback\. Then, we enhance the prompt optimization workflow by utilizing multi\-dimensional historical feedback to drive continuous self\-evolution\. Moreover, we provide formal theoretical proofs to validate the advantages of our customized query group relative policy optimization\. Evaluations show that SEFRQO\-Plus outperforms state\-of\-the\-art LQOs, achieving reductions of 66\.52% and 69\.79% in query latency for the complete CEB and Stack workloads, respectively, compared to PostgreSQL\. SEFRQO\-Plus achieves an additional 15% improvement over the initial SEFRQO\. Moreover, it generalizes effectively across multiple workloads and scenarios, and even across different DBMSes\.
