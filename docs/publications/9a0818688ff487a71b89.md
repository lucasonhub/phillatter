# Yamashita, Hiroki: 多経路生成構造からの対象生成

**Autores:** 

**Data de descoberta:** 2026-10-16 · **Tipo:** unknown

## Descrição do feed

本稿は、対象を理論の出発点とする従来の哲学的枠組みを再検討し、生成構造から対象生成を導く一般理論を提示する。従来の多くの理論では、対象・同一性・差異・評価という順序が前提とされてきた。本稿はこの順序を反転し、多経路生成構造を世界の最小構造として導入する。多経路生成構造とは、生成経路集合 Σ と結果集合 R の間の写像 Π : Σ → R において、異なる生成経路が同一結果へ収束しうる構造である。 この構造のもとでは、応答操作 E : Σ → V が結果集合上の写像へ因数分解されることは一般には保証されない。したがって同一結果に対応する生成経路の間に応答差が生じうる。本稿は、このような応答差が同一結果に集中する場合、応答差は結果集合上の差として表現できず、生成経路集合の内部差異として現れることを示す（差異集中定理）。 差異集中が成立する場合、結果集合上の応答写像を一意に定義することはできない。このとき結果を単一結果として保持するためには、差異の帰属を決定する関係が不可避となる。本稿では、この差異帰属決定関係を評価と定義する。さらに評価が入力記述の精密化に対して安定する場合、同一の評価値を共有する入力記述の集合が同値類を形成し、この同値類が対象として成立する。 以上により本稿は、多経路生成構造のもとで応答差が同一結果に集中する場合、評価を介して対象が生成されることを示す。本稿はこの生成系列を「対象生成連鎖」と呼び、対象を前提された存在ではなく評価安定から成立する構造単位として位置づける。 \(direct link \)
