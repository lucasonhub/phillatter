# Group Actions and Harmonic Analysis in Number Theory

**Autores:** Valentin Blomer; Manfred Einsiedler; Emmanuel Kowalski; Maryna Viazovska

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

Rooted in number theory, this workshop combines recent methodological advances in a variety of adjacent fields including automorphic representation theory, ergodic theory, Fourier analysis and algebraic geometry\. It focuses on a selected set of problems that could recently be solved quite surprisingly in a number of cases, but are awaiting a more general framework\. This includes in particular equidistribution problems in homogeneous dynamics, automorphic forms in higher rank and exponential sums and arithmetic over function fields\.
