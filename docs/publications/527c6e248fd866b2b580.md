# A Weighted Hybrid Scoring Framework for Static Detection of Hash\-novel Polymorphic Worm Variants

**Autores:** Sulieman Mohamed Ali Sulieman; Yahia A\. Fadlalla

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

Polymorphic malware continuously changes its binary representation while preserving malicious functionality, reducing the effectiveness of signature\-based detection against previously unseen variants\.This paper proposes a Weighted Hybrid Scoring Framework \(WHSF\) for static detection of hash\-novel polymorphic worm variants\.WHSF integrates four complementary modalities: exact cryptographic matching \(M1\), CTPH\-based fuzzy similarity hashing \(M2\), Random Forest structural analysis of PE features \(M3\), and CNN\-LSTM semantic analysis of API\-call sequences \(M4\)\.A Normalized Dynamic Redistribution mechanism reallocates weights among available modalities, preventing inactive or unavailable evidence from imposing a fixed scoring ceiling\.The framework was evaluated on 11,146 samples comprising 5,268 polymorphic malware variants and 5,878 benign executables\.WHSF achieved a 99\.98% detection rate with a 0\.00% false\-positive rate, demonstrating that complementary static modalities with adaptive score fusion can effectively detect hash\-novel polymorphic malware\.
