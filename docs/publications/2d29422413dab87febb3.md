# An Integrated Deep Learning Approach for Chest X\-Ray Abnormality Recognition and Automated Radiological Report Synthesis

**Autores:** Haragopal V\.P\.; Shaik Munna; Penujuvi Sandeep; Thummaluru Soumith Reddy

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

Chest X\-ray \(CXR\) interpretation and radiology report creation depend on efficient feature extraction and report creation in medical terms\. This research work proposes a multimodal AI framework for the automatic analysis of CXRs, which includes deep learning techniques to represent visual data, vision\-language models, generate reports, and interpretability via Grad\-CAM\. For chest abnormality classification, this study uses visual deep neural network architectures as Swin Transformer, ConvNeXt, EfficientNet, and ResNet\. This research utilizes ViT\+BART, ViT\+GPT\-2, Swin\+BART, and Swin\+GPT\-2 for the input image to generate report\. The performance of visual classifiers is measured in Accuracy, Precision, Recall, and Macro F1\-score\. The generated reports are evaluated by BLEU, ROUGE\-1, ROUGE\-2, ROUGE\-L, and BERT\-F1\. Swin Transformer achieved an accuracy of 0\.77, while ViT\+BART achieved BLEU, ROUGE\-1, ROUGE\-2, ROUGE\-L, and BERT\-F1 scores of 0\.13, 0\.42, 0\.17, 0\.33, and 0\.89 respectively
