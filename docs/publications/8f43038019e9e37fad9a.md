# Integrasi Framework Laravel dan Android pada Sistem IoT untuk Monitoring Parameter Fisika\-Kimia di Greenhouse

**Autores:** Ramadanzah Ramadanzah; Dodi Yudo Setyawan; Nurfiana Nurfiana; Refi Arioen

**Data:** 2026-10-17 · **Tipo:** article

## Resumo

Pengembangan teknologi pertanian presisi \(precision agriculture\) pada ekosistem greenhouse menggunakan sistem hidroponik menghadapi tantangan teknis dalam menjaga stabilitas parameter lingkungan mikro secara simultan\. Penelitian ini bertujuan untuk mengintegrasikan framework Laravel dan platform Android ke dalam sistem Internet of Things \(IoT\) untuk memantau parameter fisika\-kimia lingkungan, meliputi suhu udara, kelembaban, intensitas cahaya, dan kadar karbon dioksida \(CO2\), pada budidaya pakcoy \(Brassica rapa L\.\) di greenhouse hidroponik\. Fokus utama penelitian ini terletak pada perancangan arsitektur backend RESTful API menggunakan Laravel untuk mengelola penyimpanan basis data riwayat jangka panjang serta menyinkronkan transmisi data dari multi\-sensor \(DHT22, LDR, dan sensor gas CO2\) yang memiliki karakteristik sampling rate berbeda\. Di sisi pengguna, aplikasi Android dan antarmuka web dikembangkan sebagai frontend yang mengonsumsi data melalui serialisasi format JSON menggunakan metode polling HTTP GET real\-time, serta menyediakan tiga mode kendali aktuator, yaitu manual, otomatis berbasis ambang batas sensor, dan penjadwalan\. Pengujian fungsionalitas dan kinerja sistem dilakukan melalui visualisasi antarmuka pada dasbor situs web neliti\-sk\.darmajaya\.ac\.id serta evaluasi transmisi data nirkabel\. Infrastruktur backend berbasis Laravel terbukti stabil dalam menangani fluktuasi frekuensi data sensor yang kompleks\. Berdasarkan evaluasi log data selama 24 jam pengujian kontinu pada rentang 14 Agustus 2026 \(00\.00–23\.00 WIB\), sistem berhasil merekam seluruh 24 titik data per jam \(100%\) tanpa satupun jam yang terlewat\. Integrasi ini menghadirkan solusi pemantauan sekaligus pengendalian pertanian presisi yang andal, terintegrasi, dan memiliki skalabilitas tinggi bagi operator greenhouse, meskipun masih memerlukan mekanisme offline logging untuk mengantisipasi gangguan konektivitas atau pemadaman listrik di masa mendatang\.
