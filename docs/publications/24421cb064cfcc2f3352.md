# Conformal Prediction for Distribution\-Free Uncertainty in Machine Learning Models

**Autores:** Mini T\. V

**Data:** 2026-10-17 · **Tipo:** article

## Resumo

A point prediction says nothing about how far it might be wrong\. Conformal prediction repairs that with very little machinery: hold out some labelled data, score how badly the model misses on it, and widen each new prediction by a quantile of those scores\. The resulting set contains the true label with a chosen probability, for any model and any data distribution, provided the data are exchangeable\. This review reads the literature with one question in mind, namely what exactly is promised and under which assumption\. We go through the split recipe and the adaptive scores built for regression and classification, then the limits of the guarantee, which is marginal and not per individual\. Most of the article concerns what happens when exchangeability fails: covariate and label shift, drifting streams, time series\. We close with risk control, counterfactual inference and generative language models, and with a short list of checks a practitioner should run before trusting a reported coverage figure\. No new experiment is reported; every number quoted is a theoretical bound taken from the cited source\.
