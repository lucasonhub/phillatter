# Fake Review Detection Using Hybrid Transformer and Behavioral Analysis

**Autores:** Janagan A\.; Madhan P\.; Leo Aandrew G\.; Mohammed Azardeen M\.

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

Fake review detection is challenging when the deceptive information is semantically plausible while reviewer level and rating information are unusual\. This paper presents Review Verity, a multi\-modal fake review detection system that uses context, behavior and language representations in a single classification model\. The language representation is created using static BERT\-base\-uncased model to generate 768\-dimensional vector and account age, verified\-purchase and multiple IP usage create three behavioral representation features\. Review depth, subjectivity, Flesch readability, rating extremeness, sentiment agreement and rating disagreement create six linguistic representation features that combine with the vectors to produce 777\-dimensional feature representation set\. The feature set is normalized and rebalanced using SMOTE and then training is performed using 100 trees Random Forest classifier\. SHAP and LIME models interpret the features and instances and the final model is deployed using FastAPI and React frameworks\.
