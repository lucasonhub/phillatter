# Application of Single Tuition Fee Classification Based on Clustering Using PCA and K\-Means

**Autores:** Arthur Farly Kaseger

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

Abstract — The determination of the Single Tuition Fee \(Uang Kuliah Tunggal/UKT\) is an important policy to ensure fairness in higher education financing based on students’ socio economic conditions\. However, conventional UKT determination is often subjective and less effective in processing multidimensional data\. This study applies an unsupervised learning approach using Principal Component Analysis \(PCA\) and the K\-Means algorithm to classify students into UKT categories\. Socio\-economic data such as parents’ income, number of dependents, electricity capacity, housing conditions, and supporting attributes were used in the analysis\. PCA was employed to reduce data dimensionality, while K\-Means was used to cluster students based on similar characteristics\. The evaluation results show that two clusters provide the optimal grouping with a silhouette score of 0\.7631, which were mapped into low and high UKT categories\. The resulting model was then integrated into a web\-based application to enable automatic UKT classification\. The developed system demonstrates the potential to improve objectivity, consistency, and efficiency in the UKT determination process\. Key words — Single Tuition Fee; PCA; K\-Means; Clustering; Classification Application Abstrak — Penentuan Uang Kuliah Tunggal \(UKT\) merupakan kebijakan penting untuk menjamin keadilan pembiayaan pendidikan tinggi berdasarkan kondisi social ekonomi mahasiswa\. Namun, proses penentuan UKT secara konvensional masih berpotensi menimbulkan subjektivitas dan kurang optimal dalam mengolah data multidimensi\. Penelitian ini menerapkan pendekatan unsupervised learning menggunakan Principal Component Analysis \(PCA\) dan algoritma K\-Means untuk mengklasifikasikan mahasiswa ke dalam kategori UKT\. Data social ekonomi yang digunakan meliputi penghasilan orang tua, jumlah tanggungan, daya listrik, kondisi tempat tinggal, serta atribut pendukung lainnya\. PCA digunakan untuk mereduksi dimensi data, sedangkan K\-Means digunakan untuk melakukan pengelompokan mahasiswa berdasarkan kemiripan karakteristik\. Hasil evaluasi menunjukkan bahwa dua cluster merupakan konfigurasi optimal dengan nilai silhouette score sebesar 0,7631, yang kemudian dipetakan ke dalam kategori UKT rendah dan UKT tinggi\. Model yang dihasilkan selanjutnya diintegrasikan ke dalam aplikasi berbasis web untuk mendukung proses klasifikasi UKT secara otomatis\.
