# How visual perspective modulates memory retrieval in a lifelogging intervention: observations from a study with Korsakoff patients

**Autores:** Tijmen van Teijlingen; Albert Postma; Geert Jan Biessels; Erik Oudman

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

OBJECTIVE: \(KS\)\. This study aimed to explore whether the perspective used in a visual lifelogging intervention, where visual recordings of daily activities are reviewed to support later retrieval, influence episodic memory retrieval\. We compared the effects of first \- versus third\-person perspectives on episodic memory performance in KS patients\. METHODS: Three patients with KS participated in a controlled within\-subject study with three experimental conditions: \(1\) review of first\-person lifelogging images, \(2\) review of third\-person images, \(3\) a control condition without review\. Both objective memory performance and subjective memory ratings were assessed after each condition\. Bayesian analyses were performed to evaluate evidence\. RESULTS: Both perspectives yielded improvements in objective memory recall compared to the control condition\. Evidence suggested that a first\-person perspective may provide additional benefit for objective recall\. No consistent advantage was observed for subjective memory ratings and experienced vividness\. CONCLUSIONS: These findings suggest that visual perspective during retrieval cueing influences episodic memory in patients with Korsakoff\. The results provide proof of concept for future investigations into how perspective influences episodic memory and hold promise for real\-life application of the intervention in amnesic populations\.
