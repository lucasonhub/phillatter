# Deep Learning of Topological Equivalence Classes

**Autores:** Linden Disney\-Hogg; Max Zuev

**Data:** 2026-10-15 · **Tipo:** preprint

## Resumo

We demonstrate an application of deep learning to the problem of identifying whether two generating vectors correspond to topologically equivalent finite group actions on Riemann surfaces, showing how architectures developed for semantic understanding have use for pure mathematical problems\. In doing so we discuss how desired algebraic structure influences model design, and explore which structural properties of topological equivalence classes the model has successfully learnt\.
