# Self\-Building Labs

**Autores:** Jiaru Bai; Yuchi Zhao; Han Hao; Miroslav Bogdanovic; Yang Cao; Varinia Bernales; Alán Aspuru\-Guzik

**Data:** 2026-10-16 · **Tipo:** preprint

## Resumo

Self\-driving laboratories \(SDLs\) accelerate scientific discovery by automating experimental execution and optimization\. AI agents can increasingly propose new experiments, but existing SDLs can only run the procedures they were built for\. Adapting them to a new experiment still takes extensive manual engineering, which makes laboratory flexibility the bottleneck for scaling discovery\. We introduce the self\-building laboratory \(SBL\), which designs, configures, and operates its own laboratory setup given a high\-level scientific goal\. SBL starts from whatever already exists, from an empty room to a working SDL, and builds the missing capabilities: the lab layout, its digital twin, robot skills, and experimental workflows\. We demonstrate the system working across different robots and setups, scaling from a single workstation to laboratories with several robots working together\. We validate SBL&\#x27;s end\-to\-end capabilities through a real\-world quantum\-dot synthesis experiment\. By shifting the role of human researchers from manually configuring and programming device automation to specifying scientific objectives, SBL makes scientific automation more accessible, flexible, and scalable\. Project website: https://self\-building\-labs\.github\.io/
