# La IA y el límite de la comprensión científica

**Autores:** Camila Adriana Portanda Polo; Carlos Acuña; Selenne Romero Servin

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Podemos describir cada operación de una red neuronal, calcular sus errores y modificar sus parámetros\. Sin embargo, cuando preguntamos qué aprendió para reconocer un rostro, una enfermedad o un objeto, la respuesta deja de ser evidente\. Este artículo explora esa diferencia\. A partir del análisis de imágenes, muestra cómo una red construye representaciones a lo largo de sus capas y por qué conocer el valor de sus parámetros no basta para interpretar una decisión\. También presenta métodos que permiten estudiar esas representaciones y examina el alcance de las explicaciones obtenidas mediante ellos\. Así, plantea que el límite de nuestra comprensión no es el mismo para todas las preguntas: una interpretación puede resultar útil para entender una operación del modelo y ser insuficiente para justificar una decisión en el contexto donde se aplica\.
