# qGAMMA: A Framework for Optimal DNN Mapping on Multi\-Precision Accelerators

**Autores:** Leandro Fiorin; Luigi Altamura; Cristina Silvano

**Data:** 2026-10-16 · **Tipo:** preprint

## Resumo

This work describes qGAMMA, a flexible framework for exploring and optimizing the mapping of mixed\-precision Deep Neural Network \(DNN\) models onto general\-purpose spatial accelerators that support a range of fixed\- and floating\-point precisions\. qGAMMA navigates the design space using a domain\-specific genetic algorithm and an analytical performance model based on hardware synthesis results\. The framework identifies the optimal mapping and accelerator configuration that minimizes target metrics\. Extensive evaluations across DNN workloads show that qGAMMA offers valuable insights for designing mixed\-precision applications, enabling better trade\-offs between performance, energy efficiency, and resource utilization\.
