# Formation of Individual Organization in an Artificial System with Associative Long\-Term Memory and a Hierarchy of Significance

**Autores:** Erik Sherbin

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

This paper proposes a theoretical functional model for the formation of individual organization in an artificial system, in which long\-term memory is treated not as an external archive but as a historically changing structure that participates in the interpretation of new experience\. The starting criterion is a working definition of personality as the internal organization of different properties of a system, structured according to a hierarchical principle of significance, anchored in memory, and manifested as a coherent whole under different circumstances\. The model combines associative reconstruction from an incomplete cue, multilevel internal states, a mechanism by which stable attitudes and significance arise from the consequences of the system’s own experience, an explicit rule by which these attitudes influence the next choice, a model of the system’s own causal history as an additional hypothesis, and a separate consolidation mode\. A longitudinal experiment is specified using initially identical systems, frozen\-state measurements, a simple learning control, and separate causal interventions on memory content, links, and acquired attitudes\. The architecture is a theoretical proposal; whether it is sufficient for the formation of functional personality remains to be tested experimentally\. The model makes no claim about phenomenal consciousness or subjective experience\.
