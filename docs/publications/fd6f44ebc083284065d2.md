# Optimization\-Assisted SSO\-BRO\-XGBoost Framework for Prediction of COVID\-19 Case Counts Using Global Health Data

**Autores:** N\. Prakash; S\. Padmalal; K Devipriya; N\. Krishnaveni; S\. Muthusundari; M\. Pompapathi

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

The COVID\-19 pandemic produced large volumes of country\-level epidemiological data that can support data\-driven estimation of case counts for public\-health decision making\. This study proposes an optimization\-assisted SSO\-BRO\-XGBoost framework for three case\-count targets that are present in the daily source file: confirmed, active and death cases\. The public dataset covers 15 February 2020 to 14 May 2022\. The framework has four stages: data pre\-processing; feature selection with Shuffle Shepherd Optimization \(SSO\); hyperparameter optimization of an Extreme Gradient Boosting \(XGBoost\) regressor with the Battle Royale Optimizer \(BRO\) using five\-fold cross\-validation; and prediction with the optimized XGBoost model\. The records were split randomly into a training/development subset \(80%\) and an independent test subset \(20%\)\. On the independent test subset, the documented normalized MAE values for confirmed, death and active cases are 0\.08, 0\.12 and 0\.108, with corresponding RMSE values of 0\.12, 0\.18 and 0\.151\. The active\-case values are harmonized with the 30\-run mean reported in the ablation study\. Because the split was random rather than chronological, these results describe retrospective estimation within the observed period; prospective forecasting and external validation remain necessary\.
