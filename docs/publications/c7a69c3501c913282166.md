# Interpretabilidad mecanística en redes neuronales usando Sparse Autoencoders \(SAE\): marco Experimental de Interpretabilidad de Espacio Latente\.

**Autores:** G\.S\.\(Gilson Saul\) Chango Curillo

**Data:** 2026-10-13 · **Tipo:** dissertation

## Resumo

Las redes neuronales suelen considerarse cajas negras porque, a pesar de ofrecer resultados excelentes, se desconoce con exactitud qué ocurre en su interior al procesar la información para tomar decisiones\. El presente trabajo tiene como objetivo desarrollar y evaluar diferentes arquitecturas de Sparse Autoencoders para analizar las activaciones internas de una red neuronal previamente entrenada en Tic\-Tac\-Toe 5x5, con el fin de relacionar las features con conceptos semánticos\. Para ello, se realizó la recolección del conjunto de datos en dos fases\. Primero se obtuvieron los tableros crudos y en la segunda fase se generaron los pares tablero activación\. Luego, se implementaron y evaluaron varias arquitecturas de Sparse Autoencoders, como el SAE estándar con P\-annealing, BatchTopK y Matryoshka, con conjuntos de datos de 500, 1000, 2000 y 10000 tableros\. Durante el entrenamiento, se probaron diferentes configuraciones de hiperparámetros para optimizar el rendimiento del modelo\. Una vez entrenados los modelos, el principal problema fue que una misma feature reaccionaba a diferentes conceptos semánticos, lo que dificultaba saber qué representa realmente\. Para solucionarlo, se implementaron y evaluaron las métricas Coverage y Board Reconstruction, y se desarrollaron mapas de interpretabilidad\. El parámetro considerado para relacionar la feature con el concepto semántico fue el F1\-score, y como criterio de desempate la precisión\. En la evaluación de Coverage, la arquitectura BatchTopK obtuvo el mejor desempeño con un valor de 0,4732, superando a SAE estándar con P\-annealing y Matryoshka\.
