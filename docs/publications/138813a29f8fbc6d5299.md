# Bitcoin Price Prediction Using Time Series Forecasting Algorithms and Deep Learning

**Autores:** Hosseinkhani

**Data:** 2026-10-11 · **Tipo:** dissertation

## Resumo

This thesis investigates Bitcoin price prediction using deep learning and statistical time\-series forecasting methods, building upon the dataset and research framework presented by Dimitriadou and Gregoriou \(2023\) in Predicting Bitcoin Prices Using Machine Learning, published in Entropy, 25\(5\), 777\. The study implements and comparatively evaluates five forecasting models: Long Short\-Term Memory \(LSTM\), Gated Recurrent Unit \(GRU\), Autoregressive Integrated Moving Average \(ARIMA\), Seasonal Autoregressive Integrated Moving Average \(SARIMA\), and Generalized Autoregressive Conditional Heteroskedasticity \(GARCH\)\. Using the dataset employed in the referenced study, this research seeks to investigate whether alternative modelling approaches and implementation choices can improve predictive performance\. The work focuses on the practical application and comparative evaluation of these models, examining their suitability for capturing temporal patterns and volatility in Bitcoin price movements\. By revisiting an existing research setup and exploring potential improvements, the thesis aims to contribute to the ongoing investigation of machine learning and statistical methods for cryptocurrency price forecasting\. The implementation was developed using Python and relevant machine learning and statistical modelling libraries\. This work provides a basis for further experimentation with financial time\-series prediction and highlights the importance of systematic model evaluation when comparing forecasting approaches\.
