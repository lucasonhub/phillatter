# Ponce, Hiram \(ed\.\): Towards a Unified Framework for Debugging Systems Requirements Specifications Translated Into ASP Logic Predicates

**Autores:** 

**Data de descoberta:** 2026-10-19 · **Tipo:** unknown

## Descrição do feed

Ensuring consistency in system requirements is a critical challenge in systems engineering, particularly as updates introduce ambiguities or conflicts\. This paper presents a theoretical framework for a systems requirements debugger that processes and maintains logical representations of requirements\. Based on Knowledge Representation and Reasoning \(KRR\), the framework detects inconsistencies within static knowledge bases and manages conflicts arising from new information\. We propose methods for rapid prototyping in logic programming and optimization of Minimum Generalized Answer Sets \(MGAS\) in Abductive Logic Programming\. An online debugger prototype is introduced as a research and educational tool, offering a practical test bed for logic programming\. Using Answer Set Programming \(ASP\) solvers, we outline a declarative implementation that advances knowledge management and lays the groundwork for more sophisticated \(semi\)automatic debugging tools\.
