# Task\-State Governance: A Virtual Machine for Verifiable and Recoverable GUI Agent Execution

**Autores:** Wenkui Yang; Yiming Hao; Kai Zhou; Chengyu Pu; Yuzhe Zhang; Jie Cao; Jin Huang; Shuai Ma; Feng Tian

**Data:** 2026-10-14 · **Tipo:** preprint

## Resumo

Graphical user interface \(GUI\) agents now execute workflows across real applications, but when execution drifts, users must determine what changed, what should have remained untouched, and what can still be recovered\. Plan\-centric interfaces leave users supervising procedure, but users live with changes to application state\. We introduce task\-state governance, an interaction paradigm that represents a task as an editable contract linking desired outcomes, facts that must be preserved, and observed application state\. We instantiate this paradigm in TaskVM, which projects live state into editable task controls, executes user edits as genuine interface actions, verifies outcomes through independent observation, and marks each action as reversible, compensatable, or irreversible\. Across an automated contract benchmark, a controlled user study, and an open live\-model exploration, the paradigm strengthened contract compliance and users&\#x27; recovery control and trust, while execution outcomes were held constant\. Task contracts open a design space for governable agent interfaces\.
