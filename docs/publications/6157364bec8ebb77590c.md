# ReSNNance: an HDL generation framework for spiking neural networks

**Autores:** Samuel López\-Asunción; Cristina Bermúdez\-Martín; Pablo Ituero; Marisa Lopez\-Vallejo

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Spiking neural networks \(SNNs\) are a promising computational paradigm for resource\- and energy\-constrained edge applications\. However, their implementation on field\-programmable gate arrays \(FPGAs\) remains a complex task that typically requires both neuromorphic\-computing knowledge and hardware\-description expertise\. This work presents ReSNNance, an open\-source framework for the automatic generation of synthesizable VHDL implementations from high\-level software descriptions of SNNs\. ReSNNance provides a Python\-based workflow in which users define the network architecture, neuron parameters, numerical precision and target configuration, while the framework generates the corresponding hardware modules, parameter files and interconnections\. Its modular architecture supports sequential networks composed of Dense, Conv2D and pooling layers based on fixed\-point leaky integrate\-and\-fire neurons\. The generated VHDL is intended to remain readable and configurable, allowing users to inspect, modify and integrate the resulting circuits into larger hardware designs\. ReSNNance also supports design\-space exploration through configurable numerical formats and network parameters, facilitating the evaluation of trade\-offs between classification accuracy, resource utilization and performance\. The complete workflow was demonstrated using a large fully connected network and a spiking LeNet\-5 architecture for MNIST classification\. Both networks were automatically translated into VHDL, verified against their software counterparts and implemented on an AMD Zynq UltraScale\+ FPGA\. The results show that ReSNNance provides a practical path from software\-defined SNN models to functional FPGA implementations by automating the generation of the corresponding VHDL modules and network interconnections\.
