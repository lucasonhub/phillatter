# Universal Distributed Feature Extraction Complementary to Side Information via H\-Score

**Autores:** Yuan Xinjie; Dier Tang;  Shaolun\-Huang

**Data:** 2026-10-12 · **Tipo:** preprint

## Resumo

This paper considers a distributed estimation system where edge nodes transmit averaged features to a center node for parameter estimation\. A key challenge arises when the center node possesses auxiliary side information: how to design local extractors that are universally optimal for any downstream task, while avoiding redundancy with the side information\. To tackle this problem, we orthogonally decompose the joint function space and demonstrate in the weak\-dependence regime that the modal decomposition of the canonical dependence kernel&\#x27;s conditional\-additive component yields optimal, task\-independent features\. We construct a distributed nested H\-score to learn this decomposition and show that, under a limited feature budget, the mean\-squared error \(MSE\) gap to the best task\-specific features is determined solely by the task&\#x27;s alignment with the discarded, least informative modes, and vanishes to leading order for every square\-integrable task once the budget is sufficient\.
