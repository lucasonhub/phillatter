# Determination of poloidal field coil currents from target plasma configuration based on deep neural network

**Autores:** Yunfei Wang; Kazuaki Hanada; Makoto Hasegawa; Haiqing Liu; Xiang Gao; Xiaoqian Cui

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Abstract Precise control of the poloidal magnetic configuration \(PMC\) is essential for optimizing plasma performance and ensuring the operational safety of tokamaks\. The PMC is predominantly controlled by the poloidal magnetic field induced by a set of poloidal field \(PF\) coils, so determining each PF coil current \(I\_PF set\) based on the target PMC before the experiment is crucial for achieving a desired discharge\. This paper proposes a data\-driven approach to determine the I\_PF set based on a deep neural network \(DNN\)\. Using the QUEST spherical tokamak as a case study, a dataset of PMC parameters and corresponding I\_PF set was generated through free\-boundary equilibrium calculations\. Crucially, the models are trained and validated entirely on simulated equilibria, and all predictions are benchmarked against the free\-boundary equilibrium solver\. Independent limiter and divertor DNN models were first trained to determine I\_PF set from target PMC features\. These models provide approximate predictions suitable for pre\-discharge feedforward design, with all coil current RMSE values below 0\.56 kA\. To enable unified current determination for both configuration types within a single network, an integrated model was further developed by training on the combined limiter and divertor datasets, with limiter samples embedded into the higher\-dimensional divertor feature space\. This integrated model achieved comparable prediction accuracy without requiring separate models for each configuration type\. Additionally, the role of PF35\-1 \(a pair of PF coils located near the divertor target\) in fine\-tuning strike point positions was examined\. The proposed method reduces computation time from several seconds to under 1 ms per prediction, and offers strong potential as a feedforward component within real\-time plasma control systems in future tokamak experiments\. The method is intended to provide approximate feedforward coil currents for pre\-discharge configuration design, with centimeter\-level accuracy in plasma shape, rather than high\-precision equilibrium solutions\.
