# Enhancing Photometric Redshift Estimation with Morphology\-Based Feature Selection via Copula Entropy

**Autores:** Karthik Raja Selvan; John Y\. H\. Soo

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

This is a poster which I presented at the 16th Asia Pacific Physics Conference 2025\. In this work, we present a novel copula entropy\-based framework to optimise machine learning\-driven photometric redshift \(photo\-z\) estimation by strategically incorporating galaxy morphological features\. For more information, please contact the corresponding author, Dr John Soo \(johnsooyh@usm\.my\) or me \(karthikraja@student\.usm\.my\)\.
