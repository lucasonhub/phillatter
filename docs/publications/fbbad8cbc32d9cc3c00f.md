# Berry, David: No Free Unity: An Information\-Theoretic Constraint on Theories of Consciousness

**Autores:** 

**Data de descoberta:** 2026-10-16 · **Tipo:** unknown

## Descrição do feed

This paper argues that if the unity of consciousness is a real structural feature of experience, then the underlying informational state must contain “whole‑only” information that cannot be reduced to the parts\. Using results from multivariate information theory, I show that such whole‑only information always implies an integration bottleneck, and I use this to derive a constraint—the “No Free Unity” principle—that existing scientific theories of consciousness must satisfy or explicitly reject\.
