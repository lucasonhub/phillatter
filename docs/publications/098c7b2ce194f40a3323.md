# Implementasi Sistem Monitoring Kualitas Udara Pada Dinas Komunikasi Informatika Dan Statistik Lampung

**Autores:** Ni Made Deni Arini; Retno Dwi Handayani

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Kualitas udara dalam ruangan merupakan faktor penting yang mempengaruhi kesehatan dan produktivitas kerja, namun monitoring masih banyak dilakukan secara manual dan belum realtime\. Penelitian ini bertujuan untuk mengimplementasikan sistem monitoring kualitas udara berbasis Internet of Things \(IoT\) yang terintegrasi dengan website\. Sistem menggunakan ESP8266 NodeMCU dengan sensor DHT11, MQ\-135, dan GP2Y1010AU0F untuk mengukur suhu, kelembaban,respon gas, dan partikulat debu\. Data dikirim ke Firebase Realtime Database dan ditampilkan pada dashboard web dashboard\. Hasil pengujian transmisi menunjukkan rata\-rata delay sebesar 1,9 detik \(\)\. Pengujian kalibrasi relatif pada 990 data sampel secara kuantitatif terbukti meningkatkan kestabilan pembacaan sensor dengan menekan rentang data ekstrem pada suhu \(dari 11,40 °C menjadi 2,70 °C\), kelembaban \(dari 59,00% menjadi 15,00%\), gas \(dari 11,62 menjadi 3,30\), dan debu \(dari 92,52 menjadi 35,20\)\. Visualisasi grafik dan penyimpanan data historis memfasilitasi analisis fluktuasi lingkungan kerja di Ruang Rapat DISKOMINFOTIK Provinsi Lampung\. Dengan demikian, sistem ini efektif mendukung pemantauan kualitas udara secara realtime dan responsif\.
