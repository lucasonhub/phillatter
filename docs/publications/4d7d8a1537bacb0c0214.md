# Detection of Eulecanium giganteum Infestation in Jujube Orchards Based on UAV Multispectral Remote Sensing

**Autores:** Yueteng Chao; Yulong Wang; Zhuoyang Xu; Ruohong He; Rina Yangdao; Hongqiang Dong; Ping Li

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

The application of remote sensing technology to monitor agricultural pests and diseases provides an effective approach for rapid and non\-destructive assessment of crop health\. This study evaluated a UAV multispectral remote sensing framework integrating vegetation indices and SPAD information for assessing Eulecanium giganteum infestation in jujube orchards\. Initially, 24 vegetation indices were extracted from canopy multispectral imagery, and Pearson correlation analysis was used for feature screening, resulting in a refined subset of 19 vegetation indices\. Seven machine learning algorithms were evaluated during model development, with Grid Search combined with tree\-level grouped 7\-fold cross\-validation for hyperparameter selection\. Vegetation indices were used as predictor variables, while SPAD value and infestation severity were treated as response variables in the regression and classification tasks, respectively\. During internal model development, the CatBoost\-19opt model achieved an R2 of 0\.81 and an RMSE of 1\.84 for SPAD estimation\. On the independent test set consisting of 58 jujube trees, the previously selected model achieved an R2 of 0\.84 and an RMSE of 1\.56\. During internal model development, incorporating measured SPAD values improved pest classification performance, with XGBoost\-19sopt achieving an OA of 0\.89 and a Kappa coefficient of 0\.84\. On the independent test set, the measured\-SPAD configuration achieved an OA of 0\.88, whereas both the VI\-only and VI combined with predicted\-SPAD configurations achieved an OA of 0\.71\. Thus, incorporating predicted SPAD did not improve overall classification accuracy relative to using vegetation indices alone\. Further model optimization and additional validation across different orchards, growing seasons, and phenological stages are required before the approach can be considered for operational large\-scale monitoring\.
