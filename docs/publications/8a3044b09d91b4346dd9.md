# SAT\-RL: Training Language Models for Logical Reasoning with Symbolic Solvers

**Autores:** Jialiang Sun; Kuldeep Meel

**Data:** 2026-10-09 · **Tipo:** preprint

## Resumo

Large language models \(LLMs\) have achieved strong performance in mathematical and logical reasoning, yet they still suffer from the curse of complexity and struggle as problem difficulty increases with the number of constraint interactions and the size of the search space\. In contrast, satisfiability solvers such as Z3 provide scalable and verifiable reasoning through constraint solving under formal theories, but lack the flexibility to interpret natural\-language problem descriptions\. In this work, we propose SAT\-RL, a reinforcement\-learning \(RL\) framework that trains LLMs to interact with symbolic solvers through multi\-turn tool execution\. SAT\-RL leverages synthetic data generation with verifiable solutions, supervised warm\-up on solver\-augmented traces, and solver\-grounded reinforcement learning with tool\-aware rewards\. Experiments show that SAT\-RL substantially improves symbolic reasoning with tools on both in\-domain and out\-of\-domain logic tasks\. Our code is available on https://github\.com/sunjia72/SAT\-RL\.
