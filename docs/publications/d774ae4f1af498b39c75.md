# Self\-Evolving Agent Harness

**Autores:** Chuyang Wei; Haoxiang Guan; Minghang Zhu; Kexin Zhou; Jiyan He; Xiren Zhou; Huanhuan Chen; Yifei Shen

**Data:** 2026-10-13 · **Tipo:** preprint

## Resumo

Harness self\-evolution revises an agent&\#x27;s software scaffolding, including prompts, memory, workflows, and executable components, while keeping model weights fixed\. We formalize a feedback\-driven process in which accepted revisions persist across runs\. The framework separates update targets from proposal and admission mechanisms\. It distinguishes changes to interpreted state from revisions to tools and code, repository\-level control logic, and plugin composition\. We characterize search through evolutionary optimization and examine its reliability through continual PAC\-learning\. Under explicit assumptions, the analysis yields an expected generalization bound, a retention bound conditional on historical regression budgets, and a high\-probability admission rule using fresh, independent validation data\. We examine how persistent harness revisions affect knowledge sharing and organizational workflows, with implications for scientific reliability, physical safety, and institutional accountability\. Cases from prior work illustrate model\-\-harness co\-design, distributed execution, and plugin reuse\. Reliable deployment requires continual validation as task distributions and evaluators change, with independent safeguards for learning, runtime privileges, and consequential actions\. We provide a comprehensive 66\-page discussion of related work, theory, algorithms, evaluation, applications, and the broader impact of Harness RSI, together with continuously updated code and supplementary materials, at https://github\.com/zgcagi/Harness\-RSI\.
