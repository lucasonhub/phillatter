# Evaluating transferability of machine learning models for DDoS detection

**Autores:** Danilo Lazić

**Data:** 2026-10-09 · **Tipo:** dissertation

## Resumo

Network intrusion detection, machine learning, cross\-domain evaluation, generalisation gap, benchmark datasets, real\-world traffic, majority\-class collapse, DDoS Izvleček: V zadnjih dveh desetletjih so bili sistemi za zaznavanje vdorov, ki temeljijo na machine learning in deep learning, predmet obsežnih raziskav, pri čemer številne študije poročajo o skoraj popolni klasifikacijski natančnosti na benchmark datasetih, kot so NSL\-KDD, KDD99 in družina CIC\-IDS\.Ta zaključna naloga preučuje, ali takšni rezultati odražajo dejanske zmožnosti zaznavanja napadov ali pa so posledica overfittinga\.Ovrednotenih je bilo trinajst open\-source ML\-NIDS implementacij, ki zajemajo Random Forest, SVM, Decision Trees ter CNN\-LSTM in GRU modele\.Vsak model je bil ponovno ovrednoten na svojem benchmark datasetu za vzpostavitev reproducibility baseline\.Za ocenjevanje je bil pripravljen evaluation dataset iz zajemov dejanskega omrežnega prometa z 1,28 milijona omrežnih tokov \(flows\), zbranih aprila 2026\.Podatki so bili obdelani v CIC in NSL\-KDD feature sete z uporabo lastnega postopka obdelave PCAP datotek\.Pripravljene so tri različice dataseta: heuristic baseline, Suricata\-based in botnet\-injected s 400\.000 sintetično generiranimi malicious tokovi, ki zagotavljajo preverjen ground truth\.Evalvacija na botnet\-injected različici je razkrila izrazito vrzel v posploševanju: enajst od trinajstih modelov je doseglo rezultate na ravni ali pod majority\-class baseline \(0,7629\), večina pa je pokazala popoln majority\-class collapse in skoraj ničelni malicious recall\.Rezultati kažejo, da dominantni ML\-NIDS benchmark dataseti ne predstavljajo več dejanskih pogojev operativnih omrežij, zato lahko temeljne pomanjkljivosti pri posploševanju modelov ostanejo neopažene\.Lazić D\. Evaluating transferability of machine learning models for DDoS detection\.
