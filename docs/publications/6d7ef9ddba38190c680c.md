# Embedding Graph Kernel Entropy \(EGKE\): Fine\-grained Hallucination Detection for LLMs from Embeddings

**Autores:** Dilrangi Sankalpana; Pragatheeswaran Vipulanandan; Uthayasanker Thayasivam; Kamal Premaratne

**Data:** 2026-10-09 · **Tipo:** preprint

## Resumo

Hallucination detection is critical for ensuring the reliability of Large Language Models \(LLMs\) in real\-world deployments\. While recent works, such as Semantic Entropy \(SE\) and Kernel Language Entropy \(KLE\), identify hallucinations by measuring semantic disagreement across multiple generated responses using Natural Language Inference \(NLI\) models, these methods depend on separately loaded NLI classifiers to estimate pairwise semantic similarity, introducing significant computational overhead\. We propose Embedding Graph Kernel Entropy \(EGKE\), a variant of Kernel Language Entropy \(KLE\) that replaces its NLI\-derived semantic graph with a Radial Basis Function \(RBF\) kernel applied to dense sentence embeddings generated by a BGE embedding model, while retaining KLE&\#x27;s graph Laplacian, heat kernel, and von Neumann entropy formulation unchanged\. By computing similarities directly in a continuous embedding space, the proposed method provides a symmetric and computationally efficient alternative to NLI\-based semantic comparison\. We evaluate our approach across 30 experimental setups \(covering multiple question\-answer datasets and open\-weight LLM families\) using both AUROC and AUARC, and demonstrate that this RBF\-based method achieves competitive hallucination detection performance against state\-of\-the\-art methods\.
