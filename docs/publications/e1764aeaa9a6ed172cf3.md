# Integration of Earned Value Management with Machine Learning for Predictive Performance Forecasting in Mivan Aluminium Formwork Construction Projects

**Autores:** 

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

High rise residential construction projects require a reliable performance monitoring and predictive tool to deliver projects on time and within budget using Mivan Aluminium formwork\.Conventional Earned Value Management \(EVM\) only offers a backward\-looking perspective and is unable to model the inherently non\-linear nature of repetitive formwork construction, such as variable slab cycle times, floor\-level complexity effects, and progressive labour productivity improvements\.This paper presents an integrated Machine Learning \(ML\) based EVM forecasting framework for Mivan construction projects in Maharashtra, India\.Multiple Mivan residential buildings historical weekly construction data were collected, pre\-processed, and fed into two complementary models: a Random Forest \(RF\) Regressor to predict weekly EVM metrics \(Earned Value, Actual Cost, SPI, and CPI\) and a K\-Nearest Neighbor \(KNN\) algorithm to predict floor\-wise slab cycle duration\.A recursive multi\-step forecasting algorithm projects future project performance\.The RF models achieved R² values of 93\.0% \(PV\), 69\.6% \(EV\), and 72\.7% \(AC\); the KNN duration model achieved R² = 61\.7% with MAE of 1\.8 days\.The model provides practical early warnings of delays and cost overruns to planning engineers for Mivan residential construction projects\.
