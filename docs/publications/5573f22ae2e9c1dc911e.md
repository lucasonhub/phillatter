# A Cryptographic Abstraction Layer for Integrating NIST Lightweight Cryptography into TLS 1\.3

**Autores:** HUSSEIN Ali Al\-shmailawi; Emad H\. Al\-Hemiary; Axel Sikora

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

In the Industrial Internet of Things \(IIoT\) domain, security solutions must remain energy\-efficient and reliable under strict latency and real\-time requirements, especially for resource\-constrained devices\.Lightweight Cryptography \(LWC\) has emerged as a feasible solution to these challenges, offering new cryptographic algorithms developed for IIoT environments\.The practical integration of LWC into standardized security protocols remains largely unexplored\.In this work, we propose a new Transport Layer Security \(TLS\) cipher\-suites integration that incorporates lightweight cryptographic algorithms, recommended by National Institute of Standards and Technology \(NIST\), through a Cryptographic Abstraction Layer \(CAL\)\.Measurements on IIoT devices show that the abstraction comes at modest effort: the dispatch cost of CAL peaks at 13\.73% for the smallest records and falls to between zero and 9\.52% once payloads pass 128 bytes, with most suites under 4%\.In return, the layer separates TLS record processing from the cryptographic implementation, conceals cipher internals from the layers above, provides runtime cipher agility, and a fixed memory footprint across the registered suites\.The layer drives different ciphers spanning block, sponge, duplex, and stream constructions through one calling convention, confirming that no single internal structure is assumed\.
