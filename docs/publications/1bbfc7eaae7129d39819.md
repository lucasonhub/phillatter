# How Many Ranks Does a Token Need? A Noise\-Floor Squelch for Rank\-One LoRA Experts

**Autores:** Mei Okonkwo; Owen Castellanos; Ingrid Solberg; Yusuf Demirel

**Data:** 2026-10-13 · **Tipo:** preprint

## Resumo

Low\-rank adaptation \(LoRA\) applies every rank\-one component of its update to every token, and mixture\-of\-experts variants replace this with a learned router that activates a fixed number of components\. We argue that the number of components a token needs is a detection question with a classical answer\. A token&\#x27;s responses to the rank\-one components of a trained LoRA consist of a few large values on a Gaussian noise floor whose width matches that of an untrained adapter, and the floor carries cross\-talk rather than adaptation\. We introduce SQUELCH, a router\-free mixture of rank\-one experts that \(i\) soft\-thresholds each token&\#x27;s responses at a multiple of its own robust noise level, so the active rank varies per token; \(ii\) chooses that multiple for each module by Stein&\#x27;s unbiased risk estimate, so no rank budget is specified; and \(iii\) replaces the resulting marginal keep\-or\-drop decisions by one explaining\-away step on the value Gram matrix, which suppresses redundant co\-active components and recruits complementary ones\. SQUELCH adds no trainable parameters to LoRA\. We prove that the squelch is within a logarithmic factor of the oracle input\-dependent allocation, that the selected threshold is risk\-consistent, and that explaining away is a descent step toward the joint sparse code whose error is controlled by the coherence of co\-active components\. On commonsense reasoning, knowledge, math, code, and GLUE with LLaMA\-3\.1\-8B, Qwen3, and DeBERTaV3, SQUELCH improves over LoRA by 2\.2\-\-3\.2 points and over the strongest mixture baseline by 0\.8\-\-1\.2 points while activating 8\.6 of 32 components per token on average\.
