# Implementing of A Computerized Automobile Fault Diagonsis System in Anambra State Polytechnic Mgbakwu

**Autores:** Chigbo Chukwuebuka Ikechukwu

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

This report on Design and Implementation of an Automobile fault diagnosis system is a web\-based application developed to solve the issue of Automobile fault\. The report is motivated by the need to guide car owners and learners of motor mechanics in the maintenance and troubleshooting of automobile problems without having to resort to presumptions and conjectures\. The system features a simple user\-friendly interface that could allow you to search for solutions to faults developed by one’s Automobile\. The methodology adopted is the Structured System Analysis Design Methodology \(SSADM\)\. The language used is PHP \(Hypertext Preprocessor\) for the server side development of the dynamic content, MySQL is used for the database design\. The software is divided into two parts, the admin area and the user area\. The developed software would ensure that automobile owners have proper assistance in time of crisis and will save them from the clutches of exploitative roadside mechanics\.
