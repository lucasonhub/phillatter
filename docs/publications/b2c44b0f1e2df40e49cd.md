# Neural network derived landslide risk assessment system

**Autores:** NUR HISYAM RAMLI; Siti Noor Linda Taib; Norazzlina M\. Sa’don; Dayangku Salma Awang Ismail; Raudhah Ahmadi; Imtiyaz Akbar Najar; Nazeri Abdul Rahman; Rosmina A\. Bustami; Tarmiji Masron

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Landslide is a frequent form of natural disaster in a tropical region such as Western Sarawak, Malaysia, and the occurrences are commonly associated with the wet season\. Contemporarily, Landslide Susceptibility Map \(LSM\) produced by machine learning models are used to assess the landslide risk\. However, LSMs are known to have spatiotemporal issues, where recent changes in the spatial data used as inputs in the models are not reflected in the LSMs, causing unjustified landslide susceptibility score in certain areas\. The same issue was also observed in Western Sarawak’s LSM\. Thus, this study was focused on transforming the Artificial Neural Network model used developed the region’s LSM into a set of equations that can be used as a landslide risk assessment system\. The new system was determined to be highly accurate with a score of 1 for both Area Under the Curve score, and recall\.
