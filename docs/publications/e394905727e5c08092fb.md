# Real\-Time Risk\-Aversion\-Adaptive Portfolio Selection by Learning a Hypernetworks

**Autores:** Khang Truong Tuan; Thang Tran Ngoc; Anh Dao Tuan

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

Serving a Markowitz efficient frontier at a varying risk\-aversion level requires one quadratic program per query\. We study a learned alternative: a hypernetwork that maps a normalized preference vector, read as a risk\-aversion level, to a long\-only portfolio in one forward pass\. A softmax output layer enforces the budget and no\-short\-selling constraints, and training minimizes a Chebyshev scalarization without any pre\-solved frontier\. The architecture, the scalarizations and the guarantees for the scalarized problem are those of controllable Pareto front learning \[1, 2\]\. Our contribution is an exact\-oracle evaluation: for the long\-only mean–variance problem the critical\-line algorithm yields the exact Chebyshev solution at every preference, so the error of thelearned map can be measured exactly, compared with the strongest alternatives and located\. On a ten\-industry synthetic instance and a fifteen\-asset VN30 instance the map attains a mean Euclidean weight error of 0\.0083 and 0\.0088 over ten seeds and answers a query in 44 microseconds on one CPU core\. From five to two hundred assets the error grows from 0\.0041 to 0\.0734; its largest values occur where the highest expected returns are nearly tied, it concentrates at changes of the active set \(median per\-seed ratio 2\.45 on VN30\), and supervised training on exact targets reduces it four\- to six\-fold\. The exact solver computes the entire frontier in 0\.22 to 3\.35 ms, so on this problem the learned map offers no computational advantage\.
