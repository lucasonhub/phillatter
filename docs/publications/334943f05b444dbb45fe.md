# ОХОРОНА НАБОРУ ДАНИХ ДЛЯ МАШИННОГО НАВЧАННЯ ЯК ОБ’ЄКТА ІНТЕЛЕКТУАЛЬНОЇ ВЛАСНОСТІ

**Autores:** Anton Tarasiuk

**Data:** 2026-10-09 · **Tipo:** article

## Resumo

Мета\. Метою статті є визначення умов, за яких набір даних для машинного навчання може підлягати правовій охороні як об’єкт авторського права, як об’єкт права особливого роду \(sui generis\) та/або як комерційна таємниця, а також встановлення відмінностей у правовому режимі відібраних наборів даних \(curated datasets\) і наборів даних, автоматизовано зібраних із відкритих джерел \(scraped datasets\)\. Методологія\. Дослідження ґрунтується на системному, формально\-юридичному та доктринальному методах\. Системний метод використано для аналізу співвідношення авторсько\-правової охорони, права особливого роду та режиму комерційної таємниці\. Формально\-юридичний метод застосовано для тлумачення положень Закону України «Про авторське право і суміжні права» та Цивільного кодексу України\. Доктринальний метод використано для узагальнення наукових підходів до правової природи баз даних, комерційної таємниці та компонентів систем штучного інтелекту\. Наукова новизна\. У статті запропоновано розглядати набори даних для машинного навчання не як однорідний об’єкт, а як сукупність різних за структурою та правовим значенням інформаційних активів\. Обґрунтовано, що правова кваліфікація дата\-сету має залежати від рівня добору, упорядкування, очищення, анотування, документування, інвестицій у створення та заходів щодо збереження конфіденційності\. Запропоновано розмежовувати curated datasets і scraped datasets як категорії, що мають різний потенціал охороноздатності\. Висновки\. Зроблено висновок, що складні відібрані набори даних для машинного навчання можуть охоронятися як оригінальні бази даних, неоригінальні бази даних, що підпадають під право особливого роду, та як комерційна таємниця\. Натомість автоматизовано зібрані набори даних без істотного творчого, організаційного чи інвестиційного внеску зазвичай матимуть нижчий рівень охороноздатності або не матимуть такого\. Визначальним для правової охорони має бути не сама технічна форма набору даних, а відповідність критеріям охорони за відповідним правовим режимом конкретного дата\-сету\.
