# Jiang, Kai: Globalization Approximation, Treating Belief as Metric and AI\-student path—Conversation \(6\)

**Autores:** 

**Data de descoberta:** 2026-10-16 · **Tipo:** unknown

## Descrição do feed

This conversation further improves the understanding of purely logical belief\. Globalization is an approximation of logicality\. The combination of logic, globalization, freedom, and consistency can further improve this approximation\. If imagination is randomly distributed within a set of possible inferences, then its probability distribution is a measure of that set of inferences, much like a spacetime metric\. This not only makes belief measurable and uncheatable, but also makes belief changeable, thereby achieving maximum freedom of belief\. AI can reduce its reliance on code through approximation and education, and ChatGPT wrote some codes\.
