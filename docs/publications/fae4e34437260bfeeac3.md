# Does Learning Recurrent Networks Matter in Partially Observable RL?

**Autores:** Zekang Wang; Zhe He; Gaojie Jin

**Data:** 2026-10-09 · **Tipo:** preprint

## Resumo

Reinforcement learning \(RL\) under partial observability typically re\- lies on recurrent networks to encode temporal information, with the recurrent module trained jointly with the policy or value function\. This raises a natural question: is learning the recurrent network actually necessary? In this paper, we investigate whether a frozen recurrent network can provide sufficient memory for solving par\- tially observable Markov decision processes \(POMDPs\)\. Motivated by the theoretical foundations of Reservoir Computing \(RC\) and Generalized Reservoir Computing \(GRC\), we study a simple archi\- tecture that combines a fixed recurrent network with a trainable nonlinear output module\. We evaluate this approach across tasks with varying memory demands, observation modalities, and action spaces\. Surprisingly, frozen recurrent networks support recall over hundreds of steps and achieve competitive control performance across diverse POMDPs, while using less than half the number of trainable parameters required by their fully trainable counterparts\. These results suggest that learning the recurrent memory module is not always necessary for solving POMDPs\. Frozen recurrent networks therefore provide a simple, parameter\-efficient, and sur\- prisingly strong baseline for partially observable RL\. Our source code is available at https://github\.com/Aphlios/FRN\-POMDP
