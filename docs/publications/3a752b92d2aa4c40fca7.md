# WUSPruner: Second\-Moment\-Optimal Transforms for Structured Pruning

**Autores:** Shengkun Tang; Dan Alistarh; Zhiqiang Shen

**Data:** 2026-10-11 · **Tipo:** preprint

## Resumo

Structured pruning is typically formulated as identifying which model dimensions to remove, often within the model&\#x27;s original representation\. However, the effect of coordinate deletion fundamentally depends on the basis in which pruning is performed\. This raises a more fundamental question: how should the basis be chosen specifically for coordinate deletion? We introduce WUSPruner, a transform\-based framework for structured pruning of large language models\. We formulate basis selection as a local linear reconstruction problem that directly minimizes the reconstruction loss induced by pruning\. Inspired by the second\-moment transformation in WUSH, we consider a WUS transform constructed jointly from activation and weight statistics\. We show that under positive\-definite second moments, WUS transform minimizes the local reconstruction loss over all invertible changes of basis\. In the resulting basis, the activation and weight second moments are simultaneously diagonalized and balanced, causing the deletion error to decompose into independent spectral contributions and yielding a principled criterion for coordinate selection\. Guided by this result, we develop a scalable pruning method based on blockwise WUS transformations and compact input projections\. Experiments on Llama and Qwen models from 8B to 72B parameters show consistent improvements over structured pruning baselines across language modeling, knowledge, commonsense reasoning, mathematics, and code generation benchmarks, while also delivering practical reductions in inference latency and memory usage\.
