# A transdisciplinary AI\-based framework for usability evaluation in digital health systems

**Autores:** Akshay Madhav Deshmukh; Ricardo Chalmeta

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

Introduction\. As healthcare systems undergo rapid digital transformation, the usability of clinical and patient\-facing technologies has become critical to adoption, user satisfaction, and patient safety\. Traditional usability evaluation methods are limited in capturing the real\-time cognitive, emotional, and behavioural complexities of interaction in high\-stakes environments\. Method\. This study presents a transdisciplinary evaluation of an AI\-augmented usability framework for healthcare interfaces\. The framework integrates methodologies from artificial intelligence, cognitive science, usability engineering, and clinical practice, incorporating eye\-tracking analytics, machine learning\-based confusion prediction, and natural language processing \(NLP\) sentiment analysis\. Forty participants, including healthcare professionals and patients, completed standardized tasks using either traditional or AI\-enhanced evaluation methods\. Analysis\. Comparative performance across both groups was assessed using usability metrics including System Usability Scale \(SUS\) scores, task completion time, error rate, and task success rate\. AI\-based analytics—eye\-tracking data, NLP sentiment scoring, and confusion prediction models—were used to generate additional insights\. Statistical analysis confirmed significant differences in usability outcomes between groups\. Results\. The AI\-enhanced evaluation significantly outperformed traditional methods in all core usability metrics\. The machine learning model achieved 89% accuracy and an F1\-score of 0\.88\. Sentiment analysis correlated strongly with self\-reported satisfaction, and eye\-tracking highlighted areas of cognitive friction\. Conclusion\. Transdisciplinary collaboration produced a novel, adaptive usability evaluation framework that offers real\-time, emotionally aware insights\. This replicable model enhances user\-centred design and supports safer, more effective digital health technologies\.
