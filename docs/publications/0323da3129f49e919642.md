# Примена алата заснованих на вештачкој интелигенцији у реинжењерингу информационих система

**Autores:** Анастасија Савић

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

This paper presents the process of re\-engineering a hospital information system using artificial intelligence \(AI\)\-based tools\. The research involves the application of an AI assistant \(Google Gemini\) and an AI agent \(OpenAI Codex\) in the phases of source code analysis, unified modeling language \(UML\) model generation, database reengineering, and application layer modernization\. The presented results demonstrate the potential of AI tools for documentation reconstruction, system modeling, and supporting various phases of the re\-engineering process, while emphasizing the necessity of expert verification of the generated results\.
