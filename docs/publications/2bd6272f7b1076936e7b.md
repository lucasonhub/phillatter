# Comparison of Wi\-Fi Roaming Performance between Software\-Defined Networking\-Based and Standalone Networks

**Autores:** Restu Angga Dwi Nurdiansyah; Muhammad Faishol Amrulloh

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

RSUD Bangil is transitioning toward the implementation of integrated Electronic Medical Records \(EMR\) connected to the Hospital Management Information System \(SIMRS\)\. The high mobility of medical personnel, particularly in the Emergency Department \(ED\), requires a stable Wi\-Fi connection when users move between access points \(roaming\)\. This study aims to analyze and compare Wi\-Fi roaming performance between a Software\-Defined Networking \(SDN\)\-based network and a standalone network at RSUD Bangil\. Testing was conducted at two locations in the ED, with ten repetitions using Windows 11 and Android devices\. The Quality of Service \(QoS\) parameters measured included throughput, delay, jitter, and packet loss using Iperf3 and Termux, complemented by an evaluation of user perceptions through questionnaires\. In the SDN\-based network, access points were centrally managed using Cloudnet, with max\-power and channel settings configured accordingly\. The results showed that the SDN\-based network demonstrated better roaming performance than the standalone network, characterized by more stable throughput, lower delay and jitter, and no packet loss during the roaming process\. The user evaluation results further confirmed improved connection stability following SDN implementation\. Therefore, the SDN\-based network architecture provides a more optimal solution for supporting the continuity of EMR services in hospital environments with high user mobility\.
