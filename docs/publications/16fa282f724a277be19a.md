# Exploration strategies for Gaussian process bandit optimization with inference regret guarantees

**Autores:** Hwanwoo Kim; Jungwoo Hong; Kyungjae Lee

**Data:** 2026-10-12 · **Tipo:** preprint

## Resumo

Existing cumulative regret guarantees for Bayesian optimization \(BO\) do not necessarily characterize the quality of the algorithm&\#x27;s final output\. This gap is critical under noisy evaluations, where the goal is to return a single high\-quality recommendation\. To address it, we introduce efficient exploration strategies that can be incorporated into any BO procedure by occasionally replacing the acquisition query with an exploration query\. To validate this approach, we bound the Gaussian process posterior standard deviation over the search space via the fill distance of the queries, which measures the largest region left unexplored\. We then use this result to derive upper bounds on the inference regret, i\.e\., the gap between the global optimum and the function value at the algorithm&\#x27;s returned point\. Empirically, these exploration strategies improve the final recommendations of existing BO algorithms on synthetic benchmarks, hyperparameter optimization, and a control task\.
