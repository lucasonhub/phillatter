# MC\-CRoMD: A Multi\-channel Statistical Feature Extraction and Selection Framework for Lung and Colon Histopathological Image Classification Using Machine and Deep Learning

**Autores:** Mohammed Thajeel Abdullah; Raed Mohammed Hussein; Ashraf Sabri Waheed Alameri

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

This study introduces MC\-CRoMD, an interpretable statistical framework for lung and colon cancer histological image classification\.Images are divided into non\-overlapping 32×32, 64×64, 128×128, and 256×256 patches\.For each patch, Cronbach&\#x27;s Alpha is used as a heuristic inter\-channel descriptor of shared spatial intensity variation among RGB channels\.Eight dispersion measures\-Range, Variance, Standard Deviation, Q1, Q3, IQR, MAD, and CV\-are extracted separately from each channel, yielding 24 channel\-wise features; together with Cronbach&\#x27;s Alpha, each patch contains 25 features\.The LC25000 dataset was evaluated under binary, three\-class, and five\-class scenarios\.Six feature\-selection methods and the AllMsr baseline were assessed using nine machine\-learning models and a DNN\.Final configurations were selected using validation data and evaluated once on a locked independent test set\.The results imply that statistical descriptors, both inter\-channel and channel\-wise, may support the classification of LC25000 histopathological images\.
