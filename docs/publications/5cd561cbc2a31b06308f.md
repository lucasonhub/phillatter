# JobOrbit: A Real\-Time, Skill\-Focused Platform for Closing the Skill Gap and Strengthening Recruitment Integrity

**Autores:** Aachal Shah; Omkar Yadav; Shagun Verma; Sweta Nigam

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

The modern job market faces challenges such as a growing skill gap, unreliable resume evaluations, and employer fraud on online hiring platforms\. Traditional recruitment methods do not effectively measure real technical abilities, while job seekers often find it difficult to identify legitimate opportunities\. This paper presents JobOrbit, a real\-time, cloud\-driven recruitment system built using React TypeScript and Firebase Firestore\. The platform features skill assessments based on hackathons, company verification, map\-based job discovery, and permanent application records to improve fairness and transparency in the hiring process\. A qualitative analysis, backed by user interviews and prototype testing, shows strong user trust, better engagement, and increased recruiter efficiency\. Future improvements will include adding professional upskilling courses to address long\-term skill gaps\.
