# Regional Indian English Accent Identification via Hybrid Acoustic\-Contextual Speech Representations and Hierarchical HuBERT Layer Probing

**Autores:** Shivapuja Sai Kiran; Varsha Thakur; Sompalli  Naveen Kumar; Vadeghar Nitin; Shivakumar Nethani

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

Regional Indian English exhibits intricate acoustic, phonological, and prosodic variations shaped by speakers&\#x27; native language \(L1\) backgrounds\. Automated identification of these regional accents is essential for accent\-adaptive automatic speech recognition \(ASR\), spoken language identification, and culturally nuanced voice interfaces\. This paper presents a hybrid speech representation framework for six\-class regional Indian English accent identification using the IndicAccentDB corpus \(8,116 recordings across Andhra/Telugu, Gujarat/Gujarati, Jharkhand/Eastern Hindi, Karnataka/Kannada, Kerala/Malayalam, and Tamil\)\. The proposed pipeline fuses low\-level spectral summary statistics derived from 13 Mel\-Frequency Cepstral Coefficients \(MFCCs; 26 dimensions capturing temporal mean and standard deviation\) with deep contextual embeddings extracted from the frozen, pretrained HuBERT\-Base encoder \(768 dimensions via global temporal average pooling\), yielding a 794\-dimensional hybrid representation\. The fused representations are evaluated using multinomial Logistic Regression with L₂ regularization and a lightweight one\-dimensional Convolutional Neural Network \(1D CNN\)\. Under a stratified 80/20 utterance\-level evaluation protocol, the framework achieves 90\.33% test accuracy with Logistic Regression and 90\.83% with the 1D CNN\. A complementary layer\-wise probe across all 13 HuBERT representations on a 500\-utterance diagnostic subset reveals that shallow layers \(Layers 1–2\) yield peak linear separability of 94\.00%, consistent with low\-level acoustic and vocal tract encoding, before declining to 88%–91% in deeper contextual layers\. Temporal duration analysis shows a 25\.48% accuracy drop when restricting audio to 0\.7\-second sub\-utterance clips\. The trained classifier is deployed in an interactive Gradio application coupling regional accent identification with a cultural culinary recommendation interface\. We provide a thorough discussion of evaluation scope, including the distinction between utterance\-level predictability and speaker\-disjoint generalization\.
