# Calibrated Disambiguation for Partial Multi\-label Learning

**Autores:** Zhuoming Li; Yuheng Jia; Mi Yu; Zicong Miao

**Data:** 2026-10-13 · **Tipo:** preprint

## Resumo

Partial multi\-label learning \(PML\) aims to train a classifier on datasets whose instances are over\-annotated with not only relevant labels but also irrelevant labels, which is common when datasets are collected from crowd\-sourcing platform\. Existing works primarily approach it from a curriculum learning perspective, leveraging the memorization effect to disambiguate noisy labels and produce robust predictions\. However, these methods are based on non\-adaptive weighting functions and lack theoretical guidance for optimal weighting\. To overcome these issues, a calibrated disambiguation model named PML\-CD is proposed\. We first formulate the optimal weighting function for curriculum\-based disambiguation, which is equivalent to the calibration of the model&\#x27;s predicted confidences, thus providing guidance for curriculum designing\. To obtain the optimal weighting function from PML dataset during the training, a transferable calibrator is designed, which takes the histogram of positive samples&\#x27; confidences as input, and outputs the optimal curriculum weighting for training\. Prototype alignment regularization is also proposed to promote the model&\#x27;s performance\. Experiments conducted on Pascal VOC, MS\-COCO, NUS\-WIDE and CUB have verified that our method outperforms existing state\-of\-the\-art PML methods\.
