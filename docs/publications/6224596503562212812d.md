# JEPA\-kMMVAE: CSI Prediction for Time\-Varying Wireless Channels

**Autores:** Efstathios Chatziloizos; Konstantinos Vandikas; Aneta Vulgarakis Feljan; Zheng Chen; Nikolaos Pappas

**Data:** 2026-10-09 · **Tipo:** preprint

## Resumo

This paper considers channel state information \(CSI\) prediction using neural networks for time\-varying multi\-antenna channels from noisy historical observations\. The main challenge is to exploit temporal correlation while distinguishing channel evolution from observation noise\. We propose JEPA\-kMMVAE, which combines a joint\-embedding predictive architecture with a k\-memory Markov variational autoencoder to predict future CSI through temporally structured latent representations\. The framework supports direct prediction and residual corrections relative to the latest latent state and noisy CSI observation\. Simulation results show that the residual configuration outperforms the evaluated baselines at moderate and high input CSI signal\-to\-noise ratios, while sequence baselines remain more accurate under stronger noise\.
