# Interpretable MSME Credit Risk Prediction Through XGBoost Feature Selection and LSSVM Classification

**Autores:** Sharmila Jeyarani S\.; Sanjay Raj J\.; Rajamannar N\.G\.; Sabari Anandh M\.

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

This research work proposes an interpretable hybrid ML approach to credit risk evaluation of MSMEs in supply chain financing, combining feature selection using XGBoost with classification using RBF\-LSSVM\. The credit information of the multi\-sourced variety is standardized into a common set of financial and operational variables followed by stratification, training normalization, and class balance through SMOTE technique to minimize the impact of minority class bias while maintaining test set independence\. Using the XGBoost classifier with TreeSHAP analysis of features selects the relevant predictors that are further classified using the RBF\-LSSVM classifier with calibrated probability estimation and optimized decision threshold for risk\-aware classification\. This proposed approach achieves 97\.96% accuracy, 94\.52% precision, 97\.43% recall, and 95\.95% F1\-score on the held\-out evaluation set\. SHAP and counterfactual explanations offer feature level interpretations of the risk assessments\.
