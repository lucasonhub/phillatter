# DriftGuard: an agentic hybrid temporal transformer and graph attention network framework for autonomous calibration drift detection and correction in distributed marine sensor networks

**Autores:** Maryam Arshad; Irum Matloob; Saria Safdar; Rukaiya; Muazzam A\. Khan Khattak; Changli Yu

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

Introduction Undetected calibration drift in autonomous ocean sensors corrupts temperature and salinity records underpinning climate reanalysis, seasonal forecasting, and marine ecosystem assessments\. With 15–20% of active Argo floats showing meaningful drift at any time and correction workflows taking three to six months, scalable autonomous quality control is urgently needed\. Methods We present DriftGuard, a five\-component autonomous framework integrating a physically\-informed heterogeneous sensor graph over 135 nodes, a Hybrid Temporal Transformer and Graph Attention Network \(HybridTGAT\), a cross\-sensor consistency loss, a conformal prediction wrapper, and a LangGraph\-orchestrated three\-stage agentic loop supported by a 2,183\-chunk RAG store\. Results Evaluated on Argo float profiles \(116 floats, North Atlantic, 2021–2024\), NDBC buoy time series \(15 stations, 2019–2024\), and the expert\-labelled AdapAD benchmark, DriftGuard achieves a GAT\-level ROC\-AUC of 0\.8376, an AdapAD zero\-shot AUC of 0\.8423, and detects gradual drift types an average of 84\.7 readings earlier than the operational Argo QC Test 16 baseline\. Operational fleet evaluation across 131 sensors identifies 13 floats in a CRITICAL state requiring correction within 24 hours\. Discussion DriftGuard is the first system in the marine sensor domain to unify graph\-based spatial reasoning, temporal modelling, autonomous LLM\-driven correction, conformal uncertainty certificates, and closed\-loop retraining within a single operational pipeline, demonstrating readiness for real\-world deployment\.
