# A Reproducible Machine Learning Pipeline for Educational Workload Analytics Using Synthetic Data

**Autores:** Mazumder

**Data:** 2026-10-17 · **Tipo:** article

## Resumo

Description This paper presents a reproducible machine learning pipeline for educational workload analytics using synthetic student data\. The study explores how lifestyle and academic\-related variables, including study hours, sleep, physical activity, and other daily activities, can be incorporated into a data\-driven framework for examining student stress\. Using a synthetic dataset comprising 10,000 records, the proposed workflow covers data preparation, feature selection, model training, predictive evaluation, and the interpretation of model performance\. The study reports standard regression metrics, including the coefficient of determination \(\(R^2\)\) and mean absolute error \(MAE\), alongside an additional measure of prediction accuracy within a specified tolerance\. These metrics provide a quantitative assessment of the model&\#x27;s ability to estimate stress\-related outcomes within the constructed dataset\. A central contribution of this work is its emphasis on reproducibility and methodological transparency\. By documenting the analytical workflow and evaluation procedure, the paper provides a practical framework that can support further experimentation in educational data analytics and machine learning\-based student workload research\. The findings should be interpreted within the limitations of synthetic data\. The results do not establish validated relationships between real students&\#x27; lifestyles and stress, nor do they constitute a clinical assessment or a validated student\-support intervention\. Instead, the study serves as an exploratory computational demonstration and a foundation for future research using real\-world, ethically collected, and appropriately validated educational data\. Keywords: Educational data analytics; machine learning; synthetic data; student stress estimation; workload analytics; predictive modelling; reproducible research\.
