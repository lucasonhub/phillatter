# Empowering Sustainable Vertical Farming Through IoT and AI\-Driven Technologies: A technical Blueprint with insights from the UK and India

**Autores:** A\. Razia Sulthana; Priyanshi Kumari

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

This repository contains the code and data provenance documentation supporting the review article &quot;Empowering Sustainable Vertical Farming Through IoT and AI\-Driven Technologies: A Technical Blueprint with Insights from the UK and India&quot; \. As a systematic PRISMA\-based literature review, the study does not involve original experimental or primary data collection; instead, all quantitative values used in the manuscript&\#x27;s tables and figures were extracted and synthesised from previously published peer\-reviewed literature, industry reports, and government/institutional publications through a four\-stage process of extraction, cross\-validation, standardisation, and weighted averaging, with full source citations provided in the manuscript\. This repository includes the Jupyter notebook \(vf\_final\_images\.ipynb\) used to generate the manuscript&\#x27;s illustrative figures \(urban population/arable land/VF adoption trends, soilless cultivation technology performance comparisons, the multi\-layer IoT architecture diagram, and the UK–India comparative climate, market, and consumer analysis charts\) from these literature\-derived values, along with a README\_vf documenting data provenance, methodology, and reproduction instructions\.
