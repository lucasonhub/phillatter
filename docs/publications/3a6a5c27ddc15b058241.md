# Wang, Jiaping: 从三条公理到意识难问题：信息层级单向约束的构造性回应 中文版

**Autores:** 

**Data de descoberta:** 2026-10-16 · **Tipo:** unknown

## Descrição do feed

主流理论多聚焦查尔默斯的“易问题”，未解释第三人称描述为何无法还原第一人称体验。本文从资源有限、非平衡存续、离散输入三公理出发，经排除式收敛形成信息容量框：系统跨时刻存续必然分层编码，高阶格式在低阶追加坐标、不可无损还原，即信息层级单向约束（ILUC）。据此将难问题拆为两层：格式鸿沟由该约束闭合，宽度即编码层级维度差、可标定；存在追问以结构性定义消解，体验即满足锚定、访问终止、整包呈现、强制权重四条件的第一人称自访问过程本身，结构外不另设现象实体，“现象质”直觉的顽固由访问终止解释为可预测内省误判。由此统一回应解释鸿沟、玛丽房间与哲学僵尸，保留并重述感受质，不预设神经基质。 \(direct link \)
