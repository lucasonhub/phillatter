# Sistem Irigasi Otomatis Berbasis Internet of Things \(IoT\) untuk Tanaman Cabai Menggunakan ESP32 dengan Kendali Kelembapan dan Suhu Tanah di Desa Boja

**Autores:** Muhamad Arjun Naja; Priyadi Priyadi; Candra Supriadi

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

Chili pepper \(Capsicum annuum L\.\) requires controlled soil moisture to support proper growth, while soil temperature can serve as a supporting environmental parameter\. This study aims to design and develop an Internet of Things \(IoT\)\-based automatic irrigation system using an ESP32 microcontroller for chili cultivation in Boja Village\. The system employs a soil moisture sensor as the primary parameter to determine irrigation needs, and a DS18B20 sensor as a supporting parameter to determine irrigation duration\. Sensor data are displayed on a 16×2 I2C LCD and transmitted to the Blynk application via Wi\-Fi for real\-time monitoring, with both automatic and manual operating modes\. Functional testing was conducted using 600\-gram soil samples in small pots under six combinations of soil moisture and temperature conditions, followed by connectivity and manual\-control tests\. Product validation used a four\-point Likert questionnaire with one internal validator \(the supervising lecturer\) and one external validator \(the user\)\. Both validations produced a score of 37 out of 40 \(92\.5%\)\. The prototype successfully performs all tested functional scenarios according to the designed control logic, while quantitative sensor accuracy, response time, and water\-use efficiency still require further evaluation\.
