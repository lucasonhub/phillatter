# FENAS: A Few\-Shot Meta\-Ensembling Framework for Efficient Neural Architecture Search with Synergized Zero\-Cost Proxies

**Autores:** Yifeng Mao; Yuze Feng; Yutong Shen; Liyang Gao; Zhixiang He

**Data:** 2026-10-11 · **Tipo:** preprint

## Resumo

Efficient neural architecture search \(NAS\) requires accurate performance estimation under limited evaluation budgets\. Existing zero\-cost proxies \(ZCPs\) provide fast training\-free signals, but each proxy usually captures only a partial property of an architecture, leading to unstable rankings across datasets and search spaces\. In contrast, GNN\-based predictors can improve accuracy, but often depend on labeled architectures, graph encoders, and costly representation learning, which makes them less suitable for extreme few\-shot settings\. We propose FENAS, a topology\-agnostic few\-shot prediction framework that turns complementary initialization priors into robust ranking signals\. Its core component, CAST, is a feature pipeline that combines copula alignment and synergy transformation\. CAST maps heterogeneous ZCPs into a compact feature manifold, enabling lightweight meta\-learners to produce reliable rankings from scarce supervision\. On NAS\-Bench\-201, with only 0\.5% labeled samples, FENAS achieves a Kendall&\#x27;s Tau \($τ$\) of 0\.70, outperforming representative topology\-based few\-shot predictors in this low\-label regime\. In closed\-domain search, FENAS evaluates the NAS\-Bench\-201 space in approximately 1138 seconds and achieves competitive test accuracy\. By providing a fast, reliable, and structurally simple evaluation mechanism, FENAS supports the design of automated neural architectures under limited evaluation budgets\.
