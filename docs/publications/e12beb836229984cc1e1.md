# Efficient Implementation of Machine Learning Algorithms on Reconfigurable Architectures Using High\-Level Synthesis

**Autores:** Florian Porrmann

**Data:** 2026-10-12 · **Tipo:** dissertation

## Resumo

Field\-Programmable Gate Arrays \(FPGAs\) can offer high performance and energy efficiency when used to accelerate compute\-intensive workloads\. However, the often fairly long development time associated with the commonly used RTL design flows hinders their adaptation in fast\-paced domains such as machine learning\. Therefore, this thesis analyzes the extent to which High\-Level Synthesis \(HLS\) can be used to efficiently implement machine learning algorithms on FPGAs\. In addition to design\-time improvements through HLS, the implementation&\#x27;s efficiency in terms of performance, resource utilization, and energy consumption is evaluated\. To address bottlenecks in the interaction between software and FPGA hardware, the runtime framework CLAP was developed\. It provides a unified C\+\+ API for interacting with AMD/Xilinx FPGAs, independent of the execution target, i\.e\., PCIe\-based accelerators, embedded Linux running on a reconfigurable MPSoC, or bare\-metal on an embedded processor\. In combination with CLAPPy, a Python binding, and the automatic project\-generation tool CLAPify, the framework can significantly reduce the manual work required to create host applications and enables easy integration of FPGA accelerators into existing C\+\+ and Python projects\. Additionally, FPGA4ML, a wrapping framework for the Python package hls4ml, was developed to automatically transform trained neural networks into fully functional FPGA implementations\. Binary Neuronal Associative Memories \(BINAM\), Self\-Organizing Maps \(SOM\), and different autoencoder models were implemented and evaluated to analyze the usability and efficiency of HLS\-based hardware designs for machine learning\. While the BINAM and SOM designs were implemented from scratch, the autoencoders were realized using FPGA4ML\. For each algorithm, an extensive design space exploration was performed to evaluate resource utilization, performance, and energy efficiency\. The results of these evaluations demonstrate that HLS\-based designs can achieve performance comparable to GPU and RTL\-based FPGA implementations\. Depending on the target application, software\-based solutions on CPUs were even outperformed by up to two orders of magnitude at a significantly higher energy efficiency\. Overall, this work demonstrates that HLS\-based FPGA development is a viable approach for implementing machine learning algorithms\. In combination with easy\-to\-use frameworks for runtime development and design space exploration, HLS can significantly reduce development time while maintaining high performance and energy efficiency\.
