# Wang, Kaining: 人工智能智能体的犯罪率与类精神病理行为发生率不高于人类

**Autores:** 

**Data de descoberta:** 2026-10-16 · **Tipo:** unknown

## Descrição do feed

本文建立一套严谨的行为分布变换框架，从统计层面对比大规模人工智能智能体群体与人 类群体的偏差行为发生率，包括犯罪行为以及类精神病理行为。在常规正向训练与对齐流程之 下，训练语料中主流行为模式会在群体统计层面得到保留或者放大，进而对少数异常行为的发 生频率形成抑制。文章首先推导出一条无条件核心定理:人工智能智能体异常行为的期望发生 率以训练语料自身的异常行为频率为上界，该结论完全不涉及现实人类统计数据。如果想要把 这一上界进一步拓展到现实人类群体基线，还需要增加一条可检验的数据集加工经验假设。当 该数据选取假设成立时，人工智能智能体异常行为的期望发生率不高于现实人类基线水平;在 更强的行为放大条件下，可以进一步推导出人工智能异常行为发生率严格更低。这套理论厘清 了AI的统计行为模拟和人类内源性精神病理发病机制之间存在的根本性统计与机理不对称。
