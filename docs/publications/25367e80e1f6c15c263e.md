# Pengembangan dan Implementasi Antar Muka Website Perusahaan sebagai Media Informasi pada PT PDPDE Hilir

**Autores:** Indah Permatasari; Freddy Kurnia Wijaya

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

Communicating information through a corporate website requires coherence among its information structure, navigation, visual presentation, and corporate identity\. This study aimed to describe the development and implementation of the PT PDPDE Hilir website interface as a medium for corporate information\. The study employed a descriptive qualitative approach\. Data were collected through direct observation of the existing website, documentation of pages and interface structure, and discussions with the field supervisor and relevant parties\. The development process included identifying information and interface requirements, designing a prototype using Figma, and implementing the design using HTML and CSS through Visual Studio Code\. The development results showed the organization of the navigation structure, corporate information, content grouping, page layout, and interface appearance\. The website structure comprises the main sections Home, About Us, Services, Media &amp; Information, and Contact, along with the Latest News and Activity Gallery submenus, which were implemented as separate pages\. This development integrated information organization, interface design, and technical implementation to produce a more structured medium for corporate information while preserving PT PDPDE Hilir’s visual identity\. The practical contribution of this study is an account of the interface development process that can serve as a reference for developing websites for similar companies\.
