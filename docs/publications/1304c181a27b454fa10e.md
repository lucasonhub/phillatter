# Analisis Pengaruh Parameter Contamination dan N\_estimators Terhadap Performa Isolation Forest Dalam Deteksi Anomali Transaksi Keuangan

**Autores:** Pravasta Adi Wijaya; Deni Arifianto; Wiwik Suharso

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Deteksi anomali pada transaksi keuangan merupakan proses penting untuk mengidentifikasi aktivitas yang menyimpang, terutama pada dataset yang bersifat tidak seimbang\. Salah satu algoritma yang banyak digunakan adalah Isolation Forest, namun performanya dipengaruhi oleh konfigurasi parameter, khususnya contamination dan n\_estimators\. Penelitian ini bertujuan menganalisis pengaruh kedua parameter tersebut terhadap kinerja Isolation Forest menggunakan dataset transaksi kartu kredit yang terdiri dari 284\.807 data\. Dataset dibagi menjadi data latih dan data uji dengan rasio 80:20 serta dilakukan standarisasi menggunakan StandardScaler\. Pengujian dilakukan menggunakan beberapa kombinasi nilai contamination dan n\_estimators, kemudian dievaluasi berdasarkan Precision, Recall, F1\-Score, dan ROC\-AUC\. Hasil penelitian menunjukkan bahwa parameter contamination memberikan pengaruh lebih besar terhadap keseimbangan Precision dan Recall dibandingkan n\_estimators\. Kombinasi n\_estimators 300 dan contamination 0\.002 menghasilkan performa terbaik dengan Precision sebesar 0\.2675, Recall 0\.3096, F1\-Score 0\.2871, dan ROC\-AUC 0\.9455\. Hasil ini menunjukkan bahwa pemilihan parameter yang tepat mampu meningkatkan kinerja Isolation Forest dalam mendeteksi anomali pada data transaksi keuangan\.Kata Kunci: Contamination; Isolation Forest; N\_estimators; Parameter Tuning; Transaksi Keuangan
