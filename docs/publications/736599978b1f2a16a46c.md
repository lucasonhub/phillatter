# Penerapan Metode Eksperimen melalui Media Interactive Smart Board untuk Meningkatkan Hasil Belajar IPAS Siswa Kelas V SD Islam Raudlatul Mubtadiin

**Autores:** Khusnul Khotimah; Wahyu Setyo Nugroho; Nanyk Sudarwati Wulan Desember

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

IPAS learning in elementary schools needs to be implemented using methods and media that can increase students’ active participation and provide direct learning experiences\. This study aimed to describe the application of experimental methods through interactive Smart Board media to improve IPAS learning among fifth\-grade students at SD Islam Raudlatul Mubtadiin on the topic of human body organs\. This study employed Classroom Action Research \(CAR\), which was conducted in two cycles, with each cycle consisting of planning, action, observation, and reflection stages\. Data were collected through observation and tests\. The results showed that the application of experimental methods through interactive Smart Board media improved students’ participation and learning process\. Students became more active in observing, conducting experiments, discussing, and presenting their observations\. The test results showed an average student score of 74\.63, with the highest score of 85\. Based on these results, it can be concluded that the application of experimental methods through interactive Smart Board media can improve IPAS learning among fifth\-grade students at SD Islam Raudlatul Mubtadiin\.
