# MoSAIC: Learning DAG Scheduling Heuristics from Optimal Schedules through Motif\-Aware Recovery and LLM\-Guided Reasoning

**Autores:** Shiva Ahir; Hashmath Shaik; Alex Doboli; Nadeem Yaseen; Simona Doboli

**Data:** 2026-10-10 · **Tipo:** preprint

## Resumo

Efficient task scheduling in heterogeneous computing systems remains a fundamental challenge in embedded and high\-level synthesis flows\. This paper presents MoSAIC \(Motif\-aware Scheduling with AI\-driven Cognition\), a learning\-based framework that bridges the gap between exact and heuristic scheduling approaches for DAG\-based applications\. The system uses the reasoning capabilities of large language models \(LLMs\) to learn the relationships between DAG structures and scheduling priority functions\. The framework first leverages the OR\-Tools CP\-SAT solver \[4\] to generate optimal schedules, which are then used to supervise the learning of compact priority\-based scheduling functions through Bayesian Optimization\. These learned heuristics capture relationships between scheduling decisions and structural graph features such as rank, depth, and fanout, enabling the construction of a reusable knowledge base across diverse DAG instances\. Experimental results across synthetic graph families and real\-world benchmarks, including PolyBench and MachSuite, show that the learned heuristics consistently improve over classical approaches such as HEFT \[2\], while maintaining low runtime overhead\. The results indicate that combining optimal supervision with learning\-based generalization provides a practical approach for scalable and adaptive task scheduling\.
