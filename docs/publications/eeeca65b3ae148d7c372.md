# Think Before You Speak: Enabling Training\-Free Latent Communication Between Language Models

**Autores:** Rishi Khare

**Data:** 2026-10-12 · **Tipo:** preprint

## Resumo

Large language models \(LLMs\) have demonstrated remarkable capabilities in solving complex tasks in coding, mathematical logic, and iterative reasoning, especially by coordinating effectively within multi\-agent systems \(MAS\)\. However, language agents traditionally communicate via text exchange, which introduces a bottleneck in information transfer and adds prefill latency for downstream agents\. Recent work proposes that directly sharing the key\-value \(KV\) cache between language models can enable efficient latent collaboration, entirely bypassing standard text\-based communication\. To enable latent communication between heterogeneous models of different sizes, prior work introduces trained fusion adapters for each model pair, which limits practical deployment\. We introduce CacheFuse, a training\-free method which demonstrates that augmenting a downstream model with an upstream model&\#x27;s KV cache using linear interpolation consistently enables superior performance than the standalone downstream model can achieve\. We systematically analyze CacheFuse across four reasoning and knowledge benchmarks and demonstrate up to 8\.6 percentage points higher accuracy compared to single\-model baselines and up to 12\.2x TTFT speedup compared to text\-based communication in multi\-model inference\.
