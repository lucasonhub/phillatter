# AI\-Driven Underwater Image Enhancement Using Autoencoder and GAN for Increased Maritime Security

**Autores:** Tharun J; S Nithyanandh; R\. Kumuthaveni

**Data:** 2026-10-11 · **Tipo:** article

## Resumo

Underwater surveillance and inspection relies on interpretable images, however, underwater images are prone to haze, colour casts, and poor scene detail\. This paper proposes a two\-stage single\-image enhancement framework which first restores the image using an autoencoder and then refines it using a generative adversarial network \(GAN\)\. The Underwater Image Enhancement Benchmark \(UIEB\) is a set of pairs of raw and reference images\. Preprocessing is done to change the size of the picture to 256 × 256 pixels and normalize the values\. Implementing with Python, TensorFlow/Keras, OpenCV and Google Colab\. This paper contains the convolutional autoencoder, a training run, assembling of the GAN and an output example panel\. These records will support a description of the components that were implemented, but the details of the generator and the discriminator internals and the full end\-to\-end execution record are not available\. The reconstruction loss in the visible autoencoder log is decreasing at the last epoch as compared to the first epoch, and the example panels demonstrate that the visible autoencoder is producing scene\-dependent changes in colour and contrast\. However, the available paper provides no PSNR/SSIM values and there is no quantitative gain for the combined system provided\. Hence, the following paper will put forward a definition of the reference\-based evaluation procedure and will touch on the present qualitative evidence without assigning unmeasured scores\. It is not an architectural priority or a proven improvement to maritime security, it is a modular restoration\-and\-refinement workflow that comes with explicit evaluation and reporting criteria\. Potential application is preprocessing for human\-led underwater surveillance, inspection and visual analysis, operational validation is required\.
