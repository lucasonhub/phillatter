# XferAgent: Cross\-Agent Experience Transfer for Self\-Improving LLM Agents

**Autores:** Weihao Li; Jun Bai; Shijie Chen; Qincheng Lu; Xinyu Wang; Ziyang Song

**Data:** 2026-10-14 · **Tipo:** preprint

## Resumo

Large language model \(LLM\) agents can reuse experience from prior task executions to improve performance on subsequent tasks\. Although existing methods enable cross\-agent experience sharing, differences in agents&\#x27; execution histories and task requirements make shared experiences difficult to reuse effectively\. We propose XferAgent, a framework for cross\-agent experience transfer that organizes reusable experience in local and shared experience graphs\. XferAgent reconciles compatible contributions from heterogeneous agents while avoiding unreliable merges\. For each new task, it selects shared experiences and integrates them with the target agent&\#x27;s local experience to support task execution\. Experiments across diverse task domains show improvements over representative memory\-based methods and effective experience transfer between heterogeneous agent frameworks\. Cumulative task success also increases over successive task passes as agents update and reuse their experiences\.
