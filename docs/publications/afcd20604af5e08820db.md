# Gender in digital game environments: A thematic analysis of mobile games for children

**Autores:** Sibel Karabekmez

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

This study aims to examine gender representations in popular mobile games for early childhood\. Based on the premise that digital games create an influential cultural environment for children from an early age, shaping social roles, norms, and identity construction processes, this study considers the analysis of representational structures in mobile games to be important\. The sample was created by selecting eight mobile games listed in the &quot;most popular free&quot; category on the App Store using the child filter and a purposive sampling method\. Document analysis was used in the study\. Data were collected through a semi\-structured observation and coding form developed by the researcher\. Data were analyzed using a hybrid thematic analysis approach \(using both inductive and deductive coding\)\. The findings show that gender representations in mobile games are grouped under six main themes: repaired femininity, designed femininity, femininity in the showcase, masculine heroism, flexible gender roles in the family, and shaping gender representations\. The analysis results indicate that femininity is heavily coded through appearance, grooming, and aesthetic arrangement, whereas masculine representations are structured more around tasks, expertise, and public action\. However, some games also present gender roles in more flexible, diverse, and counter\-stereotypical ways\. The study suggests that mobile games can be considered digital environments in which gender representations are reproduced and, in some cases, presented in more flexible ways\. Based on these findings, it is recommended that gender representations in digital game design be considered critically and that more inclusive content be developed within the context of early childhood education\.
