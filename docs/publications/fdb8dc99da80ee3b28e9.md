# An Intelligent Tourism Recommender System Using Retrieval\-Guided Large Language Models

**Autores:** Ammar Alazab; Wei\-Jun Lim; N\. D\. Salih; Hairulnizam Mahdin

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

Travel planning has become more complex nowadays due to the information overload from numerous online platforms causing travelers to be overwhelmed when selecting destinations, accommodations, and activities that match their preferences and constraints\. Traditional tourism recommender systems usually provide static and generic suggestions that fail to match users’ needs and cannot understand natural user language\. This research develops and evaluates a Generative AI Chatbot for Tourism Recommendations that use Large Language Models \(LLMs\) to generate personalized travel itineraries through natural language interaction to solve these limitations\. The system can process user natural language inputs including travel origin and destination, trip duration and dates, and budget in a conversational way\. This project used the osunlp/TravelPlanner dataset which contains real\-world tourism information on attractions, restaurants, accommodations, and flights\. The chatbot uses carefully designed prompts with strict generation rules to produce day\-by\-day itineraries that match user constraints\. The preliminary results show the system’s capability to generate human–readable travel plans that include correct flight selections, accommodation recommendations, and structured daily activities\. The chatbot prototype also supports conversational refinement which allows users to modify their itineraries interactively\. The evaluation will be conducted using BLEU and NIST metrics to measure response quality while also using a user satisfaction survey to assess the usability and personalization of the itinerary in the next phase\. This research has contributed to AI\-driven tourism planning by showing how generative AI can be used to create interactive and context\-aware assistants in recommender systems\. Future work will focus on including external APIs and conducting a comprehensive user testing to measure the usability and satisfaction level in the real world\.
