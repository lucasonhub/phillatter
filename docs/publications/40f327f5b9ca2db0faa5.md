# Fourier Positioned\-INR MobileNetV1 Fusion Framework for Maternal\-fetal Plane Classification

**Autores:** Chaitali Haldankar \.; H\. P\. Rajani

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

Accurate classification of maternal\-fetal ultrasound planes is an arduous and challenging task owing to lowresolution image quality, anatomical variability, maternal\-fetal movements, and sonographers&\#x27; expertise\.This leads to misclassification of maternal\-fetal US planes, causing anomalies to go unnoticed\.This study presents a retrospective model development and internal validation process through a lightweight Fourier\-encoded coordinate implicit neural representation \(INR\)\-CNN framework for six\-class maternal\-fetal ultrasound plane classification\.The framework combines image\-dependent convolutional features extracted by an ImageNet\-pretrained MobileNetV1 backbone with a shared positional feature field learned from normalized two\-dimensional coordinates\.Six\-frequency sinusoidal Fourier encoding expands each coordinate pair into a 26\-dimensional representation, which is processed by coordinatewise 1 × 1 convolutional layers\.The resulting positional feature map is spatially aligned with the projected MobileNetV1 feature map and fused through channel\-wise concatenation and a 1 × 1 convolutional projection\.Global average pooling and a regularized softmax classifier are subsequently used to classify fetal abdomen, fetal brain, fetal femur, fetal thorax, maternal cervix, and other ultrasound images\.The model was evaluated using 12,400 images from 1,792 patients in the publicly available Fetal Planes DB dataset\.The dataset was divided at the patient level into training, validation, and test sets containing 10,203 images from 1,433 patients, 1,062 images from 179 patients, and 1,135 images from 180 patients, respectively\.No patient overlap was observed among the three partitions\.Performance was assessed using patient\-level stratified ten\-fold cross\-validation with identical locked folds across the ablation models, followed by evaluation on an untouched patient\-independent test cohort\.The proposed Fourier\-INR fusion model achieved an accuracy of 90\.16 ± 1\.04% under ten\-fold cross\-validation and an accuracy of 91\.10% with a macro F1\-score of 88\.53% on the untouched test cohort\.The proposed model outperformed the MobileNetV1 baseline on the untouched test cohort, increasing accuracy from 90\.57% to 91\.10%\.These findings demonstrate that integrating a shared multi\-frequency positional representation with image\-dependent Mo\-bileNetV1 features provides a modest performance improvement over the corresponding CNN baseline while retaining a lightweight classification architecture\.While external and multicentre validation is required before clinical deployment, this lightweight framework holds strong potential to aid automated prenatal workflows and clinical decision support\.
