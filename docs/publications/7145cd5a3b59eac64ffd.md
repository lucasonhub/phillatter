# Sistem Pembayaran Uang SPP Pada Sekolah MTs Maura EL\-Mumtaz Menggunakan Metode RAD \(Rapid Application Development\) Berbasis Web

**Autores:** Dhimas Ansyahri Aritonang; Muhammad Syahputra Novelan; Hardiansyah Putra

**Data:** 2026-10-09 · **Tipo:** article

## Resumo

The tuition fee payment system is one of the essential administrative services in school financial management\. At MTs Maura EL\-Mumtaz, the tuition fee payment process still faces several challenges, including transaction recording, payment data management, payment history retrieval, and report preparation, which require considerable time\. This study aims to design and develop a web\-based tuition fee payment system to improve the effectiveness and efficiency of payment administration\. The system development method used in this study is Rapid Application Development \(RAD\), which consists of the requirements planning, user design, construction, and implementation stages\. The developed web\-based system provides features for managing student data, tuition fee payment data, recording payment transactions, searching payment histories, and generating payment reports\. The results indicate that the implementation of the RAD method supports a fast and structured system development process according to user requirements\. The developed system facilitates school administrators in recording and monitoring tuition fee payments and generating reports more quickly and accurately\. The implementation of this system is expected to make the tuition fee payment administration process at MTs Maura EL\-Mumtaz more organized, effective, and efficient\.
