# 智慧赋能幼儿科学启蒙教育实践策略研究

**Autores:** 蕊 杨; 佳蓉 李

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

幼儿科学启蒙教育旨在培养和提升幼儿的探索能力、创造能力以及认知能力。智能产品可打破传统幼儿科学启蒙教育桎梏，释放智慧教育发展新优势。本研究探讨了普及智能教室设备、AI智能体、智能应用软件和智能教具后，“游戏化教学”“拟景化教学”“个性化教学”智慧赋能幼儿科学启蒙教育模式的应用价值与实践路径，提出构建智能化背景下“家园社企”联动式育幼生态，以期为幼儿在智慧时代的全面发展提供教学思路与参考。
