# Agent\-assisted modeling for urban drainage systems

**Autores:** Meagan M Tobias; Jacob Marchionda; Branko Kerkez

**Data:** 2026-10-11 · **Tipo:** article

## Resumo

Recent advances in large language models \(LLMs\) offer new opportunities to make water management more intuitive through natural language interfaces\. However, the generalised training of these models limits their effectiveness at domain\-specific tasks such as stormwater modelling, particularly when nuanced answers require executing and modifying water models\. The Model Context Protocol \(MCP\) addresses this challenge by providing a standardised interface for LLMs to interact with external tools while enforcing guardrails for quality control\. Building on this protocol, we introduce SWMM\-MCP, a cross\-platform, model agnostic framework that enables conversational interaction with the United States Environmental Protection Agency’s Stormwater Management Model \(EPA SWMM\)\. SWMM\-MCP leverages the swmm\_api and PySWMM libraries through an MCP server built with FAST\-MCP, allowing users to configure, modify, and evaluate SWMM models via natural language\. We demonstrate SWMM\-MCP using a benchmark task and prompt\-response evaluations comparing performance using eight different base LLMs\. For the benchmark SWMM task, all base LLMs completed the tasks, but at varying levels of computational efficiency and detailed responses\. For the prompt\-response evaluations, the LLMs exhibited distinct personalities\. Results highlight that even within a structured MCP framework, LLM selection significantly affects task efficiency and domain specific prompting remains important for optimal performance\.
