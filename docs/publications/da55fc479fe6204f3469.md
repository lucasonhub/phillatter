# A Machine Learning\-Based Bengaluru Real Estate Valuation and Booking System with Locality Analysis and Buyer CRM

**Autores:** Dr\.  R Rajeswari; Bhoomika H\. V; Bushra; Dudekula Shabana; Krishnaveni K\. A

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

House\-price estimation is difficult because property value is influenced by several interacting factors, including locality, floor area, bedroom configuration, bathrooms, availability and property type\. This paper presents an implemented Bengaluru real\-estate decision\-support system that combines machine\-learning\-based valuation with locality exploration, property verification, booking management and a Buyer Customer Relationship Management \(CRM\) module\. The supplied Bengaluru housing dataset contains 13,320 records and nine original attributes: area type, availability, location, size, society, total square feet, bathrooms, balconies and price\. The raw file contains missing values and duplicate records, motivating a preprocessing stage before model development\. Two regression approaches, Linear Regression and Random Forest Regressor, are evaluated\. In the implemented benchmark, 10,234 cleaned records are evaluated\. Random Forest obtains an R2 of 0\.7706, MAE of INR 18\.35 lakh, RMSE of INR 34\.24 lakh and MAPE of 19\.73%, compared with R2 0\.3724, MAE of INR 26\.35 lakh, RMSE of INR 56\.64 lakh and MAPE of 26\.61% for Linear Regression\. The deployed interface demonstrates a Vijayanagar valuation of INR 89\.71 lakh, a displayed 90% prediction interval of INR 85\.4–94\.0 lakh, a locality map, verification information and an active\-booking dashboard\. The study therefore extends house\-price prediction from an isolated regression task to an integrated Bengaluru real\-estate workflow\.
