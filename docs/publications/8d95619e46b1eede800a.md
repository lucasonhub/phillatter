# Jezyk, Zigmond: Pseudoupdate: A Naturalized Framework for the Experimental Study of Recursive Non\-Actualization

**Autores:** 

**Data de descoberta:** 2026-10-16 · **Tipo:** unknown

## Descrição do feed

This paper develops a naturalized and empirically testable framework for a specific problem in cognitive science: the possibility that a system can undergo substantial internal modification while failing to acquire correspondingly new information about an independently existing target\. The central construct is termed a pseudoupdate\. A pseudoupdate is defined here as a measurable transition from one internal state to another that changes the system’s representational configuration but does not produce an independently validated increase in information about the target variable under investigation\. The distinction is deliberately narrower than a claim about consciousness or subjective experience\. It concerns the relation between state transition, information provenance, predictive performance, and external validation\. The state\-transition model represents cognition as a state\-transition system with internally generated transitions and externally constrained transitions\. A self\-referential operator is represented as a transformation whose inputs are drawn from the system’s existing state and internal transition rules\. Such a transformation may produce a different state, including a state that contains recombinations, abstractions, or higher\-order descriptions of prior states\. The resulting modification is therefore real as a state transition\. The question is whether it constitutes an informational update relative to an independently measured target\. The proposed methodology separates state displacement from information gain and predictive improvement\. It introduces a causal intervention protocol in which internal recursion, external evidence, and control conditions are manipulated independently\. The protocol estimates state\-space displacement, predictive loss, mutual information with an external target, retention after removal of the initiating stimulus, and the extent to which apparent updating survives counterfactual replay\. The central hypothesis predicts that internally generated self\-reference can produce persistent state modification without necessarily producing externally validated information gain\. The prediction is falsifiable: if matched internal\-only transitions reliably produce target\-specific predictive improvements that cannot be reproduced from the pre\-transition state and transition rules, the strong pseudoupdate hypothesis is rejected\. Internal change is not treated as unreal, nor is any nonphysical entity inferred from the persistence of self\-reference\. Its purpose is to provide a measurable distinction between changing a system’s state and changing the information that state contains about a separately controlled target\.
