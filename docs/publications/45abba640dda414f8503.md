# Naoto, Fujie: Credit\-Score Operational\-Shape Penetration\-Cycle Theory Experimental Supplement II: Cross\-Score Mutual Conditioning Between Two Independent Scoring Sites

**Autores:** 

**Data de descoberta:** 2026-10-16 · **Tipo:** unknown

## Descrição do feed

\_Zenodo\_ 1\. 2026This experimental supplement tests whether two initially independent scoring sites become mutually conditioning once the output of each site is allowed to alter the inputs, access conditions, or reachable states relevant to the other\. Rather than treating a credit score as a passive representation of an independently existing subject, the experiment models scoring as an intervention in a coupled configuration: a score can change resource access, eligibility, transaction conditions, or subsequent behavior, and these changes can in turn modify the variables from which later scores are generated\. Cross\-score mutual conditioning is identified when perturbing one scoring site produces a non\-redundant downstream change in the other after controlling for shared baseline variables and direct common causes\. The analysis distinguishes correlation between scores from penetration, in which a locally generated score changes the configuration encountered by another scoring process, and from circulation, in which the resulting change returns to alter later scoring conditions at the originating site\. The experiment therefore tests whether nominally independent scoring systems can generate endogenous dependence through repeated allocation, exclusion, and feedback\. The broader claim is that credit scores should be analyzed not only as measurements or predictions but as operational interventions capable of reorganizing the populations, resources, and future data on which subsequent scoring depends\. \(direct link \)
