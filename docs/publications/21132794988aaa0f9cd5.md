# Pemodelan Klasifikasi Tingkat Kerusakan Peralatan Penunjang Akademik Berbasis Natural Language Processing dan Naïve Bayes

**Autores:** Trizaurah Armiani; Diah Novita Sari; Aqila Putri Fathiyah; Rahmawati Dwi Lestari; Muhammad Karison

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

Pengelolaan laporan kerusakan peralatan akademik menghadapi permasalahan karena informasi kerusakan umumnya disampaikan dalam bentuk teks tidak terstruktur dengan variasi deskripsi yang berbeda\. Kondisi tersebut menyulitkan proses identifikasi tingkat kerusakan secara konsisten dan dapat memperlambat penanganan aset\. Penelitian ini bertujuan menerapkan Natural Language Processing untuk mengolah deskripsi laporan kerusakan dan menggunakan algoritma Naïve Bayes untuk mengklasifikasikan tingkat kerusakan peralatan\. Data penelitian diperoleh dari laporan kerusakan pada Unit Penunjang Akademik Perawatan dan Perbaikan Politeknik Negeri Sriwijaya periode 2021–2026\. Sebanyak 4\.147 data laporan dikumpulkan dan melalui tahap data preparation diperoleh 2\.374 data yang digunakan dalam proses klasifikasi\. Pengolahan teks dilakukan melalui case folding, tokenizing, filtering, dan stemming, kemudian data direpresentasikan menggunakan pembobotan Term Frequency\-Inverse Document Frequency \(TF\-IDF\)\. Karena distribusi kelas tidak seimbang, Synthetic Minority Over\-sampling Technique \(SMOTE\) diterapkan pada data training sebelum proses klasifikasi menggunakan Naïve Bayes\. Evaluasi terhadap 475 data testing menghasilkan akurasi sebesar 86,53%\. Hasil tersebut menunjukkan bahwa kombinasi text preprocessing, TF\-IDF, SMOTE, dan Naïve Bayes dapat diterapkan untuk mengklasifikasikan tingkat kerusakan peralatan berdasarkan teks laporan kerusakan\.
