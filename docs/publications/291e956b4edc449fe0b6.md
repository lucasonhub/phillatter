# Subspace‐Based System Identification From Binary Measurements

**Autores:** Ali Mestrah; Mathieu Pouliquen; Eric Pigeon

**Data:** 2026-10-09 · **Tipo:** article

## Resumo

ABSTRACT This paper is concerned with subspace identification from binary measurements for systems whose dynamical behavior can be splited into a deterministic and a stochastic subsystem\. An identification algorithm is detailed\. The main contribution of the proposed identification algorithm lies in the identification of both the deterministic subsystem and the stochastic subsystem\. Some convergence properties are established\. Numerical simulations confirm the analysis\.
