# Research on an Efficient Authentication Scheme for Vehicle Networking Broadcast Messages Based on Attribute Encryption

**Autores:** Jingdan Zhang; Li Cao; Lingfeng Yang; Sun Mengmeng

**Data:** 2026-10-11 · **Tipo:** article

## Resumo

ABSTRACT To address the issues of insufficient privacy protection strength, as well as low computational and communication efficiency in existing vehicular network broadcast message authentication schemes, a highly efficient attribute‐based encryption solution for broadcast message authentication is proposed\. The scheme innovatively integrates elliptic curve cryptography with the LSSS access structure, establishing an attribute‐based encryption mechanism that does not require bilinear pairings\. By associating identity information with attribute sets, dynamic privacy protection for messages is achieved without exposing specific identities in resource‐constrained environments\. Simultaneously, the key generation process is optimized by pre‐generating part of the keys during the offline registration phase, significantly reducing the interaction frequency and communication delay between vehicles and trusted institutions\. Security analysis confirms that the solution meets multiple security requirements, including vehicle identity privacy protection, message unforgeability, attribute revocation, and malicious node tracking\. Performance test results demonstrate that, compared with existing typical solutions, the proposed scheme reduces computational overhead by 88% and communication overhead by 66%, offering a practical solution for secure and efficient message communication in IoV environments\.
