**Autores:** Benedict Dell; Paul Robert White; Jonathan M\. Bull; Denise Risch

**Data:** 2026-10-15 · **Tipo:** dissertation

## Resumo

Dataset related to thesis of same name\. MetaData for the project is contained in the ReadMe files, with each providing details of the file structure and scripts used in each Chapter of the thesis\. Please read the Thesis\_Data\_Overview\_Read\_Me for more details\. Data is available upon request using the attached Request Form \(due to the size of the data it cannot be stored directly\) \. The data is structured into corresponding chapters\. Each folder Contains Code, Plots and Data used for that chapter\. The data folder for each chapter contains the indices used along with environmental datasets\. Raw acoustic data is not included due to size limitations\.
