# naspaclust: A hybridisation of spatial fuzzy clustering with nature\-inspired optimisation

**Autores:** Bahrul Ilmi Nasution; Rezzy Eko Caraka; Robert Kurniawan

**Data:** 2026-10-12 · **Tipo:** preprint

## Resumo

We present an overview of R package called \\texttt\{naspaclust\}, a tool for spatial fuzzy clustering improvement by hybridising the Fuzzy Geographically Weighted Clustering \(FGWC\) with nature\-inspired optimisation algorithms\. There are seven optimisation algorithms in general, namely Artificial Bee Colony, Flower Pollination Algorithm, Gravitational Search Algorithm, Harris\-Hawk Optimisation, Intelligent Firefly Algorithm, Particle Swarm Optimisation, and Teaching\-Learning Based optimisation\. The optimisation algorithms available do not only use the basic algorithms, but also the modified version of several parts such as randomisation terms and updating rules\. Furthermore, we also provide additional options by providing more distance metrics options based on the \\texttt\{ rdist\} package\. This study showed the implementation of the \\texttt\{naspaclust\} package in various cases, as well as comparing the performance of the algorithms in the scope of basic algorithms\. The \\texttt\{naspaclust\} package allows to improve the performance of fuzzy clustering, mainly in spatial context\.
