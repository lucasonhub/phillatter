# ResNet\-50\-XGBoost Based Hybrid Model for Detection and Classification of Breast Cancer in Histopathology Imaging

**Autores:** K\. Vinay; D\. Lohith; S\. Suresh Babu; Sunil Babu Melingi

**Data:** 2026-10-09 · **Tipo:** article

## Resumo

Breast cancer continues to be the main cancer type which threatens women’s lives across all countries while creating a significant number of cancer deaths\. The medical field requires immediate and accurate assessment of biopsy histopathological images which must be divided into benign and malignant categories to improve patient care through early medical intervention\. The research introduces a novel system which uses deep learning techniques together with ensemble learning techniques to conduct breast cancer histopathological image classification for its binary classification task using BreakHis dataset\. The proposed method establishes ResNet50 as an everlasting feature extractor which produces 2048dimensional deep feature vectors from microscopic tissue images through its Global Average Pooling \(GAP\) function after being pretrained on ImageNet\.
