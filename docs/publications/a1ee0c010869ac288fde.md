# Harm Spot Detection using Artificial Intelligence &amp; Machine Learning

**Autores:** Sariya Anjum; Rohan Gowda U; Spoorthi E S; Srushti A M; Dhanush N

**Data:** 2026-10-18 · **Tipo:** article

## Resumo

Crime is a major concern in urban and semi\-urban areas, and identifying locations where crime risk may be higher can support better planning and resource allocation\. This project presents an Artificial Intelligence and Machine Learning based Crime Hotspots Detection system that uses location\-based crime\-related features to estimate the risk level of a selected geographical point\. The system combines a web\-based map interface with a machine learning backend\. A user selects a location on an interactive map, the frontend sends latitude and longitude to the backend API, and the backend extracts relevant features and applies a trained XGBoost model to predict the crime\-risk category\. The result is returned to the user as a risk score and a category such as Low, Medium, or High\. The system is designed to provide an easy\-to\-understand visual representation of potential crime\-risk areas and can support data\-driven analysis and planning\.
