# Integrasi Generative AI dan Large Language Model pada Aplikasi Web untuk Transformasi Sketsa Menjadi Gambar Realistis dan Evaluasi Otomatis

**Autores:** Muhammad Yulasfi Pahrizal; Nasruddin Bin Idris; Pramudya Prima Insan

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Penelitian ini bertujuan untuk merancang dan membangun sebuah aplikasi generative artificial intelligence \(GenAI\) berbasis web yang mampu mentransformasi sketsa dua dimensi menjadi gambar realistis secara otomatis, serta dilengkapi fitur AI review sebagai media evaluasi dan pembelajaran menggambar sketsa\. Penelitian ini mengintegrasikan layanan GenAI berbasis diffusion model untuk proses generasi gambar dengan large language model \(LLM\) yang menganalisis sketsa, prompt, dan hasil gambar, tanpa melakukan pelatihan atau pengembangan arsitektur model AI baru\. Metode penelitian yang digunakan adalah penelitian terapan \(applied research\) dengan pendekatan rekayasa perangkat lunak model waterfall\. Aplikasi dibangun menggunakan Next\.js sebagai frontend, FastAPI sebagai backend, PostgreSQL sebagai basis data, MinIO sebagai object storage, serta Docker dan Nginx untuk mendukung deployment berbasis container\. Studi ini menggunakan pengujian fungsional dengan metode black box testing teknik equivalence partitioning yang menunjukkan seluruh 44 skenario uji pada sembilan modul sistem berjalan sesuai kebutuhan fungsional dengan tingkat keberhasilan 100%\. Evaluasi penerimaan pengguna \(User Acceptance Test\) terhadap 15 responden menghasilkan skor rata\-rata 4,38 dari skala 5 \(87,59%\) dengan kategori sangat baik, dimana fitur AI review memperoleh nilai tertinggi\. Secara praktis, aplikasi ini dapat langsung dimanfaatkan oleh desainer, ilustrator, dan kreator digital untuk mempercepat eksplorasi konsep visual tanpa memerlukan keahlian ilustrasi tingkat lanjut\. Secara sosial, aplikasi ini berkontribusi pada demokratisasi proses kreatif dengan meningkatkan aksesibilitas produksi visual bagi masyarakat yang memiliki keterbatasan kemampuan menggambar\. Nilai originalitas penelitian ini terletak pada penambahan fitur AI review berbasis LLM sebagai mekanisme evaluasi dan umpan balik otomatis yang belum tersedia pada aplikasi maupun penelitian transformasi sketsa sejenis sebelumnya\.
