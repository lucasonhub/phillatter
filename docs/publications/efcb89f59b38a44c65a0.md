# Sistem Pendukung Keputusan Seleksi Penerimaan Peserta PKL/Magang Menggunakan Metode Multi\-Attributive Border Approximation Area Comparison \(MABAC\) di Sarastya Agility Innovations

**Autores:** Indrawan Rizqi Prasetia; Wilda Imama Sabilla; Ulla Delfana Rosiani

**Data:** 2026-10-11 · **Tipo:** article

## Resumo

The selection process for internship participants at Sarastya Agility Innovations requires an objective, structured, and business\-unit\-oriented assessment\. The previous manual selection process had the potential to cause subjectivity, difficulties in managing applicant data, and longer processing time in determining eligible candidates\. In addition, the selection process must consider multiple assessment criteria, preferences from several decision makers, document completeness, business unit placement, and the acceptance quota for each business unit\. This study aims to develop a web\-based Decision Support System \(DSS\) for the selection of internship participants using the SWARA, GDSS\-BORDA, and MABAC methods\. The SWARA method is used to calculate criteria weights based on priority Rangking and relative importance values provided by each decision maker\. Furthermore, the GDSS\-BORDA method is applied to aggregate the Rangking results from multiple decision makers in order to obtain final group\-based criteria weights\. These final weights are then used in the MABAC method to calculate preference values and generate candidate Rangkings\. The developed system provides several functions, including user authentication, recruitment team account management, selection period management, candidate data import, document validation, criteria and sub\-criteria management, criteria weight management, candidate assessment, MABAC Rangking calculation, acceptance quota management, Rangking result printing, and user profile management\. The results show that the system can support the internship candidate selection process in a more measurable, objective, and well\-documented manner\. Black Box Testing on system functions achieved a 100% success rate, indicating that all functions worked according to the predetermined test scenarios\. The System Usability Scale \(SUS\) evaluation obtained an average score of 81\.25, which falls into the very good/acceptable category\. The Spearman Rank Correlation test on 20 alternatives obtained a value of 0\.9895, indicating a very high level of agreement between the spreadsheet calculation Rangking and the Rangking generated by the system\. Therefore, the implementation of SWARA, GDSS\-BORDA, and MABAC methods in the decision support system can support the internship participant selection process at Sarastya Agility Innovations in a more objective, consistent, and efficient manner\.
