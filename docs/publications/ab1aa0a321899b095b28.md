# Peningkatan User Experience Website SIP Dispendukcapil Jember Melalui Evaluasi UEQ Dan SDLC Waterfall

**Autores:** Nurulia Ainur Rohmah; Henny Wahyu Sulistyo; Habibatul Azizah Al Faruq; Nur Qodariyah Fitriyah; Qurrota A&\#x27;yun

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Website SIP Dispendukcapil Jember merupakan media pelayanan administrasi kependudukan berbasis web yang masih memerlukan peningkatan pada aspek pengalaman pengguna, terutama terkait kemudahan penggunaan, navigasi, dan tampilan antarmuka\. Penelitian ini bertujuan mengevaluasi user experience menggunakan User Experience Questionnaire \(UEQ\) serta mengembangkan website melalui Software Development Life Cycle \(SDLC\) model Waterfall\. Evaluasi dilakukan berdasarkan enam dimensi UEQ, kemudian hasilnya digunakan sebagai dasar penyusunan kebutuhan sistem\. Setelah pengembangan selesai, dilakukan evaluasi ulang menggunakan instrumen yang sama\. Hasil evaluasi menunjukkan seluruh dimensi UEQ mengalami peningkatan, dengan kenaikan terbesar pada dimensi Novelty sebesar 0,632 dan Dependability sebesar 0,387 setelah implementasi pengembangan sistem\. Berdasarkan UEQ Benchmark, dimensi attractiveness, efficiency, dependability, dan novelty berada pada kategori Excellent, sedangkan perspicuity dan stimulation berada pada kategori Good\. Hasil tersebut menunjukkan bahwa penerapan UEQ sebagai dasar pengembangan melalui SDLC Waterfall mampu meningkatkan kualitas user experience Website SIP Dispendukcapil Jember\.Kata Kunci: User Experience ; UEQ; SDLC; Waterfall; Website
