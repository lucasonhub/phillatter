# Automated Data Preprocessing Using Parameterized SWRL Inference within a Local RAG Pipeline

**Autores:** Maria de los Ángeles Contreras Trujillo; Mayerli Rosario Quintuña Ramón; Claudia Tamara Serpa Flores; Marcia Patricia Ullauri Carrasco; Marcos Orellana

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

This work formalizes expert knowledge in data preprocessing through the Web Ontology Language \(OWL\) and parameterized Semantic Web Rule Language \(SWRL\) rules, integrated with a Retrieval\-Augmented Generation \(RAG\) pipeline for natural\-language queries\. An OWL ontology comprising 47 classes, 42 individuals, and 19 SWRL rules was designed in Protégé and validated on the Netflix Movies and TV Shows dataset \(8,807 records, 12 columns\)\. A Python\-implemented inference engine, which parses the SWRL rule structure from the RDF/XML serialization and evaluates antecedents through deterministic conditionals without invoking a native OWL DL reasoner, generated 15 preprocessing\-technique recommendations across 9 analyzable columns; the remaining 3 columns \(show\_id, title, description\) were excluded as identifiers and free\-text fields, respectively, for which tabular preprocessing is not applicable\. The system guides data scientists in selecting preprocessing techniques based on each column&\#x27;s statistical profile, reducing reliance on manual configuration\. The novelty lies in parameterizing SWRL rules using dynamically computed statistical metrics and multilingual semantic retrieval, within a fully local RAG pipeline that supports traceability and privacy\.
