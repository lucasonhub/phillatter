# Modus Ponens in the logic of reasons

**Autores:** Vincenzo Crupi; Andrea Iacona

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

This paper addresses the question whether Modus Ponens holds in the logic of reasons, that is, whether a binary connective that formally represents the relation ‘is a reason for’ should validate Modus Ponens\. As will emerge, there is no straightforward answer to this question, since different intuitions about reasons pull in different directions\. Our aim is to show how these intuitions can be captured within a single formal framework\.
