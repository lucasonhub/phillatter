# Edge\-AI enabled real\-time classroom attentiveness monitoring via facial emotion recognition on Raspberry Pi

**Autores:** Bhavya Davda; Safvan Vahora; Nilesh Maltare; Hiren Patel

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Monitoring student attentiveness in physical classrooms remains a largely manual and subjective process, typically relying on instructor observation, which is neither scalable nor continuous\. This paper presents an edge\-AI enabled system for real\-time classroom attentiveness monitoring using facial emotion recognition deployed entirely on a Raspberry Pi 5, eliminating the need for continuous cloud connectivity or transmission of raw video data\. The proposed pipeline captures classroom images at 60\-s intervals over a full session, performs on\-device face detection using RetinaFace, and classifies detected faces into seven emotion categories using DeepFace\. A weighted aggregation scheme maps the resulting class\-wide emotion distribution to a normalized per\-frame attentiveness score, which is logged locally and subsequently visualized through a cloud\-based dashboard for instructor review\. The system was evaluated on a self\-collected classroom dataset comprising 2 classrooms and 8 sessions with number of students ranging from 60 to 90 in each session\. Each session is around 50–55 min\. In the proposed system, the face\-detection using the RetinaFace achieved an accuracy of 95\.67%, compared with 89\.46% using the implemented three\-layer convolutional neural network \(CNN\) baseline\. For emotion classification, the DeepFace achieved an accuracy of 93\.46%, compared with 78\.42% for the three\-layer CNN baseline\. The complete pipeline achieved an average inference latency of 62 ms per frame on a Raspberry Pi 5\. By performing all sensitive image processing at the edge and transmitting only derived, non\-identifiable attentiveness metrics to the cloud, the proposed system offers a privacy\-preserving, low\-cost, and scalable alternative to conventional classroom monitoring approaches\. Results demonstrate the feasibility of deploying deep learning\-based engagement analytics on resource\-constrained edge hardware for real\-world educational settings\.
