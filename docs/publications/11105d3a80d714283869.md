# GPU Goldmines: Tunable WebGPU Kernels for Edge LLM Inference

**Autores:** Rithik Sharma; Reese Levine; Zheyuan Chen; Ananthajit Srikanth; Yanwen Xu; Tyler Sorensen

**Data:** 2026-10-12 · **Tipo:** preprint

## Resumo

As demand for LLM inference grows and consumer GPUs grow more capable, edge deployment is becoming increasingly attractive\. WebGPU is compelling in this setting because it offers cross\-platform portability and browser accessibility\. However, these same strengths also make high performance difficult to achieve, as an implementation that performs well in one context may not perform well in another\. To address this, we present GPU Goldmines, a framework for specifying, executing, and tuning WebGPU kernels\. We instantiate GPU Goldmines with kernels for key LLM building blocks: matrix multiplication, matrix\-vector multiplication, and flash attention\. We characterize performance across diverse devices, shapes, and browsers, and use the resulting database to accelerate subsequent autotuning and configuration selection\. On shapes drawn from Llama and Qwen models, our matrix multiplication kernels outperform ONNX Runtime and llama\.cpp WebGPU kernels by 7\.0x and 1\.41x geometric mean, respectively, and deliver end\-to\-end improvements of 1\.48x in the prefill stage of llama\.cpp for chat workloads\.
