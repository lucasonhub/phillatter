# Time series regression network using exogenous variables for missing effective ion charge reconstruction in EAST tokamak

**Autores:** K\. Jia; Zong Xu; Zhenwei Wu; Wei Gao; Minrui Wang; Ang Ti; Hailin Zhao; Xiaohe Wu; Zhen Zhou; Kaibo Nan; Zhe Yuan Si; Zichao Lin; Juan Huang

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

Abstract The effective ion charge \(Zeff\) is a key parameter for characterizing plasma impurity levels and is important for investigating impurity transport and assessing discharge conditions in tokamaks\. However, diagnostic system failures can lead to missing or incomplete Zeff signals\. Accurate reconstruction remains challenging because Zeff is related to multiple plasma parameters and exhibits temporal dependencies\. In this study, a time series regression network was developed to reconstruct missing Zeff values from exogenous plasma parameters in EAST\. The model employed a sequential CNN\-BiGRU\-Transformer encoder architecture, in which the CNN extracted local temporal features, the BiGRU captured bidirectional temporal information, and the Transformer encoder modelled dependencies across different timescales through multi\-head self\-attention\. The model was trained and validated using a dataset comprising 1566 EAST discharges\. The results show that the average similarity between the reconstruction and experimental data is 90\.3%, while the average coverage probability is 91\.4%, indicating that most reconstruction values fall within the standard deviation error range of the experimental results\. Overall, this study presents a feasible offline signal reconstruction method to maintaining the integrity of Zeff signals in EAST and provides a useful reference for reconstructing missing diagnostic data in future fusion devices\.
