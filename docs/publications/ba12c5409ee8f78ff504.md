# Intensity\-Measure\-Driven Prediction of Equivalent Seismic Responses for Deep\-Water Bridge Pile\-Group Foundations

**Autores:** Xiaowei Wu

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

Abstract Rapid seismic screening of deep\-water bridge pile\-group foundations requires evaluation of ground\-motion intensity, site condition, water depth, and foundation geometry\. This study develops an intensity\-measure\-driven workflow for predicting responses from an equivalent dynamic model without using original acceleration time histories as inference inputs\. A subset of 461 records from 82 Next Generation Attenuation\-West2 events is combined with water depths of 30, 60, and 90 m, yielding 1,383 samples\. One acceleration realization is shared across the three depths of each record\. Its coefficients are calibrated to peak ground acceleration, peak ground velocity, and spectral accelerations at 0\.2, 1\.0, and 3\.0 s; median relative errors for all five measures remain below 0\.003%\. Twelve regression models are assessed using an event\-independent test set and target\-wise normalized metrics\. Long short\-term memory \(LSTM\) achieves the lowest complete\-input normalized mean absolute error \(NMAE\) of 0\.0090 and normalized root mean square error \(NRMSE\) of 0\.0155\. Three\-seed tests confirm this ranking, with LSTM attaining an NMAE of 0\.0101 ± 0\.0016\. The five\-measure input set lowers three\-seed NRMSE from 0\.0852 for peak ground acceleration alone to 0\.0166\. When 20%–60% of features are set to training means, the latent\-relation residual variant lowers NMAE by 1\.45%–2\.11% relative to LSTM while adding 16 parameters\. Thus, combined intensity measures govern complete\-input accuracy, whereas relation\-residual mixing provides a bounded benefit under incomplete conditions\. The labels remain limited to a linear equivalent oscillator and a parameterized foundation family\. Within this scope, the workflow enables rapid equivalent\-response screening across conditions without AT2 records as prediction inputs\.
