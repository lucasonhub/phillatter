# Machine Learning Versus Deep Learning in Macroeconomic Forecasting: A Global GDP Growth Application

**Autores:** Fazale Naeem; Muhammad Naveed; Muhammad Fayez; Santosh Prasad Sah

**Data:** 2026-10-18 · **Tipo:** article

## Resumo

This study compares regularized linear, tree\-based ensemble, boosting, and feed\-forward neural\-network approaches for forecasting country\-level annual GDP growth using a global panel covering 213 countries from 2010 to 2023\. A chronological out\-of\-sample evaluation is employed, with models trained on observations through 2021 and tested on 401 country\-year observations from 206 countries during 2022–2023\. Ridge regression, Random Forest, Histogram\-Based Gradient Boosting, AdaBoost, and a multi\-layer perceptron \(MLP\) are evaluated using root mean squared error \(RMSE\)\. Ridge regression records the lowest observed test RMSE \(5\.50\), followed by Histogram\-Based Gradient Boosting \(6\.28\), Random Forest \(6\.75\), AdaBoost \(7\.13\), and the MLP \(8\.12\)\. AdaBoost is treated as a classical boosting\-based machine\-learning method, whereas the MLP serves as the neural\-network benchmark\. The baseline models use one\-year lags, while AdaBoost and the MLP use one\-to\-three\-year lag windows\. Consequently, the observed ranking reflects differences in both model specifications and information sets and should not be interpreted as a strictly like\-for\-like comparison or evidence of statistical superiority\. Within this annual panel, predictor set, and 2022–2023 evaluation period, greater model complexity is not associated with lower forecast errors\. The findings highlight the practical importance of regularization, model parsimony, and chronological evaluation in country\-level macroeconomic forecasting\.
