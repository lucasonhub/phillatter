# An Algebraic Approach to Constrained K\-means Clustering

**Autores:** Hiroki Oohori; Kentaro Fukushima; Michio Yamamoto

**Data:** 2026-10-10 · **Tipo:** preprint

## Resumo

Clustering is typically performed using only object features, although additional information about relationships between objects may be available and can be incorporated through constraints\. Among these, pairwise constraints require two objects to belong to the same cluster or to different clusters\. Several extensions of the k\-means algorithm accommodate such constraints, but they sometimes fail to find a feasible assignment or incur high computational cost\. Motivated by these limitations, we propose an algebraic approach to k\-means clustering with pairwise constraints\. The algorithm simplifies the constraints using Gröbner bases before optimization, improving the efficiency of cluster assignment\. It can also detect whether the constraint set has a feasible assignment before optimization\. Comparative experiments with existing algorithms showed that the proposed algorithm achieved comparable or better clustering quality at a lower computational cost, particularly when the numbers of constraints and clusters were small\.
