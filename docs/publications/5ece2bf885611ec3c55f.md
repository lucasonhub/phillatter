# Desain UI/UX Game\-Based APP Edukasi Pengenalan Bahasa Daerah Batak Toba Dengan Metode Design Thinking

**Autores:** Angela Fadilla S; Randi Rian Putra; Heni Wulandari

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

The Batak Toba regional language in North Sumatra is currently classified as Level 6b \(Threatened\) on the Expanded Graded Intergenerational Disruption Scale \(EGIDS\)\. Conventional learning media have failed to engage the digital native generation\. This study aims to design an interactive, user\-centered User Interface \(UI\) and User Experience \(UX\) for a mobile game\-based educational application focused on basic vocabulary \(greetings, numbers, colors, and common objects\)\. The design process systematically follows the five stages of the Design Thinking methodology: empathize, define, ideate, prototype, and test\. The research scope is limited to high\-fidelity visual prototype development using Figma\. An empirical evaluation was conducted with 20 student respondents from Universitas Pembangunan Panca Budi Medan using structured task scenarios\. Usability was measured quantitatively using the standard 10\-item System Usability Scale \(SUS\) questionnaire\. The calculation yielded a global average SUS score of 78\.5\. This scientifically proves that the prototype design exceeds the standard acceptable threshold of 68 and achieves a &\#x27;Good&\#x27; rating\. Consequently, the proposed UI/UX design is validated as effective and ready for the software engineering phase as a preventive effort against digital language extinction\.
