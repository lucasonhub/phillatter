# Design and development of an automated telephone ordering system using artificial intelligence

**Autores:** Ελευθέριος Βλάχος

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Η παρούσα διπλωματική εργασία πραγματεύεται τον σχεδιασμό και την ανάπτυξη ενός συστήματος αυτόματης λήψης και διαχείρισης τηλεφωνικών παραγγελιών για επιχειρήσεις εστίασης, με αξιοποίηση τεχνολογιών Τεχνητής Νοημοσύνης και Επεξεργασίας Φυσικής Γλώσσας\. Η ανάγκη για την ανάπτυξη ενός τέτοιου συστήματος προκύπτει από τις δυσκολίες που μπορεί να παρουσιάζει η παραδοσιακή τηλεφωνική καταγραφή παραγγελιών, όπως λάθη στην καταχώρηση, καθυστερήσεις και αυξημένη απασχόληση του προσωπικού\. Στόχος της εργασίας είναι η δημιουργία ενός λειτουργικού πρωτοτύπου που μπορεί να λαμβάνει την προφορική παραγγελία του πελάτη, να επεξεργάζεται το περιεχόμενό της και να τη μετατρέπει σε δομημένη μορφή, ώστε να μπορεί να αποθηκευτεί, να ελεγχθεί και να διαχειριστεί από το προσωπικό της επιχείρησης\. Για την υλοποίηση του συστήματος συνδυάζονται σύγχρονες τεχνολογίες αναγνώρισης ομιλίας, Μεγάλων Γλωσσικών Μοντέλων και ανάκτησης σχετικής πληροφορίας, ενώ παράλληλα υποστηρίζεται η λειτουργία πολλαπλών καταστημάτων με διαφορετικά μενού\. Η αξιολόγηση της εφαρμογής πραγματοποιήθηκε τόσο σε λειτουργικό επίπεδο, μέσω αντιπροσωπευτικών σεναρίων δοκιμών, όσο και ως προς τη χρηστικότητά της\. Για την αξιολόγηση της εμπειρίας χρήσης εφαρμόστηκε η μέθοδος System Usability Scale \(SUS\)\. Τα αποτελέσματα δείχνουν ότι το προτεινόμενο σύστημα μπορεί να αποτελέσει μια λειτουργική βάση για την αυτοματοποίηση της τηλεφωνικής λήψης παραγγελιών, διατηρώντας παράλληλα τη δυνατότητα ανθρώπινου ελέγχου και παρέμβασης όπου αυτό απαιτείται\.
