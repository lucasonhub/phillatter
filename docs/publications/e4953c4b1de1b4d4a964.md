# Linear Independence of Polynomial Compositions with Bounded Input Degree

**Autores:** Xiaotian Chang; Yacoub Hendi

**Data:** 2026-10-14 · **Tipo:** preprint

## Resumo

We prove the weak composition\-independence conjectures of Kohn, Marchetti, Massarenti and Mella\. The proof uses deformations of rational curves and a single kernel of the linearized equation\. Riemann\-Roch gives a contradiction from tangent fields with controlled poles\. By settling these conjectures, we prove that a neural network with a general polynomial activation function of sufficiently large degree is identifiable\.
