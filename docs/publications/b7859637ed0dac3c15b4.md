# GeoEdgeJoin: Efficient multimodal raster\-vector joins for intelligent geospatial cloud–edge–IoT systems

**Autores:** Isam Mashhour Al Jawarneh; Luca Foschini; Paolo Bellavista

**Data:** 2026-10-09 · **Tipo:** article

## Resumo

Integrating satellite\-derived raster data \(e\.g\., NDVI\) with ground\-based vector readings \(e\.g\., air quality sensor readings\) is essential for real\-time smart city analytics\. However, existing geospatial join systems depend on computationally expensive geometric predicates and centralized processing\. They are thus considered ill\-suited for resource\-constrained edge\-cloud architectures\. We propose GeoEdgeJoin, a novel framework that integrates multi\-modal geospatial data by applying a lightweight raster\-vector join equijoin operator using Discrete Global Grid Systems \(DGGS\) such as Uber’s H3 or geohash\. The system encodes spatial data into DGGS keys \(e\.g\. Geohash or Uber’s H3\) at the edge and relies on those keys to send these data to the Cloud, which ensures co\-partitioning in the cloud and thus eliminates costly network shuffle and geometric computations\. We have evaluated our system using real\-world multi\-modal geospatial data \(i\.e\., low\-cost sensor’s air quality vector data and Landsat 8 satellite raster data\)\. Our results show that GeoEdgeJoin achieves up to 40 × faster join times than exact geometric baselines \(i\.e\., Apache Sedona, a Cloud\-only specialized geospatial big data processing system\) while maintaining robust statistical accuracy\. Furthermore, we show that Uber’s H3 encoding outperforms Geohash by 17% in latency due to uniform spatial partitioning, which helps reduce straggler tasks in distributed environments\. Our system supports both exact and error\-bounded approximate analytics by using stratified DGGS\-based sampling, to enable scalable, low\-latency environmental monitoring\. This work provides a foundational paradigm for next\-generation, edge\-native geospatial intelligence\. Our work provides a foundational paradigm for real\-time, multi\-modal geospatial analytics in complex and advanced smart city applications\.
