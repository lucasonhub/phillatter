# Machine Learning\-based Prediction of SVI Parameter in Maize: A Comparative Study and Feature Importance Analysis

**Autores:** Mustafa Turan Arslan; Gülay Zülkadir

**Data:** 2026-10-11 · **Tipo:** article

## Resumo

Background: Accurate estimation of seedling vigor indices \(SVI\) is critical for monitoring plant health and predicting yields in precision agriculture\. This study comparatively evaluates the performance of different machine learning algorithms in estimating the SVI parameter\. Methods: Germination data were collected from 39 maize genotypes under three different salinity conditions \(0 mM, 100 mM, and 200 mM NaCl\), including the parameters Gmax, MGT, GI, SL, RL, SdL, SMR, RMR, and SVI\. The dataset was preprocessed through normalization to the \[0–1\] range\. The SVI parameter was estimated using four different machine learning methods: Random Forest, CatBoost, LightGBM, and Support Vector Regression \(SVR\)\. To evaluate the performance of the models, both 10\-fold cross\-validation and 80%–20% hold\-out validation techniques were employed\. The model performance was examined using RMSE, MSE, MAE, and R² metrics\. Results: The findings show that all models have a high explanatory power in the training dataset\. Specifically, the CatBoost model showed the highest success in the training phase \(R²=0\.9962\), whereas the SVR model achieved the highest generalization performance on the test dataset \(R²=0\.9712, RMSE=0\.0582\)\. Feature importance analysis results revealed that the &\#x27;App&\#x27; parameter had the highest impact on the target variable in most models, but different structural interactions were prominent in the LightGBM model\. The results demonstrate that machine learning techniques provide high accuracy in SVI estimation and that the tendency towards overfitting is limited\. Conclusions: In conclusion, this study confirms that machine learning techniques are powerful and reliable tools for estimating spectral indices in precision agriculture applications\. The integration of SVR and ensemble\-based models into agricultural decision support systems is expected to significantly contribute to optimizing resource use and improving yield predictions\.
