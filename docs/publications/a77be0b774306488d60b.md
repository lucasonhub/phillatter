# When Goals Leak Across Relationships: How Cached Goal Representations Shape Cross\-Client Decisions

**Autores:** Saloni Gupta; Sébastien Krier; Glenn Matlin

**Data:** 2026-10-12 · **Tipo:** preprint

## Resumo

As LLM agents take on more autonomous roles, they may interact with multiple clients and counterparties whose goals and incentives conflict\. If an agent maintains shared inference state across these interactions, information associated with one relationship may influence decisions made for another\. We test OLMo\-3\-7B\-Instruct in a controlled two\-client environment with 20 market scenarios, where each client is assigned an opposing objective\. With shared conversational memory, the model deviates from the current client&\#x27;s objective in 22% of eligible decisions\. We then investigate how these goals are represented in the KV cache\. Linear probes show that client\-goal ownership becomes highly recoverable in middle layers and is concentrated in particular attention heads\. We use these results to identify where to intervene in the cache and test whether these representations affect the model&\#x27;s decisions\. Ablating the competitor&\#x27;s cached goal representations at these locations shifts the model toward the current client\. The effect is larger for heads identified by probing than for randomly selected heads, and larger when ablating goal tokens than matched non\-goal tokens from the same client\. Our results show that client\-specific goal representations persist in the KV cache and can causally influence decisions made for other clients, highlighting the importance of relationship\-specific state isolation in persistent LLM agents\.
