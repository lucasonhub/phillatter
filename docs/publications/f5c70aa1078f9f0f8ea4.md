# Применение машинного обучения для прогнозирования загрузки вычислительных ресурсов сервера

**Autores:** Кокухина Софья Александровна

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

В статье рассматривается применение методов машинного обучения для краткосрочного прогнозирования загрузки вычислительных ресурсов сервера\. На основе сформированного набора данных, содержащего сведения о загрузке центрального процессора, использовании оперативной памяти, количестве активных пользователей и процессов, сетевой и дисковой активности, разработана модель прогнозирования на основе алгоритма Random Forest Regression\. Проведена оценка точности прогнозирования загрузки центрального процессора и оперативной памяти с использованием метрик MAE, RMSE и коэффициента детерминации R2\. Полученные результаты демонстрируют возможность применения методов машинного обучения для заблаговременного обнаружения роста нагрузки и последующей автоматизации управления серверными ресурсами\.
