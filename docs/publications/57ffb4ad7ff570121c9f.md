# Not All Drift Is a Mechanism: Tracing Prompt Adaptation in LLMs

**Autores:** Mikhail Aleksandrov; Nail Bashirov; Maksim Ivanov; Andrew Tsukanov; Timofey Karyagin; Alexander Miasnikov; Gleb Molodtsov; Valentin Samokhin; Aleksandr Beznosikov

**Data:** 2026-10-13 · **Tipo:** preprint

## Resumo

Prompt\-based adaptation offers several ways to specialize a frozen language model, ranging from natural\-language prompt optimization to learned continuous prompts\. These methods are usually compared through downstream performance, although similar outputs need not arise from similar internal computations\. We study how discrete prompt optimization, prompt tuning, and prefix tuning alter the processing of dense and mixture\-of\-experts language models\. Our analysis shows that the location of the adaptation predicts how task information is carried to the output: optimized text primarily changes response construction, input\-level prompts write their influence into content representations, and layer\-wise prefixes maintain direct control through attention\. In MoE models, these differences further induce distinct expert\-routing patterns\. At the same time, common representation\-level measurements respond strongly to generic context changes and do not reliably distinguish useful adaptations from matched placebos\. We argue that understanding prompt adaptation requires separating representation drift from the part of that drift that is aligned with, and causally used by, the model&\#x27;s task computation\. This perspective provides practical guidance for selecting, evaluating, and interpreting prompt adaptation methods\.
