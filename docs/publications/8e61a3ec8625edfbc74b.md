# Model\-adaptive simulation of moment models with applications in shallow free\-surface flows and rarefied gases

**Autores:** Rik Verbiest

**Data:** 2026-10-13 · **Tipo:** dissertation

## Resumo

This section serves as an informal introduction to the method of moments as a general strategy to reduce high\-dimensional PDE models to lower\-dimensional PDE models\.A mathematically more rigorous formulation \(for the case of kinetic theory\) can be found in \[37\], for example\.The main idea of the method of moments is to represent a scalar high\-dimensional function by a set of lower\-dimensional functions\.Suppose that the function of interest f \(⃗ x,⃗ y\) ∈ F : D x × D y → R is a function of ⃗ x ∈ numerical method for hypersonic non\-equilibrium gas flows, J\.
