# Using large language models to probe the limits of atom\-centered structural descriptors

**Autores:** Michelangelo Domina; Michele Ceriotti

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

Mapping an atomic structure to a compact set of geometric descriptors is an essential step in any machine\-learning application to atomic\-scale modeling\. A powerful and widely used approach can be understood as a discretization of the histogram of pair distances, triangles, etc\., which results in a hierarchy of symmetry\-invariant atom\-centered descriptors\. Unfortunately, the lower rungs on this hierarchy \(two, three, four\-body clusters\) were found to be incomplete, with symmetry\-unrelated pairs of structures having exactly the same descriptors\. However, all the &quot;degeneracies&quot; reported so far are resolved by considering larger clusters of neighbors to build the descriptors\. We report examples of 3D structures that are indistinguishable even if one considers clusters of up to seven neighbors, and to arbitrary order when considering a practical level of discretization of the descriptors, discovered with the assistance of large language models\. The key ingredients in their construction can be traced to results that have been known for decades in different communities: the model was able to find the references and recognize their significance for the problem at hand\. We believe that this experiment exposes an extremely fruitful usage pattern for Artificial Intelligence in science: translating results between different communities and application domains, accelerating the process by which serendipitous discoveries in a field become breakthroughs in another\.
