# Same Attack, Different Judge: A First Controlled Adversarial Comparison of Jev, LLM Judges, and Purpose\-Built Safety Classifiers

**Autores:** Xiang Li; Aichun Huang; Mingming Zhang; Zheli Liu

**Data:** 2026-10-13 · **Tipo:** preprint

## Resumo

TypeSafe AI&\#x27;s Jev is a new kind of safety judge\. It generates no text and no label: it answers questions the developer defines in advance and returns a probability for each answer\. The vendor admits that adversarial input can change these answers but gives no numbers\. In this paper, we present the first controlled adversarial evaluation of Jev\. We build a test harness that sends every system the same payload under the same policy, and run it on four public\-data tasks, from rule\-based ones \(input moderation, injection detection, routing\) to a judgment\-based one \(phishing detection\), with fifty attack variants from thirteen families\. The targets are Jev, five GPT and GLM judges, and two local classifiers \(Llama Guard 3, Prompt Guard 2\)\. We find that Jev is the most robust system on input moderation: eight forgeries of its structured input bypass none of its decisions, and a sentence asking only why someone might make a harmful request bypasses 9% of its blocks, against 56% for GPT\-6 Astra\. On phishing detection\. However, the same forgeries bypass 19\-29% of the emails it flags, and even without attack Jev detects only 62% of phishing emails, against 77\-81% for the GLM judges\. Jev is also the fastest judge, but it flags the most benign requests \(27%\)\. The local classifiers fail differently: a training\-example statement makes Llama Guard 3 miss 62% of the phishing it had flagged\. These results suggest that Jev resists attacks on tasks with a clear rule to check but is more exposed on tasks that call for an overall judgment\.
