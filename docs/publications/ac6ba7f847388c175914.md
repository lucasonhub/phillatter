# Exact Discrete Spectral Invariants as a Falsification Baseline for Learned Operator

**Autores:** Michael Aksman

**Data:** 2026-10-17 · **Tipo:** article

## Resumo

We have presented a mathematically closed, comprehensive foundation for the C861 discrete spectral benchmark\. By establishing the exact rank\-two projector geometry, resolving Dirichlet sum cancellations, providing constructive proofs for linear B\-spline KAN operator reproduction, and formalizing the Lyapunov convergence of Dense Associative Memory on spherical manifolds, this framework eliminates ambiguities in evaluating learned physical operators\. Furthermore, the spectral interlacing analysis of the CN → PN structural homotopy equips the scientific machine learning community with a tool to distinguish authentic topological sensitivity from numerical discretization artifacts\.
