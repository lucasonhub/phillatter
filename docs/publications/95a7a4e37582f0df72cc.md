# Anàlisi espacial de la severitat d&\#x27;incendis forestals a la Comunitat Valenciana mitjançant teledetecció i machine learning

**Autores:** Giancarlo Gómez Lucero

**Data:** 2026-10-14 · **Tipo:** dissertation

## Resumo

\[ES\] Este trabajo analiza la interacción entre diversas variables ambientales y el daño producido por el fuego para optimizar la gestión forestal\. El objetivo principal consiste en estructurar la base de un modelo predictivo espacial orientado a evaluar la severidad de los incendios en la Comunitat Valenciana\. La metodología emplea computación en la nube mediante Google Earth Engine para el procesamiento masivo de series temporales de imágenes satelitales Sentinel\-2, extrayendo índices espectrales de severidad y estrés hídrico previos y posteriores a cada evento\. Posteriormente, a través de programación en Python, se ejecuta el cruce espacial y temporal topológico de estas métricas con Modelos Digitales de Elevaciones, cartografía de usos del suelo y registros meteorológicos históricos\. Esta convergencia paramétrica facilita el cálculo de la Humedad del Combustible Vivo \(HCV\), un indicador biofísico que constituirá un insumo para la fase predictiva con técnicas de Machine Learning\. La consolidación de esta robusta infraestructura geoespacial posee gran utilidad práctica para la protección civil y ordenación territorial, siendo clave para anticipar el comportamiento del fuego, priorizar la prevención silvícola y optimizar los recursos de extinción\.
