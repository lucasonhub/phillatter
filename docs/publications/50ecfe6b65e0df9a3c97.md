# CA\-VSN: A Context\-aware Variable Selection Network with Context\-guided Cross\-attention for Personalized Recommendation

**Autores:** Bhumika Pahwa; Indu Kashyap; Rachna Behl

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

Providing personalized recommendations, depends on two complementary sources of information, one is user&\#x27;s past interactions and the second is the context in which a new decision is made\.In practice, however, combining these two sources is not straightforward\.Many existing methods either treat contextual variables too uniformly which introduces context noise\.The context noise weakens personalization as user history is utilized without adequately accounting for the current context at hand\.To address this problem, this paper proposes CA\-VSN, a Context\-Aware Variable Selection Network for highly personalized recommendation\.The model first uses a Variable Selection Network to assign instance\-specific importance weights to contextual variables and build a refined context representation\.It then applies a Context\-Gated Cross\-Attention mechanism, where the refined context vector is used to retrieve the most relevant signals from the user&\#x27;s historical interactions\.A gating function further controls how strongly historical information should influence the prediction under the current context\.CA\-VSN is evaluated on ITM\-Rec and MovieLens\-100K for both rating prediction and Top\-K recommendation\.CA\-VSN remains competitive in both score prediction and ranking with Recall@20 = 0\.831 and NDCG@20 = 0\.460 on ITM\-Rec and Recall@20 = 0\.705 and NDCG@20 = 0\.383 on MovieLens\-100K\.Additional ablation and sensitivity analyses confirm the importance of the proposed components and the robustness of the model design\.Beyond predictive performance, CA\-VSN provides inspectable feature selection and history attention signals whose behavioural relevance is supported by perturbation, stability, and counterfactual analyses\.Refining context before modelling history offers an effective approach to personalized recommendation\.
