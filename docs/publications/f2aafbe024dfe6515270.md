# Performance Evaluation of Machine Learning Algorithms for Breast Cancer Diagnosis using Clinical Data

**Autores:** A\. Poongothai N\. Paranjothi

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

This study focuses on the application of machine learning techniques for the prediction and classification of breast cancer using clinical data obtained from primary health checkups\. The dataset consists of 300 patient records collected from the outpatient department of a private hospital, including socio\-demographic details and clinical parameters such as blood pressure, oxygen saturation, and diabetes indicators\. The methodology involves data preprocessing, feature selection, and the implementation of four machine learning algorithms, namely Naïve Bayes, Support Vector Machine \(SVM\), K\-Nearest Neighbor \(KNN\), and XGBoost\. These models were trained and tested to evaluate their performance in classifying breast cancer cases\. The results were analyzed using performance measures such as sensitivity, specificity, accuracy, True Positive Rate \(TPR\), False Negative Rate \(FNR\), and Kappa statistic\. Among the models, SVM demonstrated the highest performance with better classification accuracy and reliability, followed by KNN and Naïve Bayes, which showed moderate results\. XGBoost exhibited lower performance in comparison to other models\. The findings highlight the effectiveness of machine learning techniques in supporting early detection and diagnosis of breast cancer\. The study concludes that SVM is the most suitable model for the given dataset and can be effectively used to assist healthcare professionals in decision\-making and improving patient outcomes\.
