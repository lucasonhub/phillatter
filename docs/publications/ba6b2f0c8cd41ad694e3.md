# Quality Evaluation of Clustering\-Based Process Model Discovery Using Event Log Similarity

**Autores:** Guodan Yin; Hui Li; Cong Liu; Qinghua Zhang; Haijun Zhang

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Model discovery discovers process models from event logs, but directly discovered models are usually complex and hard to interpret\. Trace clustering tackles this problem by splitting an event log into smaller sublogs, each of which can support the discovery of simpler models\. In this setting, clustering quality means that the obtained sublogs are behaviorally coherent and sufficiently different to achieve meaningful process model discovery\. Existing evaluation depends on F\-Measure, but it is dependent on the chosen discovery algorithm, requires costly fitness and precision computation, etc\. To overcome these disadvantages, in this paper, we propose a clustering evaluation approach as a surrogate complement to model\-quality evaluation rather than an alternative to existing model\-quality measures such as fitness, precision, and F\-Measure\. Specifically, this clustering evaluation approach assesses clustering quality on the inter\-sublog event log similarity, rather than the discovered process models\. These are instantiated with three state\-of\-the\-art log\-similarity metrics\. Our experiments using four real\-life event logs show that the obtained scores are strongly negatively correlated with the F\-Measure in most of the cases and have reduced the evaluation time by a factor of 47,547 down to 63 ms\. These results indicate that the proposed framework provides an efficient and discovery\-relevant alternative for clustering evaluation in process model discovery\.
