# The memory that walks out the door: Generative AI and the knowledge depletion spiral in permacrisis

**Autores:** Geshwaree Huzooree

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

Permacrisis leaves no interval to rebuild what each crisis removes\. Experienced people leave, and the judgment that crisis response depends upon goes with them, faster than handover and succession planning can replace it\. This knowledge depletion spiral compounds when the next crisis arrives before those losses are restored\. The institutional memory model interrupts it at three points, early spiral detection, crisis\-speed knowledge capture, and memory reintegration\. Generative AI makes each component feasible at the speed permacrisis demands, under consent and data\-handling commitments\. Run as a loop, the components let each crisis add to institutional memory rather than deplete it\. Boundary conditions identify where the model applies most directly and when leaders should adapt or defer it\. Cautionary notes address the mistakes that recur in implementation\.
