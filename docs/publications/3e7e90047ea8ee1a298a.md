# A SIMPLIFIED ITERATIVE ALGORITHM WITH RELAXATION FACTOR FOR SOLVING AN ANNULAR INVERSE ELECTROCARDIOGRAPHY PROBLEM

**Autores:** Yu Shen; Xiangtuan Xiong

**Data:** 2026-10-17 · **Tipo:** article

## Resumo

This paper presents a simplified iterative algorithm with a relaxation factor for solving the Cauchy problem of Laplace equation in an annular domain, with applications to inverse electrocardiography\. Building upon the classical Kozlov\-Maz’ya iterative framework, we introduce a new simplified iteration algorithm with the relaxation factor to accelerate convergence\. Theoretical analysis and numerical experiments demonstrate that the proposed method maintains computational efficiency while significantly improving reconstruction accuracy and numerical stability\.
