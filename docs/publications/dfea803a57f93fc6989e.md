# Bloodstain Pattern Analysis Using Deep Learning and Convolutional Neural Networks for Forensic Crime Scene Reconstruction

**Autores:** Sashwath Kishore K\.; Mohameed Faaiq Dhanish; Revathi A\.

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

Bloodstain pattern analysis \(BPA\) is a critical forensic science tool for reconstructing crime scene events and understanding the dynamics of violent incidents\. Traditionally conducted through manual analysis by trained experts, this process is time\-consuming, subjective, and prone to contextual bias\. This paper presents a comprehensive deep learning frame\-work integrating convolutional neural networks \(CNN\) for auto\-mated detection, classification, and impact angle determination of bloodstain patterns\.
