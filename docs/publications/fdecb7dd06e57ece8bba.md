# Transformer\-Based Behavioral Representation Learning for Gamer Engagement Detection from User Interaction Patterns

**Autores:** Wad Ghaban

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

Automated gamer engagement detection enables the detection and classification of the level of user involvement in a gaming environment, which remains a challenging issue because of high dimensionality, heterogeneity, and complex interdependencies of behavioral data\. Conventional machine learning and deep learning models are mainly based on handcrafted features with limited ability to model complex nonlinear interactions among heterogeneous behavioral attributes\. To address these issues, this study proposes a Transformer\-based Behavior Analysis Framework for Gamer Engagement Detection \(TBAF\-GED\) model\. The proposed model first uses correlation\-based feature selection to remove redundant behavioral attributes\. An autoencoder is then applied to learn nonlinear representations from the selected features\. Finally, a Feature Tokenizer Transformer converts the selected attributes into feature\-level tokens and uses self\-attention to capture their interactions\. Moreover, the Nadam optimizer is applied to update model parameters and improve convergence stability during training\. Experimental evaluation demonstrates that the proposed TBAF\-GED framework achieves superior performance, with an accuracy of 94\.26% compared with existing approaches\. The final outcome categorizes gamer engagement levels based on game difficulty and genre as Low, Medium, and High\. The framework provides an interpretable approach to analyze engagement patterns using the available gaming behavioral attributes\. The proposed model supports game analytics by enabling proactive identification of gamer engagement levels from behavioral data\. It helps to improve game design decisions and enhances player retention through intelligent engagement analysis\.
