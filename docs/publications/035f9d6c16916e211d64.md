# SafeDiSTL: Decomposing Joint Constraints for Safe Multi\-Agent Reinforcement Learning

**Autores:** Hongrui Zheng; Aditya Singh; Rahul Mangharam

**Data:** 2026-10-09 · **Tipo:** preprint

## Resumo

Cooperative multi\-agent tasks often impose constraints on a shared objective or collective safety\. A team level violation cost function can measure this constraint outcome, but does not distinguish which agents&\#x27; actions most strongly influence that violation\. We present SafeDiSTL, a constrained multi\-agent reinforcement learning framework that allows for credit assignment even with joint constraint measurements\. We use Signal Temporal Logic \(STL\) robustness to measure episode\-level violation through running\-maximum cost increments\. Smooth full\-episode robustness and differentiable dynamics provide action sensitivities, which allocate each cost increment across agents at the same decision time\. These sensitivities account for delayed effects when weighting agents&\#x27; shares of each cost increment\. We study the framework in cooperative payload transport, connected navigation, and networked traffic control tasks\. SafeDiSTL achieves 1\.6\-5\.1x the safe\-success rate in transport, improves navigation safe\-success by 11\.1%, and delivers 50\-68% more throughput in traffic when compared to constrained baselines\. Results demonstrate a strong improvement of the learned policy in dealing with shared constraint while retaining the performance of unconstrained policies\.
