# An Embedded AI Vision System for Real\-Time Object Classification in PLC\-Based Industrial Automation

**Autores:** Van\-Khanh Nguyen; Bao\-Toan Thai; Tri\-Loc Nguyen; Minh\-Thu Nguyen; Van\-Den Ngo

**Data:** 2026-10-09 · **Tipo:** article

## Resumo

This paper presents an integrated embedded vision and edge artificial intelligence \(AI\) solution for a programmable logic controller \(PLC\) that does not officially support modules for AI applications\. The proposed method employs image processing and artificial neural network \(ANN\) training and inference directly on a cost\-effective ESP32\-P4 microcontroller, facilitating advanced perception capabilities at the edge without necessitating expensive hardware\. A PLC is used as the main controller to manage data acquisition, model development, training, making predictions, and running the system using specially designed function blocks and Modbus TCP/IP communication\. Color\-based classification of bell peppers on a conveyor belt is used as a representative application to validate the proposed system\. Visual information is encoded using hue spectra extracted from camera images, which retained relatively stable performance under the tested illumination shift\. The ANN model is first trained using a large set of images collected beforehand and then adjusted on the device with real samples taken directly from the conveyor system, using a transfer learning approach\. Experimental results demonstrate that the proposed system achieves up to 100% classification accuracy under consistent lighting conditions and maintains 94\.7% accuracy under significantly increased illumination\. Performance analysis yielded an end\-to\-end PLC–MCU transaction time of approximately 128\.85 ms, corresponding to about 7\.8 classification transactions per second under the tested configuration\. These findings demonstrate the feasibility of integrating embedded vision and on\-device learning into PLC\-based industrial automation systems\.
