# AI\-Based Cognitive Twin System for Real\-Time Behavioral Analysis and Risk Prediction in Autism Spectrum Disorder

**Autores:** Ananya S; Padmapriya KV; Gagana A; Niharika K Sheernali; Anusha U\.A\.

**Data:** 2026-10-11 · **Tipo:** article

## Resumo

NeuroTwin is an AI\-based cognitive twin system designed for behavioral analysis and risk prediction in individuals with Autism Spectrum Disorder \(ASD\)\. The system integrates Natural Language Processing \(NLP\) for text emotion analysis and response suggestions with machine learning\-based behavioral risk classification\. It provides separate modules for patients, caregivers, and therapists, supporting mood tracking, behavioral monitoring, predictive analytics, and collaborative care management\. The platform is developed using HTML, CSS, JavaScript, Node\.js, Python, and MongoDB\. This paper presents the system architecture, methodology, functional modules, and future scope of NeuroTwin\.
