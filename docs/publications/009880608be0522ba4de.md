# Analisis Sentimen Program MBG Sebelum Dan Sesudah Implementasi Pada Platform X Dan Tiktok Menggunakan SVM

**Autores:** Ismail Akbar Rosiqin; Deni Arifianto; Reni Umilasari

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Program Makan Bergizi Gratis \(MBG\) merupakan kebijakan pemerintah Indonesia untuk menanggulangi stunting melalui penyediaan asupan gizi\. Sebagai program nasional, MBG memunculkan beragam respons publik yang banyak disampaikan melalui media sosial\. Penelitian ini bertujuan menganalisis perubahan sentimen publik sebelum dan setelah implementasi MBG pada platform X dan TikTok, serta mengevaluasi kinerja metode Support Vector Machine \(SVM\)\. Data dikumpulkan melalui scraping menggunakan tagar \#MakanSiangGratis, \#MakanBergiziGratis, dan \#MBG, dengan total 4\.000 data pada masing\-masing platform untuk periode sebelum dan sesudah implementasi\. Tahapan penelitian meliputi pelabelan sentimen, preprocessing, pembobotan TF\-IDF, dan klasifikasi menggunakan SVM dengan evaluasi K\-Fold Cross Validation\. Hasil menunjukkan perbedaan pola sentimen setelah implementasi\. Pada platform X, sentimen negatif meningkat dan positif menurun, sedangkan di TikTok sentimen positif tetap dominan meskipun netral dan negatif meningkat\. Secara keseluruhan, SVM menunjukkan kinerja yang baik dan stabil dengan tingkat akurasi tinggi, serta memberikan kontribusi akademik dalam kajian analisis sentimen kebijakan publik di media sosial\.Kata kunci: Analisis Sentimen; MBG; Platform TikTok; Platform X; Support Vector Machine
