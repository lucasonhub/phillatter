# A Novel Gear Fault Diagnosis Method Based on COA\-VMD, RCMFE and SSA\-BP

**Autores:** Duowen Chen; Haoze Lv; Xinze Li; Wenjie Liang; Kailin Bai; Xin Zhao; Linlin Cao; Xiaolong Zhou

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

Aiming at the difficulties in extracting gear fault feature information and the unsatisfactory performance of commonly used machine learning classification models in terms of feature separability and stable within\-distribution recognition, this paper proposes a fault diagnosis method combining variational mode decomposition \(VMD\) optimized by the coati optimization algorithm \(COA\) and a BP neural network optimized by the sparrow search algorithm \(SSA\)\. Firstly, a composite index based on permutation entropy and mutual information entropy is adopted as the fitness function, and the COA is used to optimize the key parameters of VMD to improve the decomposition accuracy of the VMD algorithm\. Secondly, the intrinsic mode function \(IMF\) components sensitive to fault information are selected for signal reconstruction according to the time–frequency\-domain comprehensive evaluation factor algorithm, and the refined composite multiscale fuzzy entropy \(RCMFE\) is used to extract the features of the reconstructed signal to form a state feature set\. Finally, the SSA is employed to optimize the parameters of the BP model to achieve accurate diagnosis of gear working conditions and fault types\. The proposed method is verified using measured gear single and compound fault data and compared with commonly used signal decomposition methods and machine learning classification models\. The results show that the proposed method can effectively extract gear fault feature information and has the advantages of high accuracy, good feature separability and stable within\-distribution recognition\. It can achieve ideal diagnosis accuracy for both single and compound gear faults, providing a certain reference for solving such problems\.
