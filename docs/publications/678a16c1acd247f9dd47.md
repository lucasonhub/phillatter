# SmartView: A Mobile Application for Google Play Review Sentiment Analysis Using Traditional Machine Learning and BiLSTM

**Autores:** Devshree Sopan Aavhad Madhuri Sanjiv Bhadane; Kavita Rajendra Nikam; Ms\. P\. S\. Pawar Janhavi Kalpesh Jadhav

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

Mobile applications receive large volumes of user reviews that provide feedback about usability, performance, reliability, and feature expectations\. Manually examining these reviews is time\-consuming\. This paper proposes SmartView, a mobile application for analyzing publicly accessible Google Play reviews using sentiment classification and visual analytics\. The proposed workflow collects accessible reviews for a selected application, preprocesses review text, and compares traditional machine\-learning models with a Bidirectional Long Short\-Term Memory \(BiLSTM\) network\. The evaluation plan uses accuracy, precision, recall, macro\-F1 score, confusion matrices, and inference time\. A Flutter interface presents sentiment distributions and review\-level predictions\. As implementation and experiments are not yet complete, this manuscript presents the proposed method and evaluation plan; it does not claim measured model performance\.
