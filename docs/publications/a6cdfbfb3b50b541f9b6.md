# Analysis of Clustering Algorithms Using Minimum Spanning Tree with Different Threshold Values

**Autores:** Lalit Pant

**Data:** 2026-10-09 · **Tipo:** article

## Resumo

Clustering analysis is a key research area in data mining because of its many uses\. Although numerous clustering algorithms have been developed, each algorithm possesses its own strengths and limitations, and no signal algorithms perform well in real world scenarios\. Among these approaches, the Minimum Spanning Tree \(MST\)\- based clustering algorithms are widely used because of their capability to detect cluster with irregular shapes and boundaries\. In this study, the MST based clustering algorithm is analyzed using different threshold values and its performance is measured using a validity index\. Thresholds are determined using Mean, Standard Deviation \(SD\) and Mean \+ Standard Deviation \(SD\) of MST edge weights\. Clusters are formed by selecting or removing edges from the MST based on these thresholds\. The clustering performance is evaluated using a validity index \(VI\), defined as the ratio of intra\-cluster distance and inter\-cluster distance, where optimal threshold is identified by the minimum validity index\. The proposed technique is implemented on both randomly generated datasets and as well as real\-world datasets using python programming language\. Experimental results demonstrate that the Mean \+ Standard Deviation \(SD\) threshold continuously on every dataset produces optimal clustering results with minimum validity index\.
