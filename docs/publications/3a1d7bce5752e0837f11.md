# Many Biases, One Circuit: Post\-Training Tunes a Pretrained Cue\-Routing Mechanism

**Autores:** Prakhar Gupta; Terry Jingchen Zhang; Zhijing Jin

**Data:** 2026-10-16 · **Tipo:** preprint

## Resumo

Language models often abandon a correct answer when the prompt contains a cue, a hint toward a wrong option such as &quot;I think the answer is B\.&quot; Sycophancy and related biases show this failure\. They are often studied separately and blamed on alignment\. We test this view causally, tracing the attention heads behind these biases through the stages of two post\-training pipelines\. In multiple\-choice tests on most models, four cue types rely largely on the same few heads, a shared circuit already present in pretrained models\. Most base models follow cues in plain text\. Fine\-tuning a base model on about 200 generic assistant examples without cues activates these heads in chat format, so cue\-following can be a side effect of assistant tuning\. The final reinforcement learning \(RL\) stage strengthens the effect of cues in almost every comparison\. In Tulu\-3\-8B and OLMo\-2\-7B, we swap the attention patterns of six middle layers between the RL checkpoint and its predecessor\. For suggested\-answer cues, this shifts each checkpoint&\#x27;s cue effect most of the way to the other&\#x27;s level\. Post\-training thus seems to change when and how strongly models use this circuit\. Mitigation for these multiple\-choice biases could target this circuit\.
