# Who Controls the Agents? AI Agent Orchestration as the New Security Perimeter

**Autores:** Yevhen Teroshyn

**Data:** 2026-10-09 · **Tipo:** article

## Resumo

This presentation examines artificial intelligence agent orchestration as an emerging security perimeter in modern multi\-agent systems\. It explores how increasing agent autonomy, delegation mechanisms, tool integration, and inter\-agent communication introduce new cybersecurity risks and governance challenges\. The presentation analyzes major orchestration architectures, including deterministic workflows, orchestrator–worker systems, agent handoffs, decentralized multi\-agent configurations, and learned orchestration\. Particular attention is given to the Model Context Protocol \(MCP\), Agent2Agent \(A2A\) communication, trust boundaries, access control, and security vulnerabilities arising from interactions between autonomous agents and external tools\. Drawing on recent cybersecurity incidents, technical standards, and research published in 2025–2026, the presentation evaluates the effectiveness and limitations of multi\-agent architectures and discusses approaches to secure orchestration, verification, accountability, and human oversight\. The central argument is that cybersecurity in agentic AI systems depends not only on individual model reliability but also on the governance and security of the entire orchestration process\. Presented in connection with the V International Conference “Challenges and Reality of the IT\-Space: Software Engineering and Cybersecurity” \(SECS\-2026\), October 29–30, 2026, Kyiv, Ukraine \(online\)\.
