# PENERAPAN ALGORITMA DECISION TREE UNTUK SISTEM INFORMASI REKOMENDASI JURUSAN BERBASIS WEB \(STUDI KASUS SMK HENDRIKUS LEVEN\)

**Autores:** Bernadus Lado Kedang; Alfian Nara Weking; Maria Bernadete Deta

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

Accurate department selection in Vocational High Schools \(SMKs\) is important because it is related to the alignment between students’ abilities, interests, and selected areas of specialization\. Manual department placement that relies mainly on academic scores and subjective considerations may result in inconsistent recommendations\. This study aims to design and implement a web\-based department recommendation information system using the Decision Tree \(C4\.5 Simplified\) algorithm at SMK Hendrikus Leven\. The study used students’ academic scores, interests, talents, and historical department data\. A total of 60 records were used as training data to construct a decision tree using Entropy and Information Gain calculations, after which the resulting IF\-THEN rules were implemented using Laravel and MySQL\. System testing consisted of black\-box testing involving 16 functional scenarios and tree traversal testing\. All functional scenarios were successfully completed\. In the test case, the system recommended the Clinical and Community Pharmacy department with a 100% Confidence Score, consistent with the generated decision rules\. The system also provides Rule Explanation to show the basis of each recommendation\. The results indicate that Decision Tree can support a more structured and transparent department recommendation process\. Quantitative accuracy evaluation has not yet been conducted and remains for future research\.
