# ระบบแจงเหตฉกเฉนอจฉรยะสำหรบผสงอายระดบทองถน

**Autores:** Tanawat Taptimtong; Taradon Potong; Wadeenat Wannasawaskul

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

This research presented the design and development of an intelligent emergency alert system for elderly individuals at the local administrative organization level\. The objective was to develop a prototype system capable of detecting emergency events, transmitting location information, and supporting emergency response within the standard response time of 8 minutes\. The system was based on an Internet of Things \(IoT\) architecture, which connected field emergency alert devices using ESP32 and ESP8266 microcontrollers to a centralized web application through a wireless network\. The research methodology included hardware and software system design, development of a web application for emergency event reception and status management, implementation of a real\-time status display and countdown mechanism at the elderly user’s residence, and system evaluation in a simulated local administrative environment\. Experimental results demonstrated that the prototype system operated correctly according to all designed functions and supported emergency response within the standard time frame, with the fastest recorded response time of 3\.25 minutes\. The results indicated that the proposed system provided sufficient performance for local\-level emergency support applications and could serve as a practical framework for improving emergency response systems and enhancing the quality of life for elderly individuals in community settings\.
