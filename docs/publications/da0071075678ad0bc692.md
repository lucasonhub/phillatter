# Small but Mighty: Test Suites as Improvement Signals for Self\-Evolving Agents

**Autores:** Yutong Cheng; Wei Cheng; Wenchao Yu; Dawei Zhou; Haifeng Chen

**Data:** 2026-10-11 · **Tipo:** preprint

## Resumo

A self\-evolving agent rewrites its own harness and must decide which rewrites to keep, so its improvement signal is the check a rewrite has to pass\. Verifying a rewrite by agent rollout is expensive and subjective, while executable checks such as the repository&\#x27;s own tests are too sparse to catch behavior\-changing rewrites, rejecting only a quarter of them\. We instead take test feedback as the executable signal, and search for test suites that are both small and strong with a quality\-diversity evolutionary algorithm, so that the signal is dense and informative\. TeSearch treats suite size as a behavior descriptor, so that quality is pursued at every size and a small, strong suite is reachable, and learns a transition kernel during the search that denoises the LLM as an actuator on that descriptor\. Across 129 real\-world modules and three backbones, TeSearch delivers the highest\-quality suites of any method compared, LLM\-driven evolutionary search included, and the smallest of any LLM\-based one\. Used as the improvement signal of a self\-evolving agent, it rejects 59\.9% of behavior\-changing rewrites against 25\.3% for the repository&\#x27;s tests, at a 4\.0% false\-alarm rate and 3\.5 s per decision\. The code and data are available at https://github\.com/ccsnow127/TeSearch\.
