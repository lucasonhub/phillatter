# Pengembangan Sistem Akses Cerdas Berbasis RFID dan Sensor Ultrasonik untuk Kendali Gerbang Otomatis Berbasis IoT pada Perumahan Griya Wastu Kencana

**Autores:** Bembi Aradea Kardika Putra; Rudjiono Rudjiono; Setiyo Adi Nugroho

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

Vehicle access management at Griya Wastu Kencana Housing Estate is currently performed manually by security personnel, leading to inefficiencies and potential operational errors\. This study aims to develop an intelligent access control system based on RFID and ultrasonic sensors to enhance security and efficiency\. The research employs the Research and Development \(R&amp;D\) methodology, including problem identification, system design, development, validation, and testing\. The system utilizes an ESP32 microcontroller, RC522 RFID module for authenticating security cards, HC\-SR04 ultrasonic sensor to detect vehicles beneath the gate, a stepper motor for automatic gate operation, along with LEDs and a buzzer as status indicators, and the Blynk application for real\-time monitoring and remote control\. Experimental results demonstrate that the system successfully authenticates registered RFID cards, automatically opens the gate for authorized access, prevents closing while a vehicle is underneath, and allows remote monitoring and control via Blynk\. The system is deemed feasible and effective for improving vehicle access management at the estate\.
