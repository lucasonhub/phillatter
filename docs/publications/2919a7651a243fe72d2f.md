# An Explainable Federated Vision–Language Learning Framework for Privacy\-Preserving Automated Medical Report Generation Across Distributed Healthcare Institutions

**Autores:** 

**Data:** 2026-10-17 · **Tipo:** article

## Resumo

Automated generation of medical reports using AI can help speed up diagnosis and reduce doctor workload, but currently, the most efficient forms of automation use centralized training, which requires hospitals to share sensitive patient data\. This raises concerns about the privacy and regulatory issues of sharing patient information to generate reports\. In addition, clinicians have difficulty trusting AI\-assisted diagnosis because the visionlanguage models used for automated report generation are not easily interpretable\. To tackle these issues, an Explainable Federated Vision\-Language Learning Framework \(EFVLL\) has been created to generate automated medical reports that preserve patient privacy through distributed healthcare institutions\. Hospitals can use federated learning to build a collaborative global vision\-language model without having to share raw patient information\. The EFVLL framework also includes an explainable attention mechanism that will help clinicians understand how specific areas of the image and text are related to the report being generated, increasing the transparency and interpretability of automated reports\. Further, the EFVLL will improve generalization across non\-homogenous datasets and comply with data privacy and regulatory requirements\. The EFVLL framework has been validated with multiple large standard datasets \(e\.g\., RSNA\), and therefore it is suitable for implementation and use in a distributed healthcare environment\.
