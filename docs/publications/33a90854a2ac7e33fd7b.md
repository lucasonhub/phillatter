# Data from in Rod We Trust – the Evaluation of a Virtual Rod and Frame Test as a Cybersickness Screening Instrument

**Autores:** Judith Josupeit; Leonore Greim

**Data:** 2026-10-09 · **Tipo:** article

## Resumo

We present data from a virtual Rod and Frame Test \(RFT\) used to screen for cybersickness and data from a gamified spatial orientation task \(City\) used as a reference for inducing cybersickness\. Data include RFT and City performance, head tracking, self\-reported cybersickness symptoms, and system logs\. As cybersickness experiments are stressful, reusing this data reduces participant burden and supports ethical research\. The dataset enables replication, further analyses \(e\.g\., postural stability\), and joint analyses\. We further describe the open\-source code for the Virtual Reality \(VR\) applications that make the logging rationale transparent\. Moreover, this promotes efficient sampling, customizable scenarios, and methodological transparency\.
