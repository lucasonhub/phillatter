# The Bell Boundary of Shared Representations

**Autores:** Yang Wu; Hanyu Zhao; Yazhou Zhang; Yuexian Hou

**Data:** 2026-10-12 · **Tipo:** preprint

## Resumo

When does a shared representation become insufficient for jointly supporting multiple tasks? This question lies at the heart of multi\-task learning models\. Although task interference in shared representations has been widely observed, its onset, measurable form, and capacity boundary remain poorly understood\. In this paper, we revisit this problem through the lens of Bell&\#x27;s theorem\. We show that if four binary task outcomes can be jointly represented by a common shared representation, their correlations must satisfy the classical CHSH bound $\|S\|\\leq2$\. We introduce NCnet, a controlled multi\-task model for studying how representational capacity affects task compatibility\. Experiments reveal a clear capacity\-dependent transition\. Once nontrivial task fitting emerges, constrained capacity can yield $\|S\|&gt;2$\. As capacity further increases, these exceedances progressively disappear and $S$ returns to the bounded region\. This systematic pattern provides evidence that limited representational capacity is an important source of the observed incompatibility\. We observe similar transitions across CNNs, PLMs, and LLMs, suggesting that the phenomenon extends beyond the controlled NCnet setting\. We refer to this capacity\-dependent transition as the Bell Boundary, providing a measurable diagnostic for representation bottlenecks, task incompatibility, and capacity allocation in multi\-task models\.
