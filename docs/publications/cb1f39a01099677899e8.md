# PATMT2: Two\-stage domain adaptation for multilingual patent translation

**Autores:** Xiaowei Su; Xusen Cheng

**Data:** 2026-10-12 · **Tipo:** preprint

## Resumo

We present PatMT2 \(Patent Machine Translation, v2\), a two\-stage LoRA pipeline that adapts the Hy\-MT2\-7B dedicated translation model to four\-language \(Chinese/English/Japanese/Korean\) patent translation\. On six translation directions, the Stage\-2 checkpoint reaches a macro\-average BLEU of 43\.39 \(BF16\) to 43\.57 \(AWQ INT4\), improving over the Hy\-MT2\-7B base by up to \+8\.8 BLEU and also exceeding Qwen3\-32B and several external systems on the same average\. We then measure the cost of adaptation: probing 38 languages absent from the fine\-tuning data, the model still produces correct, fluent output on 34, while four low\-resource languages collapse into distinct, reproducible failure modes\. We treat these as diagnostic cases rather than retention rates, and report their mechanisms without attributing them to a single cause\. Paired bootstrap tests confirm the translation gains over all baselines \(p &lt; 0\.001\)\.
