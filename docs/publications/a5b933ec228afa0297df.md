# Multiclass Software Defect Prediction Using an Optimized LLM CodeSentinel\-BERT Based Framework

**Autores:** Vijayarajan S M\.; Ponnalagar V\.; Ravikrishnan R\.; Sarguna Gokul R\.

**Data:** 2026-10-17 · **Tipo:** article

## Resumo

The prediction of software defects is important to detect defects in source codes prior to their deployment but traditional techniques use selected features and limited binary classification\. This research work proposes DefectGuard, a transformer\-based multiclass software defect prediction system for C/C\+\+ source code that utilizes CodeBERT fine\-tuning\. This custom dataset consists of 2,000 samples of manually collected and labeled C/C\+\+ source codes and includes nine classes of defects, namely syntax, semantic, logic, linker, and runtime\-related defects\. The proposed pipeline includes preprocessing, stratified splitting, sub\-word tokenization, CodeBERT representation learning, and multiclass classification\. The experimental results show the accuracy, precision, recall, and F1\-score of 98\.8%, 96\.4%, 95\.8%, and 96\.1%, respectively, on the test set\. Additionally, ROC\-AUC and confusion\-matrix metrics are used to evaluate the class\-level discrimination\. Moreover, the proposed model is implemented in a real\-time Flask\-based web application, which can classify the source code into defect labels with confidence scores and language detection to provide the interpretation feedback\.
