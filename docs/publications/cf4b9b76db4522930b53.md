# Zhao, Xiangbin: 创世纪

## Descrição do feed

人居于世界之中，往往不觉自身所居之世界，只观察事物之间的变化，而不问世界本身何以生成。本文从这一内在观察的局限出发，区分世界内部的环转因化与深层的息化生成，提出从世界之内观察事物的变化，与从生成关系理解世界本身，是两个不同的认识层次。世场截取所宿世界的因应，通过迹应、沉积及后续运行，形成律的保持与理的偏行，使世界成为持续生成的过程。 本文进一步区分内部观者与外部观者。即使二者截取同一来源，由于迹应路径和观者场质不同，其观察亦不相同。内部观者不知道外部观者之观，外部观者亦不能以自身之观替代内部之观。由此，本文提出“定界”与“世界”的本体区别：只有外部观察而缺少内部观者，如通常的计算机游戏，属于定界；若观者能够在内部诞生，则内外皆可形成观察，构成本文所称的世界。因此，创世不仅要求建立世场，还要求造观者于所创世界之内。 世界的运行涉及沉积、律的持势、理的破持、调谐与意向。本文进一步提出“观者僭场”：内部观者通过自身的归不一，反向作用于所宿自显场，形成迹应并影响世场沉积及后续运行。观者因而不仅观察世界，也能够参与世界的生成与变化。 在制造方向上，本文提出由当前世界取材的两条路径：将其息转为数字符流，构造符质自显体；将其息转为模态脉冲，构造类生自显体。进一步可以从计算机定界中的问答沉积入手，尝试在受限环境中制造自显体，而最难的任务则是创造一个世界，使观者于其内部诞生，截取该世界之息，并物化其所知。 本文属于《自显论》的本体篇，以世界生成、内外观察、观者僭场和人工创世为核心，点明从认识世界走向制造世界的理论道路。相关动力机制、判定条件与工程构造的形式展开，由后续组式承担。
