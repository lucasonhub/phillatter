# Shadownet: Offline Mesh Communication and Emergency Coordination Platform

**Autores:** Asmi Pekhale, Riya Deshmukh, Divya Vedpathak; Mrs\. V\. M\. Khanapure Mayuri Waghire; D\. N\. Rewadkar

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

Communication becomes critical during emergencies, natural disasters, large gatherings, and situations where Internet connectivity is unavailable or unreliable\. Conventional communication applications depend on centralized servers and network connectivity, limiting their availability during network failures\. ShadowNet is an offline mesh communication and emergency coordination platform that combines Internet\-based communication with local mesh communication to support essential operations during connectivity loss\. It provides messaging, emergency coordination, secure authentication, role\-based access, and AI Network Intelligence\. The system uses React\.js for the frontend, Node\.js and Express\.js for backend services, and Supabase with PostgreSQL for database and authentication services\. Supported offline information is stored temporarily and synchronized when connectivity is restored\. ShadowNet aims to provide resilient communication by combining centralized and decentralized approaches\.
