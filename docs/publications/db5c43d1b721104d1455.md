# ANALISIS PENGARUH USER INTERFACE DAN USER EXPERIENCE TERHADAP MINAT PENGGUNAAN PORTAL BERITA HUMAS POLRI

**Autores:** Muhamad Dody Firmansyah; Ayesha Nashwa Ferya Putri; Syaeful Anas Aklani

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

Penelitian ini dilakukan untuk menganalisis pengaruh User Interface \(UI\) dan User Experience \(UX\) terhadap Minat Penggunaan Portal Berita Humas Polri serta memperdalam temuan kuantitatif melalui pendekatan kualitatif\. Penelitian menggunakan explanatory sequential mixed methods dengan data kuantitatif dari 421 responden di Kota Batam dan data kualitatif dari empat informan\. Data kuantitatif dianalisis menggunakan regresi linier berganda dan bootstrapping 5\.000 replikasi, sedangkan data kualitatif dianalisis menggunakan Reflexive Thematic Analysis\. Hasil penelitian menunjukkan bahwa UI dan UX berpengaruh positif dan signifikan terhadap Minat Penggunaan, dengan kontribusi relatif UX lebih besar dibandingkan UI\. Model menjelaskan 59,8% variasi Minat Penggunaan\. Analisis kualitatif menghasilkan empat tema yang memperjelas peran tampilan, navigasi, pengalaman penggunaan, serta kebutuhan informasi dan kredibilitas sumber\. Integrasi hasil menunjukkan bahwa temuan kuantitatif dan kualitatif saling melengkapi dalam menjelaskan penggunaan portal\.
