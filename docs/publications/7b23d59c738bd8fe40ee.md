# Enhancing House Rent Prediction Using A Stacking Ensemble Model for Sustainable Community Development

**Autores:** O\. Arowolo Abiola; Israel Taye Rotimi; Jesufunminire Emmanuel Odufewa

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

House rent estimation remains a challenge due to inconsistent pricing methods, reliance on manual valuation, and the absence of intelligent systems for determining fair rent values\. Traditional approaches used by house agents and property owners often result in price variations and inaccurate rent estimations\. This study developed a House Rent Prediction System using stack ensemble to estimate annual house rent values based on housing characteristics\. The dataset used for the study was obtained from house agents and secondary sources and was preprocessed through data cleaning, encoding, and feature scaling using StandardScaler\. The developed system was implemented using Streamlit and included functionalities such as manual prediction, property visualization, house comparison, prediction history, market analytics, and property carousel display\. Model evaluation was carried out using MAE, MSE, RMSE, R² Score, and K\-Fold Cross Validation\. The results showed that the developed system was effective in predicting house rent values and can support intelligent housing valuation and decision\-making in community development\.
