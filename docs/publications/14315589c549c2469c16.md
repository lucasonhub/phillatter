# KTUfy: Smart Academic Assistance for KTU Students

**Autores:** Jasmin K\. N\.; Mohammed Thanzeel M\. T\.; Mohammed Nasif A\. K\.; Shadan P\. K\.; Najla Musthafa; Mohammed Shamil K; Femina B\.

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

KTU students often face difficulties in organizing their studies, finding syllabus\-based materials, and preparing effectively for examinations\. Most existing learning platforms provide general content that does not fully match the KTU cur\-riculum\. To address this problem, this project presents KTUfy, a smart academic assistant designed specifically for KTU students\. KTUfy provides an intelligent chatbot that answers student queries based on the official syllabus and study materials\. The system also includes features such as automatic quiz generation, a coding practice module, and a question paper pattern analysis system to help students identify important topics for exams\. In addition, academic management tools such as a study calendar, reminders, and SGPA/CGPA calculator are included to support better planning and time management\. The system is developed using React for the frontend and Python with Fast API for backend services\. Natural Language Processing techniques and retrieval\-based models are used to improve the accuracy of answers\. The main aim of KTUfy is to improve learning efficiency, exam preparation, and overall academic support for KTU students through a single integrated platform\.
