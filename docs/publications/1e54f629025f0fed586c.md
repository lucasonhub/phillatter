# The Hasse Principle Analogy in Physics\-Informed Machine Learning: From Local Failure to Global Success via Adaptive Normalization and Multi\-Task Learning

**Autores:** MOHAMMED TAHAR SAIM

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

We investigate an analogy between the Hasse Principle from arithmetic geometry and transfer learning in physics\-informed machine learning\. Using five topological insulator models \(SSH, Haldane, Kane\-Mele, BHZ, and Weyl\), we train models on 3,000 synthetic samples and examine cross\-model transfer\. FINDINGS:\(1\) Global\-to\-Local transfer \(restriction\) outperforms Local\-to\-Global transfer \(lifting\), with F1 scores of 0\.70 vs\. 0\.62\.\(2\) An adaptive normalization scheme improves Global\-to\-Local transfer from F1 = 0\.70 to 0\.92\.\(3\) Multi\-Task Learning with a model\-type auxiliary task achieves F1 = 0\.99 across all models\. CAUTION:The connection to the Hasse Principle is HEURISTIC, not a formal mathematical equivalence\. The observed asymmetry is consistent with a statistical interpretation \(distribution shift\); its resemblance to arithmetic obstructions remains a suggestive but UNPROVEN analogy\. This work is a starting point for interdisciplinary investigation, not an established mathematical bridge\.
