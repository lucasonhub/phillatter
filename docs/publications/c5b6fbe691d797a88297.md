# GPU\-Accelerated Robust MA\-\-RIS Pre\-Optimization for Communication and Target Illumination

**Autores:** Tran Le Dung; Ho Viet Duc Luong

**Data:** 2026-10-15 · **Tipo:** preprint

## Resumo

Movable antennas \(MAs\) and reconfigurable intelligent surfaces \(RISs\) offer strong spatial control for integrated sensing and communication \(ISAC\), but repeatedly adapting MA positions and RIS phases to each channel realization can be impractical\. This letter develops a GPU\-accelerated robust pre\-optimization framework that jointly selects slow\-timescale MA geometry and RIS phases and returns a reusable Pareto set balancing expected worst\-user rate and transmit\-side worst\-target illumination\. The illumination objective measures directional transmitted power rather than complete echo\-detection or parameter\-estimation performance\. The proposed Regime\-Aware Multiobjective Pre\-optimization \(RAMP\) preserves regime\-specific Pareto populations, regulates cross\-regime mating using Pareto\-survival feedback, and constructs a worst\-regime robust archive\. Numerical results demonstrate competitive robust Pareto quality against the considered evolutionary baselines while avoiding online physical re\-optimization\.
