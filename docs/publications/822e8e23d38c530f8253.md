# Context\-Aware Network Behaviour Analyser

**Autores:** Shrey Akulwar; Prof\. Vibha D\. Gomase; Gopala Awadhi; Mohan R\. Bhandekar; Khushi Sakhare; Jagruti Patle

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Conventional network\-security tools such as firewalls and intrusion\-detection systems examine packets, ports, protocols and signatures, but they rarely capture the application, process, user and operating conditions behind a connection\. This gap makes it hard to separate legitimate activity from suspicious behaviour, especially when malicious traffic rides on commonly permitted ports or hides inside encrypted channels\. This review paper surveys existing work in traffic classification, deep packet inspection, application\-aware firewalls and machine\-learning\-based anomaly detection, and uses these findings to motivate a proposed Context\-Aware Network Behaviour Analyser\. The proposed system correlates live network flows with the originating process, the logged\-in user, the time of activity and the host&\#x27;s recent behaviour, builds behavioural baselines for applications and users, and applies statistical and machine\-learning techniques to flag meaningful deviations\. A real\-time dashboard is envisaged to present flows, process\-to\-flow associations, user activity and context\-rich alerts to support faster investigation\. The paper concludes by outlining an evaluation plan that compares the proposed analyser with a conventional rule\-based monitor on detection rate and false\-positive rate\.
