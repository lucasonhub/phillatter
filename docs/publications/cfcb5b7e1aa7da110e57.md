# Physics\-regularized deep learning for mining method selection in computational geomechanics

**Autores:** Duo Zhang; Qingtong Jin; Yu Zhang; Haining Hao; Huasheng Zhang

**Data:** 2026-10-09 · **Tipo:** article

## Resumo

Selecting an appropriate mining method for fractured “three\-soft” ore bodies, with soft ore, soft hanging wall, and soft footwall, is a safety\-critical artificial\-intelligence application in computational geomechanics\. Existing multi\-criteria decision\-making \(MCDM\) methods are limited by subjective weighting, linear additive assumptions, and weak use of numerical simulation outputs\. This study develops a Physics\-Regularized Transformer \(PRT\) artificial\-intelligence framework for underground mining method selection\. The framework integrates type\-aware tabular embedding, a physics\-regularized attention mask for Mohr\-Coulomb safety\-stress coupling, rock\-mechanics feasibility penalties in the loss function, and geomechanical features derived from Fast Lagrangian Analysis of Continua in Three Dimensions \(FLAC3D\)\. In real\-case leave\-one\-out cross\-validation, the PRT achieved 94\.7 percent accuracy \(18/19 cases; Wilson 95 percent confidence interval: 75\.4–99\.1 percent\)\. On the augmented dataset, it achieved 98\.2 percent accuracy \(bootstrap 95 percent confidence interval: 96\.3–99\.4 percent\), outperforming Unascertained Measure Theory \(UMT\) and Back\-Propagation Neural Network \(BPNN\) baselines\. Ablation analysis showed that simulation\-derived physics features contributed a 16\.1 percentage\-point cumulative accuracy gain\. Attention analysis further showed that the model captured safety\-first feature interactions that additive utility models cannot readily represent\. During an observational 18\-month field deployment, implementation of the recommended method was associated with an 80 percent productivity increase, a 12 percent cost reduction, and zero roof\-fall incidents\. These field outcomes are interpreted as associative evidence, not as causal effects attributable solely to the PRT framework\. Limited external validation showed 100 percent in\-distribution accuracy \(7/7; Wilson 95 percent confidence interval: 64\.6–100\.0 percent\), but the model failed for a single hard\-rock out\-of\-distribution case at Rock Quality Designation \(RQD\) = 78 percent\. The current operational domain is therefore bounded to three\-soft orebody conditions with RQD approximately 40–63 percent\. Deployment beyond this range requires additional site\-specific data, uncertainty assessment, and retraining\.
