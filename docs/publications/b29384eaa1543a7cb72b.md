# Identifikasi citra aksara Lota Ende menggunakan transfer learning MobileNetV2

**Autores:** NATALIA VANESSA SAILO; Kartono Pinaryanto

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

Disrupsi kecerdasan buatan \(AI\) membuka peluang bagi perguruan tinggi untuk berperan aktif melestarikan budaya lokal melalui inovasi akademik berbasis teknologi\. Aksara Lota, salah satu warisan budaya masyarakat Ende, kini semakin jarang digunakan sehingga berisiko punah\. Sebagai kontribusi riset dan pengabdian akademik, penelitian ini bertujuan mengembangkan serta mengevaluasi kinerja sistem identifikasi citra aksara Lota menggunakan metode Transfer Learning dengan arsitektur MobileNetV2\. Penelitian menggunakan metode Research and Development \(R&amp;D\) dengan dataset 480 citra huruf aksara Lota hasil digitalisasi buku dan tulisan tangan responden, yang melalui tahap preprocessing dan augmentasi sebelum pelatihan model\. Kombinasi parameter terbaik diperoleh menggunakan optimizer Adam, batch size 16, epoch 15, dan learning rate 0,001, menghasilkan validation accuracy sebesar 97,22%\. Pengujian pada data testing memperoleh accuracy 96%, precision 97%, recall 96%, dan F1\-score 96%\. Hasil User Acceptance Testing menunjukkan nilai rata\-rata 4,60 dari skala 5, mengindikasikan penerimaan pengguna yang baik terhadap sistem\. Temuan ini membuktikan bahwa MobileNetV2 efektif mengidentifikasi citra aksara Lota, sekaligus menjadi contoh konkret bagaimana inovasi AI di lingkungan akademik dapat mendukung digitalisasi dan pelestarian budaya lokal di tengah disrupsi teknologi pendidikan tinggi\.
