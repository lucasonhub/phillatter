# Automated Network Backup and Recovery Using a Safe\-Set Baseline and Hash\-Based Change Detection

**Autores:** Hamida Algoula

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

This paper is relating to PC data back up and the recovery, the techniques and systems for ordaining the data backup and recovery\. Also, this paper is implementing the distribution\. With various apps in the PC system and constant developments of Information Technology, fast increase the quantity of the data, which became a critical factor in the working life\. The research based on the understanding the importance of the network backup and restoring data to managers, clients, server level collected from the system constructions\. The program is able to manage the gathering of network data and restore and backup it automatically\. To protect against data loss the user can be saved by using backup and data recovery program\. System backup and recovery \- is a software or hardware and software system to create copies of data at regular intervals for subsequent recovery\. In addition to protection against loss of data backup systems also allow for the continuity of the work of employees to organize due to the rapid recovery of the operating system \(if its image\), or restore data on another computer\.
