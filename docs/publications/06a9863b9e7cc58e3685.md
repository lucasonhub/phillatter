# Assessment of Physical Activity, Balance, Muscle Strength, and Cognitive Function in Patients Diagnosed with Schizophrenia

**Autores:** Ebru Akbuğa Koç; İsmail Koç; Pınar BAŞTÜRK

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

Background: Physical and cognitive impairments are common in schizophrenia, but associations among physical activity, balance, handgrip strength, and cognitive function in community\-based mental health settings remain insufficiently understood\. Therefore, this study examined these associations in patients with schizophrenia receiving treatment at a Community Mental Health Center \(CMHC\)\.Methods: This exploratory cross\-sectional study included 35 outpatients diagnosed with schizophrenia by a psychiatrist according to DSM\-5 criteria\. Physical activity, balance, handgrip strength, and cognitive function were assessed\. Relationships between variables were examined using Spearman rank correlation coefficient\. An exploratory hierarchical multiple linear regression analysis was performed to identify factors independently associated with cognitive function\.Results: Physical activity was moderately correlated with cognitive function \(r = \.593, P &lt; \.001\)\. Positive correlations were also observed between physical activity and balance \(r = \.430, P = \.010\), balance and cognitive function \(r = \.478, P = \.004\), and handgrip strength and cognitive function \(r = \.421, P = \.012\)\. Regression analysis showed that physical activity \(β = \.406, P = \.017\) and handgrip strength \(β = \.364, P = \.019\) were associated with cognitive function after accounting for age and duration of illness\. The final model was statistically significant \(Adjusted R2 = \.349, P = \.003\)\.Conclusion: Physical activity and handgrip strength are potentially modifiable physical health indicators linked to cognitive function in patients with schizophrenia\.
