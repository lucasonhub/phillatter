# Definition Grounding in Theory\-Level Auto\-formalization

**Autores:** Leyan Pan; Christian Szegedy; Frederick Rajasekaran; Robi Bhattacharjee; Gregory Constantine; Wenke Lee

**Data:** 2026-10-13 · **Tipo:** preprint

## Resumo

LLM\-based auto\-formalization systems can now generate formally verified Lean code at unprecedented rates\. However, a formalization advances mathematical research only when further mathematical results can be built on it, especially when its definitions and helper lemmas are general enough to be imported and used idiomatically\. We propose definition grounding, where definition formalizations are continuously judged and revised, as a method to ensure formalization quality\. We find that agents formalizing definitions from textbook text often produce definitions that later statements cannot use, and only 25%\-50% of their definition sets are compatible with all later statements\. However, clarifying the informal definitions can improve this rate up to 77\.5% averaged over all models\. Furthermore, stating a small set of basic properties without proving them can improve model judges&\#x27; capability to detect definitions with compatibility issues, at only about 11% of the definition formalization cost\. These results are verified with ReuseBench, a benchmark we curated for formalizing new mathematical fields and theories\.
