# Hybrid Deep Feature Extraction and Ensemble Machine Learning for Potato Leaf Disease Classification in Uncontrolled Field Conditions

**Autores:** Cihan Ünal; Cengizhan Tumer; Elham Tahsin Yasin; İlkay Çınar; Murat Köklü

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

Early and accurate diagnosis of potato leaf diseases is critical for preventing yield losses under real field conditions\. This study proposes a hybrid deep feature–based machine learning framework that combines transfer learning and ensemble classifiers to automatically identify seven potato leaf disease classes from images\. A total of 4,260 images from the publicly available Potato Leaf Disease Dataset were organized into seven categories: Bacteria, Virus, Pest, Fungi, Nematode, Phytophthora, and Healthy\. Real\-time image augmentation was performed using Keras ImageDataGenerator to improve strength to field variability\. Deep feature vectors were extracted from three pre\-trained convolutional neural networks \(ResNet50, EfficientNetB0, and MobileNetV2\), each followed by a lightweight dense head, and concatenated into 768\-dimensional feature representations\. After standardization, dimensionality reduction was applied via principal component analysis, and class imbalance in the training set was addressed using the SMOTE\-ENN hybrid resampling method\. On these deep features, 32 classical machine learning and ensemble models including SVMs, tree\-based methods, boosting algorithms, multilayer perceptrons, and four ensemble schemes, were trained\. Model performance was assessed by three\-fold cross\-validation on the training set and final evaluation on the held\-out validation set using accuracy, precision, recall, and macro F1\-score\. Ensemble models outperformed individual classifiers\. The best performance was obtained with the StackingClassifier\_L2 model, which combines XGBoost, LightGBM, Random Forest, SVM with RBF kernel, and Extra Trees within a stacking framework\. This model achieved an accuracy of 81\.34% and a macro F1\-score of 81\.74% on the validation set\. The proposed hybrid system, which integrates multi\-backbone deep feature extraction with comprehensive classical and ensemble classifiers, provides a robust and practical solution for automatic potato leaf disease classification in uncontrolled field conditions\. The results suggest that stacking\-based ensembles on top of deep features can capture complex visual patterns more effectively than single models and may support decision\-making in precision agriculture\.
