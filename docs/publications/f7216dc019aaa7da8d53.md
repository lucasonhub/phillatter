# A POLYMORPHISM\-AWARE MULTIMODAL MALWARE DATASET GENERATION AND VALIDATION FRAMEWORK FOR DEEP LEARNING\-BASED DETECTION

**Autores:** Amina Fadila Shehu; Peter M\. Ogedebe

**Data:** 2026-10-09 · **Tipo:** article

## Resumo

Polymorphic malware detection is challenged by malicious executables that can alter their observable representation while preserving their underlying behaviour\. Although public malware datasets have advanced learning\-based malware research, many were not designed to represent controlled polymorphic transformation across structural, behavioural, instruction\-level, and spatial feature spaces\. This paper therefore presents a polymorphism\-aware multimodal malware dataset generation and validation framework whose primary contribution is the controlled construction and empirical validation of a traceable dataset for downstream deep learning research, rather than the proposal of a new detector\. The framework uses a family\-based construction strategy to generate related polymorphic variants while preserving parent–child lineage\. A controlled transformation engine applies API\-level, opcode\-level, and structural transformations, including API noise injection, API reordering, instruction substitution, dead\-code insertion, control\-flow obfuscation, packing, payload encoding, section padding, import\-table variation, and timestamp randomisation\. Each sample is represented through four synchronised modalities: structured metadata features, API\-call sequences, opcode sequences, and grayscale binary\-image representations\. The resulting balanced dataset contains 20,000 samples, comprising 10,000 polymorphic and 10,000 non\-polymorphic samples, obtained from an initial generation process involving 2,500 malware family profiles and 27,510 total generated samples\. The 10,000 polymorphic samples retained for the balanced dataset were selected using the fixed\-seed sampling procedure implemented during dataset construction, after which family\-aware partitioning was applied to reduce lineage leakage\. Exploratory and statistical analyses assessed class balance, entropy and file\-size distributions, API and opcode sequence\-length distributions, transformation diversity, structural and behavioural indicator prevalence, feature correlation, feature\-level separation, and binary\-image structure\. The validation evidence indicates that the dataset is balanced, traceable, transformation\-diverse, and statistically characterised, with overlapping distributions for several structural and sequence\-level indicators\. These findings support its use as a controlled research resource for evaluating deep learning models under known polymorphic transformation conditions, while not establishing that the generated samples reproduce the full realism of real\-world malware ecosystems\. Due to the security\-sensitive nature of malware binaries, reproducibility is supported through derived feature representations, transformation metadata, validation procedures, and controlled\-access sharing rather than unrestricted distribution of executable samples\.
