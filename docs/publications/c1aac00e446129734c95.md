# Predicting Cross\-Country Waste Recycling Performance Using Regression and Explainable Machine Learning

**Autores:** Mehmet Çevık

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

Recycling is central to sustainable waste management and the circular economy, yet performance varies substantially across countries\. This study examines economic and waste\-related factors associated with municipal recycling performance and evaluates whether machine learning \(ML\) models improve prediction relative to conventional statistical modelling\. The analysis included 84 countries with populations of at least one million using World Bank What a Waste 3\.0 data\. Municipal recycling rate was modelled using GDP per capita, municipal solid waste \(MSW\) generation per capita, and food, plastic, and paper and cardboard waste shares\. Multiple linear regression \(MLR\) was compared with Random Forest \(RF\), XGBoost, and Support Vector Regression \(SVR\) using nested repeated five\-fold cross\-validation, while SHapley Additive exPlanations \(SHAP\) were used to interpret the best\-performing ML model\. ln\(GDP per capita\) was the only statistically significant independent predictor in MLR and the dominant RF predictor, accounting for 47\.67% of global SHAP importance\. Food waste \(18\.95%\), paper and cardboard \(14\.71%\), and MSW generation \(14\.69%\) also contributed meaningfully, whereas plastic waste showed limited importance \(3\.98%\)\. RF achieved the strongest predictive performance \(R2=0\.312\), outperforming MLR \(R2=0\.229\), while XGBoost showed a modest improvement \(R2=0\.263\) and SVR did not \(R2=0\.215\)\. Income\-stratified SHAP analysis showed that GDP remained dominant across income groups, while waste\-related importance varied\. These findings demonstrate the value of explainable ML as a complement to conventional statistical modelling\.
