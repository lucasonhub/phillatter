# Packet\-Level In\-Network Semantic Adaptation for Unstable Mobile Emergency Networks

**Autores:** Zhiyuan Ren; Tao Zhang; Wenchi Cheng

**Data:** 2026-10-11 · **Tipo:** article

## Resumo

Mobile emergency networks can experience independently changing intermediate wireless links on timescales shorter than endpoint feedback can track\. When an egress changes after packet emission, feedback affects only later source data, while the on\-path node observes the current condition with the affected packet still mutable\. This paper presents DINA, a packet\-level in\-network semantic adaptation method\. An image is divided into self\-describing spatial packets carrying coordinates, a current representation identifier, and payload\. At each eligible node, a packet\-local policy chooses among compatible operators\. Our evaluated implementation uses an offline\-trained frozen selector\. The node immediately transforms the packet and forwards it without image reconstruction or cross\-packet adaptation state\. Later nodes can retain or further compact the packet through the same typed compatibility contract\. The receiver places available packets by coordinate, fills missing regions with black, and runs a fixed machine task\. We realize DINA in a 24\-node unmanned aerial vehicle \(UAV\) environment using eXpress Data Path \(XDP\) and AF\_XDP user\-space sockets\. In the primary forest\-fire trace, 80\-image paired runs raise deadline coverage from 40\.5% to 72\.3% and observed accuracy from 82\.5% to 92\.5% relative to forwarding\. In an independently trained RescueNet segmentation case, coverage rises from 66\.2% to 92\.0% and foreground mean intersection over union \(mIoU\) from 0\.474 to 0\.535\. Sufficient\-capacity profiles reach full delivery; extreme profiles reveal task\-dependent limits\.
