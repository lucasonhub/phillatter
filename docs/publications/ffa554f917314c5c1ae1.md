# Pengembangan Sistem Informasi Monitoring Lembaga Kemahasiswaan Universitas Stella Maris Sumba Berbasis Web Menggunakan Framework Laravel dan Database MySQL

**Autores:** Rikardassara Swasti Bili; Herman Huki Ratu; Paulus Mikku Ate

**Data:** 2026-10-09 · **Tipo:** article

## Resumo

The management of student organizations in higher education requires accurate, accessible, and traceable information to support activity planning, administration, monitoring, and reporting\. At Universitas Stella Maris Sumba, organizational information and activity administration can be consolidated through a web\-based monitoring information system so that relevant stakeholders can access current data according to their roles\. This study aims to design and develop a web\-based student organization monitoring information system using the Laravel framework and MySQL database\. The research uses a systems development approach consisting of system requirements analysis, UML\-based system design, implementation, and functional and usability testing\. System analysis is conducted using the PIECES framework to identify problems in performance, information, economy, control, efficiency, and service\. System design employs use case, activity, sequence, class, and entity\-relationship models, while the Waterfall model is used as the development method\. Laravel is used to implement the application using an MVC architecture and MySQL is used for structured data management\. The proposed system provides role\-based access to organization data, administrators, activity programs, proposals, accountability reports, monitoring status, and reporting\. The empirical testing values, including the number of test scenarios and usability score, should be inserted from the actual test results before publication\. The study is expected to support more structured, transparent, and traceable management of student organization activities at Universitas Stella Maris Sumba\.
