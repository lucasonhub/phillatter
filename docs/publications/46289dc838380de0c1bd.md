# Palla, Christian Mattias: Syntaxens fängelse? Det kinesiska rummet, dagens AI och gränserna för vad vi kan utesluta

**Autores:** 

**Data de descoberta:** 2026-10-16 · **Tipo:** unknown

## Descrição do feed

Denna essä undersöker räckvidden hos John Searles argument om det kinesiska rummet i ljuset av tränade neurala nätverk och stora språkmodeller\. Huvudtesen är att argumentet inte ensamt motiverar ett generellt uteslutande av artificiell förståelse och att bedömningar av fenomenellt medvetande kräver ytterligare argument\. Searle avser att visa att programinstansiering inte i sig räcker för förståelse, men lämnar öppet att andra fysiska system kan ha intentionalitet om de besitter relevanta kausala förmågor\. Essän prövar därför vilka ytterligare premisser som behövs för att gå från denna otillräcklighet till ett negativt omdöme om ett bestämt system\. Studier av interna representationer och förslag om referentiell förankring preciserar vad som kan undersökas, men deras betydelse för förståelse måste motiveras separat\. På motsvarande sätt måste evidens för en mekanisms kausala roll skiljas från argument för dess betydelse för fenomenell upplevelse\. Teoriberoende indikatorer kan bidra till välgrundade bedömningar utan att därmed vara allmänna nödvändiga villkor för medvetande\. Att både tillskrivningar och uteslutningar behöver motiveras innebär inte att deras evidensläge är likvärdigt\.
