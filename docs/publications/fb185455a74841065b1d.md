# Sistema de gestió i monitorització d&\#x27;inventari mitjançant IoT i intel·ligència artificial

**Autores:** Alejandro Ferrer Fernández

**Data:** 2026-10-15 · **Tipo:** dissertation

## Resumo

\[ES\] Este TFM trata sobre la creación de un sistema de gestión y monitorización de inventario utilizando sensores IoT con cámaras y un modelo de reconocimiento de imágenes impulsado por IA\. El objetivo de este sistema es identificar los productos independientemente de su marca y realizar un seguimiento continuo de su estado, con el objetivo de ofrecer una trazabilidad completa de todos los productos presentes e integrarse con otros dispositivos IoT para gestionar los productos de forma eficiente\.
