# Cloud Computing: Security, Resource Optimization, and Algorithm Evaluation

**Autores:** Nidia Jael Muñoz Oviedo

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Cloud computing is a key component of modern digital infrastructure; however, its adoption faces challenges related to operational efficiency and security\. This systematic review analyzes the convergence of data protection, resource optimization, and algorithm evaluation in distributed environments\. Methodologically, it examines metrics and approaches used to validate algorithmic performance and ensure efficient service delivery\. The findings highlight the effectiveness of metaheuristic and hybrid algorithms for task scheduling, as well as virtual machine consolidation techniques that improve hardware utilization and reduce energy consumption\. Persistent risks are also identified, such as DDoS attacks and vulnerabilities in multi\-tenant architectures, for which solutions based on blockchain, federated learning, and homomorphic encryption are emerging\. This synthesis provides a classification of adaptive strategies to enhance security and efficiency in cloud computing, serving as a reference for the development of more resilient, transparent, and sustainable ecosystems\.
