# Model Sistem Pendukung Keputusan Berbasis Web untuk Penentuan Siswa Berprestasi pada Sekolah Dasar Katolik Wikico Kawango

**Autores:** Melkianus Mone; Herman Huki Ratu; Mitra Permata Ayu

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

Selecting high\-achieving elementary school students is a multi\-criteria decision problem because academic performance alone does not fully represent student achievement\. This study proposes a web\-based Decision Support System \(DSS\) to identify outstanding students at Sekolah Dasar Katolik Wikico Kawango using the Simple Additive Weighting \(SAW\) method\. The research design combines system analysis, object\-oriented system design using Unified Modeling Language \(UML\), Waterfall\-based development, and black\-box functional testing\. SAW is applied through criteria identification, criterion weighting, decision matrix construction, normalization by benefit and cost attributes, and calculation of the preference value for each student\. The proposed model is intended to make the selection process more structured, transparent, reproducible, and easier to document than a purely manual process\. Because the source materials supplied for this drafting stage do not include the school&\#x27;s actual student dataset, criterion weights, or testing records, the numerical ranking results in this manuscript are presented as a validation\-ready model, not as empirical findings\. The resulting manuscript therefore provides a complete methodological and reporting structure that can be populated with verified school data before submission\.
