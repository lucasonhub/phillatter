# Beyond the End\-Effector: Learning Whole\-Arm Contact Manipulation from Human Demonstrations

**Autores:** Bo\-Ruei Huang; Daniel Seita; Erdem Bıyık

**Data:** 2026-10-13 · **Tipo:** preprint

## Resumo

Robot manipulation has traditionally relied on end\-effector\-centric interactions\. In contrast, humans routinely exploit whole\-arm contacts to improve efficiency, robustness, and adaptability, especially when the hands are occupied or when precise grasping is unnecessary\. Enabling similar capabilities in robots remains challenging: the robot must select where on its arm to make contact, generate effective non\-prehensile interactions, and satisfy task\-specific pose or safety constraints on the end\-effector\. We propose Whole\-Arm Contact Learning \(WACL\), a hierarchical framework that describes each whole\-arm contact task with three robot\-agnostic representations and hands them to a quasi\-static surface\-contact optimizer: semantic keypoints that summarize the scene, a reference contact trajectory that specifies where and how the arm presses on the object, and safety\-aware path constraints that a vision\-language model generates from the task description to protect the end\-effector&\#x27;s task\. The robot&\#x27;s kinematic chain enters only in this optimizer, which grounds these representations onto the arm by jointly searching over which link makes contact, where on that link, and the joint configuration that realizes it\. This decomposition lets WACL learn the contact trajectory from 10 bare\-hand human demonstrations per task collected without teleoperation, while new end\-effector constraints change only the optimizer&\#x27;s input rather than any trained component\. Real\-world experiments on a 7\-DoF arm across four whole\-arm tasks show that WACL sustains contact under end\-effector constraints where a strong link\-pose baseline fails \(78% vs\. 33% success\) and generalizes to new constraints without retraining\.
