# Reproducible Learning Artifacts for AI\-Enabled Science

**Autores:** Mikhail Titov

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

As artificial intelligence and data\-driven methods become integral to scientific workflows, practical computational training is increasingly important\. Hands\-on tutorials and notebooks are key mechanisms for transferring complex methods into practice, yet they depend on rapidly evolving combinations of scientific libraries, machine\-learning frameworks, specialized hardware, and external data\. When this operational context is implicit or distributed across multiple configuration files and workflows, instructional content and execution environments can diverge, creating environment\-content drift that reduces reproducibility and increases maintenance effort\. We propose Reproducible Learning Artifacts \(RLAs\) as a model in which educational content, dependencies, runtime requirements, external assets, and validation expectations are represented through a unified, machine\-readable specification\. RLAs address three complementary dimensions of reproducibility: content reproducibility, ensuring required code and assets are available; environment reproducibility, ensuring the intended runtime can be reconstructed; and behavioral reproducibility, ensuring the artifact continues to execute as intended\. As a proof of concept, we demonstrate this paradigm through Tutorial\-SDK, an open\-source framework that operationalizes RLAs using declarative manifests and automated continuous\-integration workflows\. From a unified artifact description, the framework can derive containerized execution environments, resolve dependencies, perform notebook\- and dependency\-aware checks, and validate execution within the resulting runtime\. This approach shifts reproducibility from a one\-time packaging task to a continuously verifiable property of computational training materials\. RLAs provide a foundation for more portable, maintainable, and reusable educational resources, supporting sustainable knowledge transfer for AI\-enabled science across evolving computing environments and institutions\.
