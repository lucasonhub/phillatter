# Optimizing the Privacy Accuracy Trade\-off in Data Stream Mining Using Random Cycle Cumulative Noise Addition

**Autores:** Anita A\. Parmar; Chirag A\. Patel

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

Data stream mining has become increasingly important as a result of the continuous generation of data in real world applications including healthcare monitoring, sensor networks, transportation systems and online services\. While stream classification techniques provide strong predictive performance, publishing or processing such streams raises serious privacy concerns\. Perturbation based privacy preserving data stream mining \(PPDSM\) methods address this issue by adding noise to the data before it is analyzed\. Cumulative noise addition accumulates noise across a fixed\-size cycle of records give a favourable privacy–accuracy trade\-off compared with independent noise addition\. However, a fixed cycle size introduces a predictable and periodic structure in the perturbation process\. This paper proposes Random\-Cycle Cumulative Noise Addition \(RC\-CNA\), a perturbation mechanism that adds noise to random cycle sizes instead of fix\-cycle size\. RC\-CNA is evaluated against the fixedcycle model\. The proposed method raises classification accuracy, lowers privacy breach probability, and achieves the overall Privacy–Accuracy trade\-off\. Proposed method indicates that randomizing the cycle size, combined with the modulation, is a practical improvement that simultaneously strengthens privacy protection and improves classification utility\.
