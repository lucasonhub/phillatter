# Howell, Robert J\.: The Ontology of Subjective Physicalism

**Autores:** 

**Data de descoberta:** 2026-10-16 · **Tipo:** unknown

## Descrição do feed

In Consciousness and the Limits of Objectivity: The Case for Subjective Physicalism\. Oxford: Oxford University Press\. pp\. 101\-122\. 2013This chapter closely examines two anti\-materialist arguments and argues that their metaphysical presuppositions are substantive and should be rejected\. The first argument considered is the “Presentation Argument” which is often attributed to Max Black\. The author argues that in fact this argument only works if one assumes an intentionalist view of properties, which should be rejected as it is likely to generate an incoherent ontology\. The second argument considered is the conceivability argument, most recently advanced by Chalmers\. It is argued that this argument presupposes an intentionalist picture of possible worlds which ties modality too closely to concepts\. It is argued that again this produces an incoherence, which can be seen using Chalmers’ own two\-dimensional semantics\. The physicalist, it is argued, can duck these arguments by adopting a strictly extensionalist way of individuating possible worlds and properties\.
