# Reproducibility package for: Prediction of Concrete Compressive Strength Using Machine Learning: A Mixture\-Grouped Comparison of Random Forest, XGBoost, Hybrid, and Stacking Models

**Autores:** Salman A\. Alshamrani

**Data:** 2026-10-16 · **Tipo:** book

## Resumo

Reproducibility package for the manuscript &quot;Prediction of Concrete Compressive Strength Using Machine Learning: A Mixture\-Grouped Comparison of Random Forest, XGBoost, Hybrid, and Stacking Models&quot; \(Materials Today Communications, MTCOMM\-D\-26\-06673\)\. It contains the public UCI Concrete Compressive Strength data \(Yeh, 1998; doi:10\.24432/C5PK67\), six Python scripts that reproduce every table and figure, the mixture\-group and train/test assignment of every observation, selected hyperparameters, ensemble weights, held\-out predictions, bootstrap, nested cross\-validation and repeated\-partition results, and the software versions used\. See README\.txt for the run order\. No new experimental data were collected\.
