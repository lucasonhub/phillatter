# 微短剧\+VR赋能《思修》理想信念教育的机理与模式研究

**Autores:** 明翰 江; 志颖 李; 旋羽 赵

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

当前高校《思想道德与法治》课程理想信念教育面临“知而不信、信而不行”的现实困境，其深层原因在于传统教学模式难以遵循理想信念内化的“认知—情感—意志—行为”全链条心理规律。微短剧能够通过叙事传输机制引发深度情感共鸣，VR技术能够通过具身认知机制锤炼意志品质，二者的有机融合并非简单叠加，而是以理想信念内化规律为指导，实现“情感预热—沉浸体验—行为转化”的闭环联动。本文基于马克思主义认识论、叙事传输理论与具身认知理论，系统阐释了“微短剧\+VR”协同赋能的内在机理，构建了“课前情感预热—课中沉浸体验—课后实践转化”的沉浸式育人模式，并通过案例应用加以验证。研究表明，技术赋能思政教育的核心在于服务理想信念内化规律，必须坚持价值引领、强化教师主导、警惕技术至上主义，方能实现从“知识传递”到“灵魂塑造”的根本转变。
