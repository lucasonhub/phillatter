# 数字时代的媒体变革与人工智能:中国的实践与探索

**Autores:** 蒋习

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

当今世界,人工智能正以前所未有的速度重塑经济社会的运行方式。从新闻生产到城市治理,从科学研究到日常生活,AI的触角正在延伸至每一个角落。作为全球人工智能领域的重要参与者,中国近年来在这一领域进行了系统性的战略布局和持续性的资源投入。与此同时,在共建“一带一路”的框架下,中国与包括乌兹别克斯坦在内的中亚国家在数字技术和人工智能领域的合作也在不断深化。中国国家主席习近平在比什凯克出席2026年上海合作组织峰会期间会见乌兹别克斯坦总统米尔济约耶夫,习近平强调,无论国际形势如何变化,中方致力于深化中乌友好的立场不会动摇,将一如既往支持乌方走符合自身国情的发展道路。双方要携手努力,做好两国合作大文章。要高质量推进中吉乌铁路建设,拓展人工智能、荒漠化治理等合作,坚持互利共赢。米尔济约耶夫表示,乌方对中国式现代化的光明前景充满信心。乌中两国有着深厚友谊,始终相互理解、相互支持
