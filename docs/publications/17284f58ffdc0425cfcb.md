# Adaptive Hybrid Learning for Real\-Time Bitcoin Price Prediction with Comparative Model Selection

**Autores:** Sai Vedikaa R\.; Siva Srinidhi V\.; Keerthika Rupa A\.; Srilekha K\.; Yuvashree P\.; Sree Rathna Lakshmi N\.V\. S\.

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

This study presents a real\-time Bitcoin price forecasting framework that integrates Long Short\-Term Memory \(LSTM\), Improved Sequential Temporal Modeling \(ISTM\), gradient boosting, and Flask\-based deployment\. The experimental dataset comprises 744 hourly BTC/USDT Spot Kline observations obtained from the Binance Public Data Repository, including Open, High, Low, Close, and Volume \(OHLCV\) variables\. A set of technical indicators and temporal features, including moving averages, exponential moving averages, Relative Strength Index \(RSI\), volatility measures, and lagged variables, was derived from the historical price series\. Following Min\-Max normalization, the dataset was chronologically divided into 595 training observations and 149 testing observations using an 80:20 split without shuffling to preserve the temporal structure of the data\. Six forecasting approaches such as Linear Regression, Random Forest, LSTM, ISTM, LSTM with Boosting, and ISTM with Boosting\. Among the evaluated models, the ISTM \+ Boosting framework demonstrated strong predictive performance, achieving an MAE of 72\.5, MSE of 19,860, RMSE of 140\.9, and R² of 0\.97\.
