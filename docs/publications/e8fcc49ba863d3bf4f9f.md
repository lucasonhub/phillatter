# Prepoznavanje kretenj znakovnega jezika z uporabo strojnega učenja in računalniškega vida

**Autores:** Matevž Kavčič

**Data:** 2026-10-09 · **Tipo:** dissertation

## Resumo

Izvleček: V zaključni nalogi je predstavljen sistem za prepoznavanje kretenj slovenskega znakovnega jezika z uporabo metod globokega učenja\.V prvem delu so predstavljeni postopki pridobivanja podatkov in ekstrakcije značilk rok, telesa in obraza z uporabo ogrodja MediaPipe ter uporaba embeddingov in nevronske mreže tipa Siamese\.V drugem delu je predstavljena implementacija sistema za prepoznavanje kretenj na podlagi prostora \.Sistem je ovrednoten z različnimi načini testiranja, pri čemer je analizirano prepoznavanje znanih in neznanih kretenj, ter delovanje sistema na novih videoposnetkih\.V zaključku so podane morebitne izboljšave in predlogi\.Kavčič M\. Prepoznavanje kretenj znakovnega jezika z uporabo strojnega učenja in računalniškega vida Univerza na Primorskem, Fakulteta za matematiko, naravoslovje in informacijske tehnologije, 2026
