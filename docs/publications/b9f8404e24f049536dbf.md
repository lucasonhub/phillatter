# Learning from Self\-Generated Responses: Reliability\-\-Uncertainty Self\-Distillation for Reasoning

**Autores:** Jinhao Pan; Bowen Wei; Yuqing Zhou; Ziwei Zhu

**Data:** 2026-10-13 · **Tipo:** preprint

## Resumo

Reference solutions and question\-specific rubrics are not always available to guide the teacher in self\-distillation\. A large language model&\#x27;s own solution attempts offer an alternative, but their quality is difficult to assess in open\-ended tasks without automatic correctness checks, and even correct attempts can involve uncertain token predictions\. We propose Reliability\-\-Uncertainty Self\-Distillation \(\\method\{\}\) to learn from these attempts\. The same model serves as teacher and student: the teacher receives the question and completed attempt, and the student matches the teacher&\#x27;s token\-level predictions using a question\-only prompt\. \\method\{\} weights each attempt&\#x27;s distillation loss by additively combining judged reliability, estimated from a self\-judge&\#x27;s score and confidence, with student predictive uncertainty\. Across eleven reasoning benchmarks, \\method\{\} outperforms all five baselines in average accuracy, reaching 70\.47\\% on Qwen3\-4B and 76\.69\\% on Qwen3\-8B \(8\.90 and 2\.10 percentage points above the base models\)\. Data and code are available at https://github\.com/JP\-25/RUSD\.
