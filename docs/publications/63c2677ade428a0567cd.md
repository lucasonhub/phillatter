# Feature analysis for malware detection

**Autores:** Αγγελική Μποϊλέ

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

Η παρούσα διπλωματική εργασία σχετίζεται με την ανάλυση χαρακτηριστικών για αναγνώριση κακόβουλου λογισμικού χρησιμοποιώντας μεθόδους μηχανικής μάθησης\. Στόχος είναι να αξιολογηθεί ένα νέο σετ δεδομένων, να γίνει σύγκριση της απόδοσης ανάμεσα στους διαφορετικούς τύπους αρχείων που περιλαμβάνει, καθώς επίσης και να ελεγχθεί κατά πόσο τα νέα χαρακτηριστικά που περιέχει το συγκεκριμένο dataset μπορούν να ανιχνεύσουν το κακόβουλο λογισμικό\. Αρχικά πραγματοποιήθηκε διαχωρισμός των δεδομένων σε υποσύνολα για να γίνει γρηγορότερα η εκπαίδευση\. Στη συνέχεια έγινε η μετατροπή τους σε διανυσματική μορφή και επιλέχθηκαν τυχαία δείγματα ώστε να ξεκινήσει η εκπαίδευση με τεχνικές μηχανικής μάθησης\. Ο αλγόριθμος που χρησιμοποιήθηκε ήταν ο Random Forest, ο οποίος γενικά παρουσιάζει υψηλά αποτελέσματα όσον αφορά την αναγνώριση malware\. Κατά τη διάρκεια των πειραμάτων, δόθηκε σημασία στην απόδοση και τον χρόνο εκπαίδευσης όλων τωνχαρακτηριστικών και ιδιαίτερα στα νέα χαρακτηριστικά που έχουν προστεθεί στην τελευταία έκδοση του dataset\. Οι μετρικές που αναλύθηκαν ήταν, μεταξύ άλλων, η απόδοση \(accuracy\), το recall, το F1\-score και το ROC AUC και πράγματι παρατηρήθηκε ότι τα νέα χαρακτηριστικά αποδίδουν καλύτερα και μπορούν να αναγνωρίσουν το κακόβουλο λογισμικό\.
