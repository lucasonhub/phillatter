# Predicting Cognitive Tasks from Single\-Channel EEG through Task\-Semantic Alignment

**Autores:** Ryota Kanai

**Data:** 2026-10-10 · **Tipo:** preprint

## Resumo

Studies of data scaling in electroencephalography \(EEG\) and related noninvasive recordings suggest that simple wearable devices could eventually reveal more about cognitive states\. However, publicly available EEG data are difficult to combine\. Different laboratories record different tasks, participants, and devices\. Task\-agnostic self\-supervised learning can exploit such data, but representations learned only with EEG signals have not consistently produced feature representations that are directly effective for decoding the cognitive state\. We therefore aimed to incorporate task information by embedding experimental instructions, stimuli and response demands in a common semantic space, and trained an EEG encoder to align signals from a single anterior\-\-posterior differential channel with those task vectors\. This framework supports zero\-shot prediction without target\-condition calibration and few\-shot prediction using labeled samples\. On a reserved ten\-class evaluation, the highest observed zero\-shot balanced accuracy was 30\.13% \(chance 10%\)\. In a separate developmental few\-shot experiment, balanced accuracy reached 34\.47% using 16 labeled EEG examples per class from another participant, and 74\.99% using examples from the test participant&\#x27;s own task recording\. Our experiments suggest that training models on datasets with multiple tasks per participant appeared useful, whereas adding datasets containing only one or a few tasks sometimes reduced established performance despite broader task coverage\. These exploratory results suggest that EEG datasets that repeat varied cognitive tasks and everyday activities within the same individuals across days, devices and independent studies would be particularly useful for training an EEG foundation model for predicting cognitive states\.
