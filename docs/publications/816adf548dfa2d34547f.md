# The Gradient That Top\-k Distillation Never Computes

**Autores:** Rasul Khanbayov; Hasan Kurban

**Data:** 2026-10-11 · **Tipo:** preprint

## Resumo

Many deployed distillation pipelines show the student a truncated view of the teacher: keep the top\-k probabilities, renormalize, and minimize a divergence on what remains\. Renormalization is assumed to account for the missing mass\. We prove that it removes the visibility of tail mass, not the freedom to move it\. The renormalized objective depends only on log\-odds among the retained tokens, so at each position its gradient along the directions that control tail mass is exactly zero; on a real teacher that component measures $2$\-$3\\times10^\{\-15\}$ of the gradient\. The full\-vocabulary gradient equals the truncated gradient plus a residual weighted by the tail masses, and training acts only on the first term\. Without the cross\-entropy term, a top\-k student&\#x27;s tail mass drifts away from the teacher&\#x27;s while a full\-vocabulary control moves slightly toward it; with it, the gap shrinks about fourfold but persists\. On seven open\-weight teachers, the retained set determines the teacher&\#x27;s distribution only from $k=d\+1$ \($d$ the hidden dimension\): recovery is exact from there on all seven, and commonly cached sizes sit below it\. In our off\-policy runs the practical effect is real but smaller than the choice of teacher\-student pair\. Renormalization is a normalization, not a safeguard\. The code is available at https://github\.com/KurbanIntelligenceLab/top\-k\-distillation\.
