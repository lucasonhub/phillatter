# Оптимизација питања за квизове уз помоћ вештачке интелигенције

**Autores:** Milos Josipovic

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

This paper presents a web application for creating and taking quizzes that integrates artificial intelligence into the educational process\. Particular emphasis is placed on the automatic generation of quiz questions using AI, significantly accelerating and simplifying the quiz preparation process\. In addition, several AI\-powered functionalities have been implemented with the aim of enhancing the teaching and learning experience, improving educational outcomes, and increasing the efficiency of both teachers and students\.
