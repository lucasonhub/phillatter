# Real\-Time Probabilistic Nowcasting of Lightning Density via a Sequential Monte Carlo Framework

**Autores:** Vlad Landa; Yuval Reuveni; Yoav Yair; Chaim Lerman; Colin Price

**Data:** 2026-10-09 · **Tipo:** article

## Resumo

Abstract This study presents a particle filter–based framework for short\-term lightning now\-casting using only lightning detection network observations\. The method employs DBSCAN clustering to identify lightning\-active structures and propagates them probabilistically, yielding useful skill at one\- to three\-hour lead times, with declining but non\-zero skill at four to six hours\. The results show that Recall is more robust than precision across increasing lead times, and that performance is sensitive to the ground truth density threshold selection\. Despite these limitations, the suggested approach achieves skill scores comparable to more data\-intensive machine learning and NWP\-based methods, while requiring minimal input data\. Importantly, the algorithm can be implemented as a real\-time Python application, demonstrating both its scientific value and practical applicability in data\-constrained environments\.
