# Learning to See through Action: Predictive Curiosity for Robots

**Autores:** Stelios Zarifis; Panagiotis Filntisis; George Retsinas; Petros Maragos

**Data:** 2026-10-09 · **Tipo:** preprint

## Resumo

Humans and animals do not learn vision from a fixed set of data: they move, interact, and learn from the visual consequences of their actions\. Motivated by this developmental view, we study whether robots can improve visual learning by actively collecting experience through curiosity\-driven interaction\. We introduce DySCOVER, a self\-supervised framework for active robot visual learning\. A robot observes RGB frames, learns a visual autoencoder that encodes and reconstructs them, and trains a recurrent world model to predict the next visual latent state conditioned on the current state and action\. The agent&\#x27;s policy is trained only with intrinsic rewards: reconstruction error encourages visually novel observations, while the world model&\#x27;s error encourages transitions whose consequences are not yet predictable\. This prediction error biases the policy toward more intricate trajectories that enrich the agent&\#x27;s set of experiences with observations beyond those encouraged by visual novelty alone\. Our experiments conducted with robotic arms as the embodied agents show that adding predictive curiosity improves the vision model over using visual curiosity alone\. Across variations in initial conditions, experience capacity, embodiment, and scene content, adding predictive curiosity consistently improved visual learning\. These results show that predictive curiosity can improve active visual learning beyond reconstruction\-based curiosity alone\.
