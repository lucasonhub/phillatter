# Design of an EEG signal processing\-based assistive support system for Autism Spectrum Disorder

**Autores:** Yuze Gao

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

Autism Spectrum Disorder \(ASD\) is a neurodevelopmental condition that affects social communication, behavior, attention, emotional regulation, and sensory processing\. To provide continuous physiological information beyond behavioral observation, this study designs an Electroencephalography \(EEG\)\-based assistive system using a TGAM single\-channel EEG module, an Arduino board, and an HC\-05 Bluetooth module\. The system focuses on detecting Theta\-band activity in an individual to determine if support is needed\. In an initial test, the average Theta amplitude increased from 52\.9375 μV in the relaxed state to 73\.2673 μV in the anxious state, giving a rise of about 38\.4%\. Repeated relaxed\-state measurements suggested an average value of 54\.58 μV, so 60 μV was selected as a preliminary threshold for state detection\. The system can acquire, process, transmit, and evaluate EEG data and trigger feedback when the threshold is exceeded\. Although the sample and test conditions are limited, the results show the potential of Theta\-based real\-time monitoring for supportive intervention\.
