# Validity of AI\-Generated Assessment Tools in English Language Teaching: A Framework and Research Design

**Autores:** Kdirbayeva Dildora

**Data:** 2026-10-09 · **Tipo:** article

## Resumo

English teachers can now use generative artificial intelligence to build interactive assessment tools without programming knowledge\. Such tools score learner work and report results, which makes them assessment instruments, but no one validates them\. This paper sets out a five\-part validity chain for these tools and describes the study designed to test it\. The study has not yet been carried out and no findings are reported\.
