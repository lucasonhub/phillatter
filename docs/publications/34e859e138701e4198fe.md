# Using Machine learning To Predict Resource Demand in Smart Cities

**Autores:** SAMI YASER ALI OTHMAN QASEM

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

Smart cities rely on efficient resource management to support urban sustainability and meet theneeds of growing populations\. Predicting future resource demand can help city planners makeinformed decisions about infrastructure and resource allocation\. Previous studies haveinvestigated machine learning methods for forecasting electricity consumption and waterdemand\. For example, Pesantez et al\. \(2020\) used smart meter data to develop and evaluatemachine learning models for hourly water demand forecasting\. Building on this research, thisproposal aims to investigate how machine learning can be used to predict electricity and waterdemand in smart cities\. The proposed methodology will involve analyzing historicalconsumption data, identifying relevant influencing factors, and comparing selected predictivemodels using appropriate evaluation metrics\. The study is expected to provide insights into thepotential benefits and limitations of machine learning for resource demand forecasting and itspossible role in supporting more effective urban resource planning\.
