# TransCRC\-XAI: Source Code and Jupyter Notebook for Colorectal Cancer Molecular Stratification and Biomarker Discovery

**Autores:** Waleed Mahmoud Ead

**Data:** 2026-10-18 · **Tipo:** book

## Resumo

This repository provides the Python implementation and Jupyter notebook associated with TransCRC\-XAI, an explainable machine learning framework developed for patient\-specific transcriptomic analysis, molecular stratification, and biomarker discovery in colorectal cancer \(CRC\)\. The framework integrates paired tumor normal gene expression analysis, patient\-specific differential expression, a Transition Stability Score \(TSS\), dimensionality reduction, molecular transition phenotype \(MTP\) discovery, and explainable machine learning to investigate heterogeneous molecular alterations associated with colorectal cancer\. The computational workflow includes data preprocessing, paired expression\-difference construction, stability\-based feature assessment, molecular phenotype identification, predictive modeling, and SHAP\-based feature interpretation\. The framework also incorporates a Patient Molecular Transition Score \(PMTS\) and pathway\-level analysis to support the biological interpretation of patient\-specific molecular alterations\. The research workflow is designed around two publicly accessible transcriptomic datasets: GSE44076: Discovery dataset containing matched colorectal tumor and adjacent\-normal expression profiles\. GSE39582: Independent external dataset intended for evaluating the generalizability of selected transcriptomic signatures\. The repository is intended to support methodological transparency, reproducibility, and further research in explainable artificial intelligence, computational oncology, precision medicine, and transcriptomic biomarker discovery\. Keywords: Colorectal Cancer; TransCRC\-XAI; Explainable Artificial Intelligence; Transcriptomics; Biomarker Discovery; Molecular Stratification; Patient\-Specific Analysis; SHAP; Machine Learning; Precision Oncology\.
