# Osteoporosis Risk Prediction in Type 2 Diabetes: An Interpretable Machine Learning Model \(v1\.0\.0\)

**Autores:** mwc16547

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Code repository and archived materials for the online risk calculator accompanying the study &quot;Interpretable Machine Learning for Identifying Prevalent Osteoporosis in Type 2 Diabetes Using Clinical and Body Composition Parameters&quot;\. The calculator estimates the risk of prevalent osteoporosis in patients with type 2 diabetes from eight clinical and body\-composition variables\. The application is provided for research use only and is not intended for clinical decision\-making\.
