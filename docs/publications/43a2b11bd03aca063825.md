# SISTEM INFORMASI PROFILE PERPUSTAKAAN SMA NEGERI 7 SIJUNJUNG BERBASIS WEB

**Autores:** Resmi Zulfarik; Faiza Rini; Rahayu Trisetyowati Untari

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

Abstract: This research aims to develop a Web\-Based Library Profile Information System for SMA Negeri 7 Sijunjung to facilitate the dissemination and access of library information\. The research used the Research and Development \(R&amp;D\) method with the Rapid Application Development \(RAD\) model\. The system was developed using Laravel 12 and MySQL\. Testing was conducted using White Box, Black Box, expert validation, and user testing\. The Black Box testing results showed that all system functions were valid, while testing by 3 experts obtained an average score of 91\.00% and testing by 20 users obtained 90\.75%, both categorized as very good\. These results indicate that the system is feasible to use as a digital library information medium\. Keywords: Information System, Library, Website, Laravel, RAD Abstrak: Penelitian ini bertujuan merancang Sistem Informasi Profil Perpustakaan SMA Negeri 7 Sijunjung Berbasis Web untuk mempermudah penyebaran dan akses informasi perpustakaan\. Penelitian menggunakan metode Research and Development \(R&amp;D\) dengan model Rapid Application Development \(RAD\)\. Sistem dikembangkan menggunakan Laravel 12 dan MySQL\. Pengujian dilakukan menggunakan White Box, Black Box, tenaga ahli, dan pengguna\. Hasil pengujian Black Box menunjukkan seluruh fungsi sistem valid, sedangkan pengujian 3 tenaga ahli memperoleh rata\-rata 91,00% dan 20 pengguna memperoleh rata\-rata 90,75%, keduanya berkategori sangat baik\. Hasil tersebut menunjukkan bahwa sistem layak digunakan sebagai media informasi digital perpustakaan\. Kata Kunci: Sistem Informasi, Perpustakaan, Website, Laravel, RAD
