# APPLICATION OF MACHINE LEARNING ALGORITHMS IN INTELLIGENT ANALYSIS OF LARGE\-SCALE DATA

**Autores:** Abdullayeva Dilfuzaxon

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

The rapid expansion of digital information has increased the need for analytical methods capable of extracting reliable knowledge from large\-scale, heterogeneous and continuously changing datasets\. This thesis critically examines the application of supervised, unsupervised and deep learning algorithms to intelligent big data analysis\. Particular attention is given to Random Forest, XGBoost, clustering and neural models, together with distributed processing, data quality, computational efficiency and model interpretability\. Based on established research, a methodological framework is proposed for selecting and evaluating algorithms under realistic data and resource constraints\. The discussion is theoretical and does not present unverified experimental improvements\.
