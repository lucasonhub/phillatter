# de Paiva, Gilberto: A UNIVERSE OF CONSCIOUS MECHANISTIC PATTERNS

**Autores:** 

**Data de descoberta:** 2026-10-16 · **Tipo:** unknown

## Descrição do feed

This work explores some philosophical and scientific discussions on the concept of pattern recognition, proposing it to be a physical and cognitive first principle in the epistemological and ontological sense\. It is based on the key proposal that all physical properties were discovered by pattern recognition experiments\. It then proposes discussions, definitions and models to some unclear philosophy of mind concepts like consciousness and panpsychism\. A two level modular integration model to define and describe the concept of a mechanistic consciousness is also proposed with the pattern recognition concept\. \(direct link \)
