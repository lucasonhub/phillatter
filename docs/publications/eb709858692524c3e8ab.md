# Analisis Sentimen Ulasan Pengguna Aplikasi DSW \(Depok Single Window\) Di Google Play Store Menggunakan Algoritma K\-Means

**Autores:** Aris Pramuja; Nanda Anggraini Maulana; Sherliani Putri; Ade Fitria Lestari

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Depok Single Window \(DSW\) is an integrated public service application developed by the Depok City Government, yet public awareness of it remains low, and thousands of user reviews on the Google Play Store still reveal technical issues such as login difficulties, slow loading, non\-real\-time notifications, and online registration failures\. These unstructured reviews make it difficult for administrators to quickly and accurately identify recurring problem patterns\. This study aims to implement the K\-Means Clustering algorithm to perform sentiment analysis and topic grouping of user reviews, and to identify complaint patterns for measurable technical improvement recommendations\. The method applied includes collecting 1\.190 review data, text preprocessing, term weighting using TF\-IDF, determining the optimal number of clusters using the Elbow Method and Silhouette Score, and clustering with K\-Means\. The results show that the optimal number of clusters is three \(k=3\)\. Cluster 0 represents positive reviews containing user appreciation, Cluster 1 contains neutral or informative reviews on general service usage, while Cluster 2 is dominated by technical complaints such as online registration failures, login difficulties, and CCTV access problems, with the lowest average rating\. These findings are expected to help developers and the Depok City Government improve digital public service quality\.
