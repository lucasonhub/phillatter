# Enhancing Image Tampering Detection Using ResNet50 with Error Level Analysis and Gamma Correction

**Autores:** Hanief Widya Wardhana; Riza Arifudin

**Data:** 2026-10-09 · **Tipo:** article

## Resumo

Image manipulation has become increasingly sophisticated, making the verification of visual authenticity a critical challenge for preventing misinformation, fraud, and other malicious activities\. Conventional detection methods often fail to capture subtle traces of tampering, motivating the use of deep learning combined with targeted preprocessing\. This study proposes a detection approach that couples the ResNet50 architecture with two complementary preprocessing techniques—Error Level Analysis \(ELA\) and gamma correction—to sharpen the features associated with tampered regions\. ELA exposes discrepancies in JPEG compression levels, while gamma correction enhances the contrast between authentic and manipulated areas; combining them yields a more discriminative feature space than either technique alone\. On the CASIA 2\.0 dataset \(12,614 images\), the model attains 82\.60% accuracy without preprocessing, 95\.16% with ELA, and 78\.74% with gamma correction alone\. Applying both techniques together produces the highest accuracy of 97\.58%, a 14\.98 percentage\-point improvement over the baseline, because ELA isolates compression\-level traces of tampering while gamma correction sharpens the contrast that makes those traces separable\. These results demonstrate that carefully selected preprocessing significantly strengthens ResNet50\-based image tampering detection\.
