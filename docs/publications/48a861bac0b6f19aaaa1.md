# Implementasi Sistem Informasi Pendaftaran dan Upload Hasil Karya Event Terpadu pada Bee Creative Event Organizer

**Autores:** Nur Hidayah; Nugroho Adhi Santoso; Bayu Aji Santoso

**Data:** 2026-10-17 · **Tipo:** article

## Resumo

This research focuses on developing and implementing an integrated, web\-based information system for event registration and submission of entries at Bee Creative Event Organizer, serving as an alternative to the previous manual process that relied on WhatsApp\. The system was developed using the waterfall approach, encompassing the stages of requirements analysis, design, implementation, testing, and maintenance\. It was built using the PHP programming language with the Laravel 10 framework and a MySQL database\. Four user roles are defined within the system: the public \(with limited access to view event information\); participants \(who can register, upload entries, and monitor registration status via a participant dashboard\); administrators \(with full access to manage event data, registrations, winners, the gallery, and homepage content\); and management \(who can view event revenue charts\)\. The system also features a Chatbot and WhatsApp integration to facilitate communication with participants\. This research contributes by integrating event registration and entry management processes, which had previously not been combined into a single system, while also supporting both online and offline events on one unified platform\. The results demonstrate that the system successfully integrates event registration, entry submissions, and participant management into a unified platform\. Black\-box testing conducted on 107 test cases across four primary roles yielded a 100% success rate, indicating that the system is highly reliable\. The system simplifies the process for participants to register and upload entries directly via the Website while enabling administrators to manage data in a structured and efficient manner\.
