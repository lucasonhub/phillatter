# Performance Evaluation of a Random Forest Classifier for Unauthorized user Detection in Decentralized Network Environments

**Autores:** I\.I\. Achi; F\.O\. Ogbunude

**Data:** 2026-10-11 · **Tipo:** article

## Resumo

Unauthorised access constitutes a primary security threat in decentralised networks, where the absence of a single control point multiplies attack surfaces and complicates timely detection\. This paper presents a rigorous performance evaluation of a Random Forest classifier engineered to distinguish authorised from unauthorised network activity on the basis of five readily extractable traffic features: packet rate, bandwidth usage, latency, failed login attempts and connection duration\. An Isolation Forest component operates in parallel as an unsupervised anomaly detector, supplying coverage for previously unseen \(zero\-day\) behavioural patterns\. Experiments conducted on labelled network traffic yield an accuracy of 96\.80%, precision of 95\.40%, recall of 94\.20% and F1\-score of 94\.80%\. By comparison, a conventional signature\-based intrusion detection baseline attains only 82\.40%, 80\.10%, 78\.60% and 79\.30% on the same metrics\. The associated confusion matrix reveals low false\-positive and falsenegative counts \(18 and 14, respectively, on a balanced test set of approximately one thousand samples\)\. These results establish Random Forest as a practical, interpretable and computationally efficient solution for real\-time unauthoriseduser classification in resource\-constrained decentralised settings, while Isolation Forest further strengthens resilience against novel attacks\.
