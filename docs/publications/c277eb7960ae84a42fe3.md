# Neural simulation\-based inference for unbinned EFT constraints in dileptonic top quark pair production

**Autores:** CMS Collaboration

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

Analyses at the LHC perform statistical inference based on histograms of physics\-motivated or machine\-learned observables\. This leads to suboptimal precision when compared to using the full high\-dimensional, per\-event information\. Neural simulation\-based inference \(NSBI\) methods overcome this limitation, using machine learning algorithms to estimate the per\-event quantities that are used for unbinned statistical inference from a high\-dimensional set of observables\. This note presents the methods explored by CMS for an unbinned NSBI measurement of 9 effective field theory operators in dileptonic top quark pair production including a representative set of nuisance parameters\. Two approaches are explored for the parameter of interest and nuisance parameter estimators, based on boosted decision tree and neural network techniques\. Several estimator performance plots are presented, indicating proper estimator calibration\.
