# Scalable Sparse Autoregressive Variational Inference for Non\-Gaussian Spatial Fields

**Autores:** Paul F\. V\. Wiemann; Matthias Katzfuss

**Data:** 2026-10-09 · **Tipo:** preprint

## Resumo

Latent field models are essential for spatial statistics, but the posterior distribution of the latent field, even with a Gaussian process \(GP\) prior, is analytically intractable whenever the likelihood is non\-Gaussian\. Existing approximations are either too slow or too restrictive for large non\-Gaussian datasets\. We present a scalable variational inference framework that mirrors the sparse nearest\-neighbor autoregressive structure of the prior in the variational family, uses normalizing\-flow conditionals for expressiveness, and amortizes all variational parameters via a single shared neural conditioner\. Doubly stochastic optimization with reduced ancestor sets achieves polylogarithmic complexity per iteration\.
