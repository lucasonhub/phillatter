# Effect of Spherical Parameter Space on Number of Non\-Forgetting Tasks and Capacity of Continual Learning

**Autores:** Nazanin Mirhosseini

**Data:** 2026-10-12 · **Tipo:** preprint

## Resumo

We propose a continuous learning formulation for $T$ non\-forgetting tasks with the spherical parameter space $\\mathbb\{S\}^\{d\-1\}\(\\sqrt\{d\}\)$ in asymptotic regime $d\\rightarrow \\infty$\. Each task $i$ has an optimum $\\bmΘ\_i$, minimizing its corresponding loss function $R\_i\(\\bm\{w\}\)$ on sphere\. We reduce each task $i$ to an acceptable loss region modeled by a geodesic ball $B\_\{\\bmΘ\_i\}\(r\_i\(d\)\)$ on $\\mathbb\{S\}^\{d\-1\}\(\\sqrt\{d\}\)$ centered at $\\bmΘ\_i$ with radius $r\_i\(d\)$\. To model task dependencies \(similarities\), task optima $\\bmΘ\_i$ are distributed by a Neyman\-Scott clustered point process $Φ$\. Cluster centers $\\\{\\bm\{Y\}\_j\\\}\_\{j=1\}^\{N\_p\}$ form a homogeneous Poisson point process on sphere, while intra\-cluster task optima follow a von Mises\-Fisher distribution with mean $\\bm\{Y\}\_j$ and concentration $κ$\. Each task $t\\in \\\{1, \.\.\., T\\\}$ learning algorithm is considered to be a channel $Q\_\{t\}\(\\mathrm\{d\}\\bm\{w\}\_t \| \\bm\{w\}\_\{t\-1\}, \\mathcal\{K\}\_\{t\-1\}\(\\bmθ\_\{1:t\-1\}\), \\bmθ\_t\)$, where $\\bm\{W\}\_t$ is the learned parameter of task $t$ and $\\mathcal\{K\}\_\{t\-1\}\(\\bmΘ\_\{1:t\-1\}\)=\\bigcap\_\{i=1\}^\{t\-1\}B\_\{\\bmΘ\_i\}\(r\_i\(d\)\)$\. Since in continual learning, the learner does not need to reach $\\bmΘ\_t$ exactly to successfully learn task $t$, to avoid forgetting as well as reliable learning, it only needs for the learned parameter vector $\\bm\{W\}\_\{t\}$ to enter $B\_\{\\bmΘ\_t\}\(r\_t\(d\)\) \\cap \\mathcal\{K\}\_\{t\-1\}\(\\bmΘ\_\{1:t\-1\}\)$\. Using this model, we derive an upper bound on $T$ ensuring $\\mathbb\{P\}\[\\mathcal\{K\}\_\{T\}\(\\bmΘ\_\{1:T\}\) \\neq \\emptyset\] \\rightarrow 1$ as $d\\rightarrow \\infty$ and $κ/d \\rightarrow α$, where $α&gt;0$ is a constant\. Finally, for $T$ tasks sampled uniformly from $Φ$, we derive an upper bound for total information theoretic capacity under the non\-forgetting constraint for each task\.
