# Defenses contra prompt injection en agents LLM: avaluació sistemàtica i anàlisi mecanicista de modes de fallada

**Autores:** Daniel Poncelas Vargas

**Data:** 2026-10-14 · **Tipo:** dissertation

## Resumo

\[EN\] Agents based on large language models \(LLMs\) with access to external tools have become the standard architecture for production artificial intelligence systems\. Their exposure to external content makes them vulnerable to prompt injection: the insertion of malicious instructions into data that the agent processes\. This exposure has been identified by the Open Web Application Security Project \(OWASP\) as the main security risk for LLM applications\. Although recent literature proposes numerous defenses, these methods are evaluated under heterogeneous conditions that prevent rigorous comparison\. This Master&\#x27;s Thesis addresses this gap through a systematic and reproducible evaluation of eight representative state\-of\-the\-art defenses \(Spotlighting, StruQ, SecAlign, PromptGuard, paraphrasing, sandwich, reminder and baseline\), which are applied to models covering both commercial and open\-source systems of different sizes\. The experimental protocol is built on the AgentDojo and InjecAgent benchmarks, applying utility, robustness and refusal metrics in the evaluation, supported by statistical tests\. The work is complemented by a mechanistic interpretability study, which applies techniques such as activation patching and logit lens, in order to characterize which internal components of the model are causally responsible for the failure of the defenses\.
