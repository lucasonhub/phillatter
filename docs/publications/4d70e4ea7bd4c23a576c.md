# A note on methods: Leveraging machine learning in media discourse analysis in European Studies

**Autores:** Mathew Doidge; Dimitrii Ustinov

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

This research note addresses the utilisation of digital methodologies in research on Germany–Pacific Island engagement\. Specifically, it covers the utilisation of machine learning leveraging natural language processing in discursive media analysis as a means of overcoming the capacity limitations inherent in traditional manually implemented methodologies\. The note outlines the methods used, and the challenges encountered, with the intent to assist other researchers in utilising this methodology for their own research\.
