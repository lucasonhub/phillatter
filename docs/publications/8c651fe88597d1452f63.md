# A Novel Framework for Content Classification Process of Online Newspaper Images Using Deep Learning Algorithm

**Autores:** S\. Saravanan; A\.K Ashfauk Ahamed

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

This paper develops an image processing\-based system in order to verify the contents in each online newspaper\. The newspaper contains many sub articles under various headings\. Each sub articles in the newspaper may corresponds to various social activities such as Crime, Education, Sports, Politics, Entertainment and Culture\. In this work, a newspaper word classification system has been proposed using Deep Learning architecture\. This proposed system consists of a preprocessing section, Deep Learning \(DL\) Architectural module and a data retrieval algorithm\. The preprocessing section is used in this work to convert the spatial image into frequency translational image by Gabor transform, and further, Optical Character Recognition \(OCR\) has been used to transform this frequency translational image into words\. The segmented words in the newspaper image are fed into the proposed DL architecture to obtain the classification results\. These classification results have been used to find the Euclidean distances with respect to the databases in order to identify the content of the newspaper image\.
