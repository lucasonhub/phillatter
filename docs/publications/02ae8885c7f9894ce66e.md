  SNSFL folder is compiled on every push, and no file is listed by hand. Four pieces
  make that hold. The file "lean-toolchain" is set to leanprover/lean4:v4.31.0, so
  every build uses the same Lean. The file "lakefile.lean" requires Mathlib at tag
  v4.31.0, and the default target is the Lean library SNSFL with a glob over every
  submodule in that folder, so Mathlib is pinned to the matching tag and every file
  in the folder is a build target. The GitHub workflow ".github/workflows/lean.yml"
  runs "lake exe cache get" and then "lake build": each push downloads prebuilt Mathlib
  and compiles every file. File convention: one self-contained module per file; files
  do not import each other, so shared names such as "SOVEREIGN_ANCHOR" and "torsion"
  never collide across files. Anyone can reproduce the result with two commands after
  cloning: "lake exe cache get" and "lake build". The build log prints one "Built
  SNSFL.filename" line per file, so coverage is visible in the log itself. On the
  reference runs, a full CI pass takes 2 to 3 minutes. About 1 minute 50 seconds of
  that is the Mathlib download; the files themselves take 3 to 5 seconds each, and
  the Total Consistency file 28 to 37 seconds. 4. TOOLCHAIN ALIGNMENT. Each file is
  aligned to the pinned toolchain by a fixed set of changes, each following a change
  in Lean or Mathlib between releases. None changes a theorem statement. Code generation
  for real numbers: definitions using real division and equality must be marked non-executable,
  aligned by a "noncomputable section" after the imports. Global decidability instance
  removed from Mathlib: an equality test on an inductive needs decidable equality,
  aligned by "deriving DecidableEq" on the inductive. "unfold" no longer closes goals
  by reflexivity: a definition unfolded to x = x leaves the goal open, aligned by
  "rfl" after a terminal unfold, or "ring" where the sides differ only by commutativity.
  Order lemmas renamed: earlier names are no longer present; the v4.31.0 names used
  are "lt_div_iff₀", "div_le_iff₀", "le_div_iff₀", "div_lt_iff₀", "div_lt_div_iff₀",
  and "le_or_gt". Mathlib modules reorganized: "Mathlib.Data.Nat.Parity" is no longer
  present; the import is replaced by one present in v4.31.0. Changed simp sets and
  tactic scope: "simp" and "positivity" close or leave different goals than before;
  alignment uses explicit steps, "rw [if_neg h]", "sub_ne_zero.mpr", "div_pos", "mul_pos".
  "push_neg" deprecated: replaced by "push Not". Before each push, every lemma name
  and every import in the file is checked against the Mathlib v4.31.0 source (8,169
  files). Lean then reports any remaining item by line. 5. RESULTS. All 105 files
