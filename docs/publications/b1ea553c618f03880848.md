# Perbandingan Algoritma Yamamoto’s Recursive Code Dan Lzw Untuk Kompresi File Video

**Autores:** Khairani Resty Harahap; Firahmy Rizky

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

Ukuran file video digital yang besar menimbulkan kebutuhan akan metode kompresi lossless yang andal untuk menghemat ruang penyimpanan tanpa mengurangi kualitas data\. Penelitian ini bertujuan mengimplementasikan dan membandingkan kinerja dua algoritma kompresi lossless, yaitu Yamamoto&\#x27;s Recursive Code \(YRC\) dan LZW \(Lempel\-Ziv\-Welch\), dalam sistem kompresi video berbasis web bernama VidCompress yang dibangun menggunakan Python dengan framework Flask\. Pengujian dilakukan terhadap 6 sesi kompresi yang mencakup 5 file video MP4/H\.264 unik dengan variasi ukuran 0,94–6,20 MB, dengan satu file diuji dua kali sebagai replikasi, menghasilkan 12 data kompresi yang diukur berdasarkan Ratio of Compression \(RC\), Compression Ratio \(CR\), Space Saving \(SS\), dan waktu proses, serta divalidasi melalui pengujian dekompresi langsung terhadap seluruh berkas hasil kompresi\. Hasil penelitian menunjukkan bahwa Algoritma YRC secara konsisten memperbesar ukuran file pada seluruh 6 sesi \(rata\-rata SS −47,18%\), namun seluruh hasil dekompresinya \(6/6\) tervalidasi identik dengan file asli\. Algoritma LZW hanya berhasil mengompresi 3 dari 6 sesi \(rata\-rata SS −2,24%\), dan seluruh hasil dekompresinya \(6/6\) dinyatakan tidak valid akibat keterbatasan implementasi lebar bit kode kamus yang dibatasi 16 bit tanpa mekanisme reset\. Keunggulan kedua algoritma bersifat bersyarat: LZW unggul pada rasio kompresi namun belum andal, sedangkan YRC andal namun tidak efisien pada data video MP4/H\.264 yang telah terkompresi oleh codec\. Perbaikan mekanisme lebar bit LZW direkomendasikan untuk penelitian selanjutnya\.
