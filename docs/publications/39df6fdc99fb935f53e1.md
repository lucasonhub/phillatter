# Density\-Matrix Reinforcement Learning

**Autores:** Chiuman Ho

**Data:** 2026-10-12 · **Tipo:** preprint

## Resumo

What information does a reinforcement learning policy omit? At each state, a standard policy stores one probability per action\. It has no place to record how actions relate to each other, such as which pairs go together and which conflict\. We ask when this missing structure matters, and we give exact answers\. We store the policy at each state as a density matrix, a positive semidefinite, unit\-trace matrix borrowed from quantum information theory\. We use it here as a purely classical data structure, computed on ordinary classical hardware\. The diagonal holds the usual action probabilities\. The off\-diagonal entries, called coherences, are new parameters\. This gives density\-matrix reinforcement learning \(DMRL\)\. Coherences change outcomes in two settings\. First, suppose a policy is regularized toward a coherent reference policy using matrix relative entropy\. The optimum then has coherences that no diagonal reference policy produces, and its action probabilities can depend on the reference policy&\#x27;s coherences\. This is relevant to fine\-tuning of large language models \(LLMs\) with a Kullback\-\-Leibler penalty\. Second, suppose the agent chooses a unit\-vector action and the reward is a quadratic function of that vector\. This could arise when an LLM judge scores a weighted consolidation of reasoning paths, or when coupled robotic sensors each respond to a mix of actions\. Then some coherent policies earn strictly more expected reward than every classical policy with the same action probabilities, and we give the margin in closed form\. In a two\-action example, both policies assign probability $0\.5$ to each action, yet the classical one earns expected reward $0$ while the coherent one earns $1$, the maximum\. Outside these two settings, DMRL matches or transfers the classical results\. This is a theory paper\. All results are proved, and we report no empirical evaluation\.
