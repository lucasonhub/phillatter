# Plataforma web inteligente para visualización interactiva, análisis predictivo y prescriptivo de datos públicos del Ecuador: diseño e implementación de arquitectura Lakehouse, pipelines ELT robustos y diseño backend basado en microservicios\.

**Autores:** J\.J\.\(José Joel\) Defaz Analuisa

**Data:** 2026-10-13 · **Tipo:** dissertation

## Resumo

El crecimiento acelerado y desarticulado de las fuentes de datos gubernamentales del Ecuador ha generado fragmentación, silos de información y dificultades de integración entre instituciones, limitando el acceso oportuno a información pública sobre dominios socioeconómicos estratégicos\. El objetivo fue diseñar e implementar una arquitectura Lakehouse y un ecosistema backend basado en microservicios para la gestión de datos públicos del Ecuador \(Población, PIB, Pobreza, Empleo y Seguridad\), asegurando la extracción, el procesamiento y la exposición eficiente de la información mediante pipelines ELT y despliegues contenerizados de alta disponibilidad\. Se empleó un enfoque ágil anidado \(Scrum, Vertical Slicing y CRISP\-DM\) sobre una arquitectura estructurada bajo el paradigma Medallion, con pipelines ELT orquestados mediante Apache Airflow y un backend en FastAPI bajo el patrón Backend for Frontend con DomainDriven Design\. Como resultado se obtuvieron cuatro modelos dimensionales como lo son de Población, el PIB, Pobreza junto a Empleo y Seguridad, más de treinta DAGs de ingesta y transformación, y un backend con más de setenta endpoints RESTful desplegado en Azure Container Apps, con coberturas de pruebas automatizadas entre 80 % y 99 %; las pruebas de carga identificaron un punto de operación estable hasta 250 usuarios concurrentes\. Se concluye que la arquitectura propuesta permite gestionar de forma escalable y confiable la información pública socioeconómica del Ecuador, sentando una base técnica sólida para el análisis predictivo y prescriptivo de la plataforma
