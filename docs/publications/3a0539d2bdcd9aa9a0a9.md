# Trace\-to\-Architecture: Capability Bottleneck Diagnosis for Harness Revision

**Autores:** Wenfeng Wang; Jianrui Shi; Mingang Guo; Jiayuan Ma; Yuqi Lu; Jiajun Sun; Guojiang Zhao; Jing Li

**Data:** 2026-10-12 · **Tipo:** preprint

## Resumo

Improving an LLM agent requires knowing what to change when it fails\. Similar failures can require different fixes, and resolving one problem can expose another\. We introduce Trace\-to\-Architecture \(T2A\), a framework that uses execution trajectories to determine what to change in an agent&\#x27;s harness and when those changes apply\. A development agent diagnoses failures using execution evidence from successful and failed tasks, revises the corresponding harness components, and then checks whether target tasks improve, selected successful tasks remain successful, and the edits are actually triggered\. New execution evidence guides subsequent diagnosis and revision\. Across ALFWorld, ScienceWorld, and AppWorld, T2A achieves the highest aggregate score for all three evaluated task agents, exceeding their respective strongest baselines by 6\.2\-\-30\.3 points\. We also integrate T2A&\#x27;s diagnosis and validation procedures into Meta\-Harness, improving the resulting harnesses&\#x27; mean ScienceWorld score by 21\.6 points from the same starting harness\.
