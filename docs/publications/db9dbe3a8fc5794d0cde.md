# Comparative Analysis of IoT Security Architectures: A Context\-Aware Security–Resource Suitability Framework

**Autores:** Dr\. S\. B\. Sarvaiya, Vedanti C\. Yawalkar, Sakshi K\. Rohankar

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

The Internet of Things \(IoT\) links sensors, cameras, appliances, vehicles, medical devices and industrial controllers to networks and cloud platforms\. This reach creates security problems that conventional networks rarely face: mixed hardware, scarce resources, devices that stay in service for years, wireless links and sensitive data\. This paper compares three representative IoT security architectures, the three\-layer, five\-layer and Fog/Edge\-based models, using published literature and recognised cybersecurity guidance\. Each is examined along seven dimensions: security coverage, performance, scalability, privacy, resource efficiency, manageability over the device lifecycle, and interoperability\. The main contribution is a Context\-Aware Security–Resource Suitability Index \(SRSI\), which reweights these dimensions to suit the application instead of declaring one architecture best in every case\. Literature\-informed scores are applied to healthcare, smart\-home and industrial or agricultural settings\. Fog/Edge gives the best overall balance in every scenario tested, while the three\-layer model stays attractive where low complexity and frugal resource use come first\. The study also argues that lifecycle manageability deserves the same attention as traditional security metrics\. SRSI is offered as a transparent decision\-support method\. Its scores are analytical, so validation on real testbeds with measured latency, energy, detection and resilience data is left for future work
