# Pengembangan Asisten Virtual Berbasis Artificial Intelligence untuk Layanan Informasi Sistem Manajemen PK IMM UMKO

**Autores:** Rizky Satrio Wibowo; Khusnul Khotimah

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

The management of the Commissariat Leadership \(PK\) of the Muhammadiyah Student Association \(IMM\) at the Faculty of Engineering and Computer Science \(FTIK\), Universitas Muhammadiyah Kotabumi \(UMKO\), has been conducted conventionally using separate Microsoft Excel and Google Form tools, leaving cadre registration, Darul Arqam Dasar \(DAD\) implementation, attendance, and news publication vulnerable to fragmented data, administrative errors, and proxy\-attendance practices\. This research develops a Web Mobile\-based PK IMM UMKO Management System integrated with an Artificial Intelligence virtual assistant for IMM\-related information services\. The system was built using the Waterfall method, the Django framework, and PostgreSQL with the pgvector extension, following a Model\-View\-Template architecture with role\-based access control for five actors\. It provides two AI services—a Retrieval\-Augmented Generation \(RAG\) Chatbot using the gpt\-4o\-mini model grounded in official AD/ART documents and a Smart Editor for language correction—together with automatic registration verification through the UMKO SSO API and a per\-session QR attendance module using regenerated UUID tokens as an anti\-proxy mechanism\. Black Box Testing on 32 scenarios was fully valid; chatbot testing on nine scenarios reached 100% accuracy with a median AI response time of about three seconds; and a four\-level Likert scale questionnaire involving 14 respondents across six validator groups yielded an average of 96\.20% in the “Very Feasible” category\. The system is therefore technically and functionally feasible as a modern solution for faculty\-level student organization governance\.
