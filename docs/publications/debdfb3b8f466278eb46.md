# Предиктивная аналитика режимов работы котельного агрегата БКЗ 420\-140 на основе машинного обучения

**Autores:** Denis I\. Karabarin

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

The article presents a comprehensive approach to developing a predictive analytics system for power equipment taking the BKZ 420\-140 boiler unit as an example\. The study covers stages from collecting and preprocessing data from the automated process control system \(APCS\) to building and validating several machine learning models, and conducting their comparative analysis\. The system structure is proposed, which includes modules for data acquisition, preprocessing, attribute calculation, and forecast classification and visualization\. Special attention is given to the data processing methodology, which includes automatic detection and replacement of physically unrealistic anomalies, as well as generation of relevant temporal and calendar features to prevent data leakage\. The performances of gradient boosting, random forest, logistic regression, and deep neural network algorithms have been compared in a detailed manner\. The best results on the test set have been obtained in using the Random Forest model with an accuracy of 86\.05% and a high ROC\-AUC value of 0\.8699, indicating its strong predictive ability\. Based on the trained model, a detailed forecast of the boiler unit operation modes for the next year has been constructed and analyzed, which revealed seasonal usage patterns and made it possible to identify 26 scheduled shutdowns\. The practical significance of the study is that a methodology that enables a shift to be made to timely maintenance of critically important power equipment has been developed, which contributes to increased reliability and optimized operational costs\.
