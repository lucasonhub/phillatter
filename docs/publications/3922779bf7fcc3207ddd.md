# An Intelligent Machine Learning Approach for Software Project Management and Performance Prediction

**Autores:** Dinesh Bhagwan Hanchate; Chaitany Shrikant Kulkarni

**Data:** 2026-10-17 · **Tipo:** article

## Resumo

SPM \(Software Project Management\) is the most important and toughest job in software engineering organizations\. For successful project management, it needs the proper planning and scheduling of each software development umbrella activity\. Software planning needs proper communication, requirement elicitation, suitable patterns and phase wise testing of software for fulfilling the clients requirements and completing the umbrella activities\. All these can be effectively achieved and predicted by accurate estimates of the budget and schedule\. Here, the literature review is illustrated by the most commonly used ML \(Machine Learning\) techniques such as neural net\-works, case based reasoning, classification and regression trees, rule induction, genetic algorithm and genetic programming for the sub\-domain of SPM\.
