# An Optimized Approach of Deep Neural Network for Liver Cancer Image Analysis

**Autores:** 

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Early detection of liver diseases helps reduce the fatality rate in liver cancer\.It also enhances the regeneration process in liver transplantation\.To achieve early detection, handcrafted features were used for analysis\.Although these features performed efficiently, they suffered in multiclass identification due to the limited choice of features\.To overcome this limitation, the proposed work implements a customized deep learning framework using Sparrow Search Optimization for network tuning, along with K\-fold training to generalize network performance\.The proposed framework was tested on a customized liver disease dataset, which undergoes preprocessing steps such as median filtering to suppress speckle noise and data augmentation to improve robustness\.The processed data is then passed through the proposed framework, and its performance is evaluated using accuracy, precision, recall, and F1\-score\.By comparing the performance of the proposed method with handcrafted feature\-based approaches using multidomain features and Particle Swarm Optimization, it is observed that the proposed method outperforms the existing methods with an accuracy above 94%\.This demonstrates that the proposed framework is suitable for automated liver disease identification\.
