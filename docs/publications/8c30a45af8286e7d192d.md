# Fault Detection and Monitoring of BLDC Motors used in EV

**Autores:** Dr\. S\. P\. Ashtankar; Astha Bhaware; Sanika Umak; Suhani Alone; Aditya Ghavat; Subodh Wadaskar

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

This research develops an IoT\-based fault detection and predictive health monitoring system for a 48V, 750W BLDC geared e\-bike motor\. Sensors monitor current, voltage, temperature, vibration, and RPM through an ESP32\. An ESP32 controller collects and processes the sensor data to identify abnormal operating conditions through IoT based learning techniques\. Real\-time monitoring, and fault alerts are provided through an IoT dashboard, enabling early fault detection and predictive maintenance\. The proposed system helps improve motor reliability, reduce unexpected failures, and extend the operational life of the e\-bike motor\.
