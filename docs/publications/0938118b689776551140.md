# Open\-vocabulary Object Detection for Open\-pit Mining Equipment: A Case Study of Prompt Formulation, Model Scale and Object Size Effects on Zero\-shot Accuracy

**Autores:** Refka Ghodhbani; Taoufik Saidani

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

Camera\-based detection in mines depends on site\-specific annotation\.Open\-vocabulary detectors take class names as text at inference time and could remove this step\.This case study evaluates seven text\-prompted detectors from four families on one open\-pit machinery collection of 171 images and seven classes, prompted with class names, mining vocabulary or descriptive phrases, with bootstrap confidence intervals on the principal results\.The best zeroshot configuration, OWLv2 with plain class names, reaches 21\.9% AP50, against 57\.9% for a YOLO11s detector finetuned on 111 images and selected on a separate validation split\.Descriptive phrases lower AP50 by up to 13\.2 points\.With one prompt per class, mining terms score clearly below plain names for three detectors and level with them for the two Grounding DINO models\.Larger checkpoints give no consistent gain\.Most errors confuse machine types, and about fourteen annotated images match the best zero\-shot result\.
