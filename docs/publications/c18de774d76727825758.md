# Wang, Kaining: 人工智能引发灾难性损失与人类灭绝风险及其防控

**Autores:** 

**Data de descoberta:** 2026-10-16 · **Tipo:** unknown

## Descrição do feed

本文主要通过无约束极端优化、边界逃逸行为以及高权限操作接口隔离不足三类机制，分析现 代人工智能的系统性灾难性风险，分析过程不以主观恶意为必要前提。现有人工智能安全研究 过度聚焦于任务专属技术护栏与事后风险缓解，由此带来冗余的安全开发流程、机构间执法标准不一致，以及侵蚀自愿性安全约束的内生市场激励。为应对上述结构性局限，本文提出一种 层级嵌套的安全架构，将制度层基线治理、系统层通用技术约束与任务层场景化约束三者分离。 本文将总安全约束集形式化为: 总体防控 = 监管基线防控 \+ 通用防控 （系统级通用硬约束） \+ 模块任务级防控 （场景专属约束） 该框架建立一套标准化、非冗余的安全栈:监管者定义统一的最低强制性边界，以抑制 市场竞次激励;人工智能系统设计者遵循通用技术原则，对优化可行解空间施加标准化限制; 部署方则根据具体风险场景补充任务层约束。 这种层级化设计减少了基线安全的重复实现，并限制了跨平台最低安全执法标准的分歧。 它进一步厘清了监管机构、系统开发者与终端用户之间的责任划分，为分析与防控七大类人工智能系统性灾难性风险提供了可推广的分层理论与工程基础。
