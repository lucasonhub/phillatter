# LLM\-BASED NEURO\-SYMBOLIC LEGAL JUDGMENT PREDICTION FOR CRIMINAL CASES

**Autores:** 

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

Predicting the outcome of a criminal case involves more than recognising which offence a narrative resembles\.A court asks whether each ingredient of the offence has been proved, whether a lesser offence still applies when one ingredient fails, whether a general exception excuses the act, and what punishment the statute prescribes\.We describe a judgment prediction framework for the Indian Penal Code \(IPC\) that assigns these questions to two kinds of components\.Large language models \(LLMs\) served through the Groq API read the narrative, extract the facts, and mark every ingredient of each candidate offence as proved, not proved or unclear, quoting the supporting text\.A symbolic layer built on a knowledge base of 213 IPC sections then applies seven explicit rules to choose the charge, decide the verdict, and retrieve the prescribed punishment, which the language model never produces\.We also show that the 4,260\-record synthetic dataset used in this project discloses its own labels: every record states the section number, the offence name and the outcome, so a TF\-IDF classifier is 100% accurate on unmodified text and about 1% accurate once the offence is hidden\.After section numbers and verdict words are masked, the rule pipeline identifies the offence in 99\.5% of 852 held\-out records and the verdict in 99\.8%, matching a trained logistic\-regression baseline \(99\.6%\) without any training; when the offence name is also removed, it declines to decide in 99\.8% of records instead of guessing\.A preliminary test on narratives that never name the offence gives 41\.7% top\-1 and 83\.3% top\-3 section accuracy\.These figures describe a controlled prototype, not performance on real judgments\.
