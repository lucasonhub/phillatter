# AI\-Powered Automated Assignment Generation and Intelligent Evaluation System Using Natural Language Processing and OpenAI API for Enhanced Learning and Fair Assessment

**Autores:** Sankaran Ramesh Kumar; M\. A\. Afsheen Sultana; M\. D\. Bilal Ahmed; Yedida Navya Sri Lakshmi Indu; Sangramjeet Ghosh

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

The integration of Generative Artificial Intelligence \(GenAI\) into higher education has precipitated a dual crisis: the exponential increase in faculty workload regarding assessment scalability and the destabilization of traditional academic integrity verification methods\. This paper introduces the proposed system, an automated academic evaluation platform designed to address these challenges through a unified, immutable assessment pipeline\. Unlike traditional Learning Management Systems \(LMS\) that function primarily as repositories, the proposed system employs Large Language Models \(LLMs\) to automate the entire grading lifecycle, from submission to feedback generation, while simultaneously performing rigorous authorship verification\. The system enforces a single\-submission policy to streamline administrative workflows and generates immutable, audit\-ready reports containing scoring rationale and AIgenerated content likelihood\. The system architecture, scoring methodology, and a multi\-layered integrity detection approach based on stylometry and machine learning classifiers are described\. Simulated performance results suggest that the proposed system mitigates the subjective variability of human grading while offering a scalable solution to the integrity challenges posed by unrestricted GenAI access\.
