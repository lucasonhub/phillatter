# Fractional\-Order Mathematical Modeling and Numerical Optimization of Nonlinear Dynamic Systems Using Machine Learning\-Assisted Approximation

**Autores:** Anuradha Amarthaluri; P\. Harikrishna; Mr\. S\. Vinoth Kumar; Dr Mokshed Ali

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

Fractional\-order models are used to model the memory\-dependent behavior of nonlinear dynamic systems, however, repeated evaluations of numerical models may be costly in terms of computation\. A machine learning assisted approximation and optimization package based on a reproducible fractional adaptive\-network simulation package is investigated\. The data available comprised the parameter\-response maps, fractional\-order sensitivity trajectories, and directed\-network baseline outputs\. The numerical protocol used product\-integration for the Caputo fractional states and Euler updates for the adaptive connectivity\. These were found to be response maps with 1,023, 990 and 899 parameter configurations, and a baseline trajectory with 1,601 time points for each configuration\. The variation of fractional order caused a change in the pathological responses of the transient state, and step size refinement caused changes of a small size in the terminal states reported\. The outputs are reference data for the development of surrogate models and for the evaluation of bounded optimization strategies\. However, the accuracy of the machine learning, the optimization improvements that have been verified by the solver and the computational savings are not measured\. Proposed framework: independent testing with a simulation, numerical convergence, and verification of candidate optima with the original solver\. Further testing on an independent nonlinear system will need to be performed to determine robustness and applicability outside of the provided biological model family\.
