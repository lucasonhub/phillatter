# The Agentic Scientist: Orchestrating Coding Agents for Automated Scientific \(Co\-\)Discovery

**Autores:** Robert Tjarko Lange; Luca Grillotti; Yutaro Yamada; Rujikorn Charakorn; David Ha

**Data:** 2026-10-13 · **Tipo:** preprint

## Resumo

Modern coding agents are fundamentally reshaping the role of human input for computational research: they write code, launch in silico experiments, analyze their results, and autonomously operate with ever\-increasing time horizons\. Despite these developments, fully autonomous research agents suffer from a limited ideation radius and myopic hill\-climbing search dynamics\. To bridge this gap, we introduce The Agentic Scientist, an end\-to\-end distributed pipeline for human researchers to conduct computational research alongside modern coding agents\. Building on its predecessor, our system decomposes research into task drafting, idea generation, planning, sandboxed experimentation, result aggregation, baseline and ablation construction, post\-hoc analysis, and report writing\. Importantly, each step in the pipeline is powered by the next generation of coding agents and leverages agentic self\-verification\. The overall research process is driven by a meta\-controller that manages parallel research agents and enforces rubric verification at each stage\. This design enables the same orchestration layer to be reused across heterogeneous domains with different execution environments, agentic coding harnesses, and evaluation metrics\. Our system can be used across a spectrum of autonomy: either as a co\-scientist tool or to perform end\-to\-end scientific investigation\. Within the co\-scientist setting, we leveraged a development version of our system to submit a single research paper, which got accepted for publication at ALIFE 2026\. We further apply The Agentic Scientist fully autonomously to open problem\-solving tasks in machine learning, and demonstrate the system&\#x27;s capability of scientific discovery across different domains of computational research\. Our ablations suggest that reliable scientific autonomy depends not only on base model capabilities, but also on the cross\-agent orchestration layer\.
