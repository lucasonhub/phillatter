# AI\-Barometer\. Adoptie en gebruik van Artificiële Intelligentie bij Vlaamse bedrijven\. Situatie 2025\.

**Autores:** Thomas Standaert; Cathy Lecocq; Petra Andries; Tom Evens

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

This report is a ECOOM\-beleidsrapport, which is a type of policy report\. The content of this ECOOM\-beleidsrapport reports on the &quot;Adoption and use of Artificial Intelligence in Flemish companies&quot; by using the data from the AI Survey 2025, conducted by ECOOM Innovation\. More information on the work of this research group can be found via https://www\.ecoom\.be/nodes/digitalisering/en\.
