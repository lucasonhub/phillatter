  这使概率成为物理学、神经科学、认知科学和人工智能共同面对的机制问题：物理学需要区分单次现实归一与跨次形成的多方向结构；神经科学需要区分测得概率分布与找到产生概率的神经组织；认知科学由此获得从经验历史到定向行为的中间层；人工智能则需要区分“会计算概率”与“能够通过自身历史形成未来方向”。

  因此： 环境作用 → 实际发生 → 沉积 → 律 → 概率维 → 概率组织 → 择与偏 → 意向 → 行动。 历史沉积成律，概率把律组织成方向，意向使系统向其中而行。
  《概率组式》最终提出的，不只是“一个结果的概率是多少”，而是一个更基础的问题： 什么物理组织，使一个系统真正拥有了未来方向？
