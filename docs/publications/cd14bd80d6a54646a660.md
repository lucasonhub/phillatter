# Agentic\-Priors: Using Large Language Models to Address the Cold Start Problem in Preference Elicitation

**Autores:** Bruno Arcanjo; Zhaoxing Li; Sebastian Stein

**Data:** 2026-10-15 · **Tipo:** preprint

## Resumo

An agent that learns a user&\#x27;s preferences from their choices faces a cold start problem: before any choices are observed, it must rely solely on a prior\. Informative priors are usually fitted to historical choice data, which new tasks and deployments lack\. To address this, we present Agentic\-Priors, which lets agentic systems use the implicit knowledge of large language models \(LLMs\) instead\. Specifically, an LLM states a new user&\#x27;s trade\-offs in interpretable terms, such as willingness to pay or value of time, which we map to a prior over multinomial logit coefficients\. This prior is then refined by a Bayesian learner as choices are observed\. Across seven choice datasets, Agentic\-Priors improves cold start accuracy over an uninformed prior by 5\-40 percentage points\. It also outperforms AutoElicit, a state\-of\-the\-art LLM prior\-elicitation method, on three datasets and loses on one\. It is up to 18 points more accurate than in\-context learning, and never significantly worse\. Against hierarchical Bayes models fitted to surveys of increasing size, our approach is worth roughly 6\-40 surveyed users, in terms of log\-loss, so its value is concentrated in a deployment&\#x27;s first users\.
