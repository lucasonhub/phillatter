# Physics\-Informed Machine Learning Framework for Predicting Joule Heating Activated Shape Recovery in Carbon Fiber Reinforced Shape Memory Epoxy Composites

**Autores:** Mehrab Hasan; Carter Thomas; Yingtao Liu

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

Shape memory epoxy composites recover a programmed shape when Joule heating drives the matrix through its glass transition, and a key challenge for these smart materials is predicting the recovery angle at drive currents outside the tested range\. In this work, three models were compared for this task: a Kohlrausch–Williams–Watts \(KWW\) theory based Physics\-KWW constitutive model, a gradient\-boosted tree model \(XGBoost\) using thermomechanical state features, and a support vector regression \(SVR\) model using raw experimental variables together with thermomechanical features\. All models were assessed by a leave\-one\-current\-out cross\-validation method over nine current levels from 1\.50 to 3\.50 A\. The physics\-informed models generalized well to unseen currents, with the Physics\-KWW model and XGBoost achieving R2 values of 0\.911 and 0\.915, respectively, compared with 0\.841 for the SVR model under the same tuning protocol\. Shapley analysis of a representative XGBoost fold identifies accumulated activation and estimated temperature as the dominant predictors\. The results demonstrate comparable accuracy for the two physics\-informed approaches, while their advantages remain conditional on the tested pipelines and calibration assumptions\.
