# Smart Portable Sensor System for Microplastic Detection in Water

**Autores:** Bavatharani K\.; Janani S\.; Leena Sri S\.; Preethi Monika K\.

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

Microplastic contamination is existing as one of the major environmental issues, which needs to be addressed in an efficient manner using economical detection methods\. Existing microplastics detection methods use spectroscopic and microscopic approaches to provide accurate results but these methods rely on expensive equipment and sample preparation processes\. In the proposed system, LED is used, while the photodiode measures the change in the intensity of transmitted light with the LM358 being the operational amplifier used for signal conditioning\. The Arduino Uno serves as the microcontroller, which takes the data input and classifies the level of contamination based on a threshold level\. The contamination level is indicated by using an OLED interface and indicator LEDs is used to enable instant interpretation for the users\. Experiments carried out using water with various levels of contamination showed reliable sensor operation with quick response time and accurate classification of the contamination level\.
