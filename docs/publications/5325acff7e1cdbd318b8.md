# Design of The Interactive Application “Paint Language Battle” for Analysing and Comparing Programming Language Performance Using a Python\-Based Paint Simulation

**Autores:** Danish Ahmad Satria

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

Choosing a programming language can be challenging for beginners because differences in computational performance are often difficult to understand without practical demonstrations\. This study aimed to develop and evaluate Paint Language Battle, an interactive application designed to visually compare programming language performance and assist beginners in selecting an appropriate programming language\. An experimental approach combined with a questionnaire\-based survey was conducted at SMA Labschool Kebayoran\. The application was developed using Python and PyQt5 to compare implementations written in Python, C\+\+, C, Java, JavaScript, and C\# across three drawing scenarios\. Performance was evaluated based on CPU utilization, memory consumption, frame rate, and lines of code, using average measurements and cumulative rankings\. Questionnaire responses from 92 students were analyzed using a Likert\-type scale\. Python achieved the highest overall ranking among the tested implementations, with a cumulative rank sum of six, average CPU utilization of 7\.43%, memory consumption of 68\.53 MB, and 233 lines of code\. Java achieved the highest average frame rate of 77 frames per second \(FPS\)\. The questionnaire yielded an overall mean score of 4\.269 out of 5, indicating highly favorable user perceptions of the application\. Additionally, 44\.6% of respondents selected Python as their preferred programming language\. These findings suggest that interactive visual benchmarking can help beginners understand performance trade\-offs among programming language implementations\. The application demonstrates potential as an educational tool for facilitating comparative performance analysis and supporting informed programming language selection\.
