# The potential of machine learning for emulating STICS grapevine yield across Europe

**Autores:** Nathalie Guimarães; João A\. Santos; Hélder Fraga

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

This deposit contains the code and derived data supporting the manuscript “The potential of machine learning for emulating STICS grapevine yield across Europe” \(Guimarães, N\., Santos, J\.A\., Fraga, H\.\)\. Grapevine yield was simulated with the STICS crop model at 286 locations across European wine\-growing regions from 2004 to 2024, for Grenache, Cabernet Franc and Pinot Noir under default cultivar parameters and rainfed management without nitrogen fertilisation\. Five machine learning algorithms \(multiple linear regression, random forest, XGBoost, LightGBM and TabPFN\) were trained to emulate the simulated yield from 144 candidate predictors, comprising weather summaries from January to August and terrain and soil properties\. Performance was assessed in 48 leave\-location\-and\-time\-out folds per cultivar, with hyperparameters tuned within each training fold and the number of predictors selected for each model and cultivar\. SHAP was applied to LightGBM, and fitting and inference times were compared with STICS\.
