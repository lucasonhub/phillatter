# 3D Visualization Tool for E\-Learning Activity Log Analysis From Desktop to VR Environment

**Autores:** Shohei Nakamura; Yoshihiro Okada

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

This paper presents a longitudinal evaluation through four studies of Cubic Gantt Chart \(CGC\), which is a three\-dimensional version of Gantt chart designed to visualize individual student e\-learning log data\. Across four system versions and four user studies through desktop to VR environments, this paper traces the CGC&\#x27;s development from an initial prototype through an enhanced desktop system, a collaborative VR environment\. The central finding across these evaluations is that each function increased users&\#x27; confidence in their analytical judgements but a ground\-truth verification in the final study revealed that this confidence did not correspond to statistical validity\. The in\-situ statistical test feature designed for integrating into participants&\#x27; analytical workflow to confirm their analysis is used sparsely and exploratorily\. These findings suggest that visual analytics tools can enhance user confidence without a corresponding mechanism ensuring that confidence tracks correctness and need active workflow support beyond the availability of a validation capability\.
