# Alhosseini Almodarresieh, Seyed Alireza: Testing Architecture\-Level Properties Relevant to Consciousness in Living Neural Biocomputing Systems

**Autores:** 

**Data de descoberta:** 2026-10-16 · **Tipo:** unknown

## Descrição do feed

Learning, adaptive behavior, or a linguistic report from a biocomputing system built of living neurons is not, by itself, evidence of consciousness\. This paper proposes consciousness\-ready biocomputing: an architecture — not a claim — for testing consciousness\-relevant properties experimentally, causally, and ethically\. It integrates recurrent processing, the global neuronal workspace, predictive processing, and higher\-order self\-modeling \(sharpened via attention schema theory\) in a living, multi\-module network embodied in a virtual body with a sensorimotor loop, memory, and a self\-modeling layer\. We define an engineering metric, the Consciousness Readiness Index \(CRI\), as a jointly\-necessary composite — not a linear sum — of global broadcast, causal recurrence, predictive quality, self\-model stability, and network integration, so that a complete absence of any one component drives the index toward zero rather than being compensated for by another\. CRI is not a probability of consciousness: it is always reported as a full component profile with a weight\-sensitivity range, each component explicitly tied to the theory that motivates it, that theory’s minimal versus strong claim, and the causal test that would challenge it\. The experimental protocol is a factorial ablation design with matched sham controls, paired with a staged ethics protocol specifying decision authority, shutdown procedure, and data governance for preventing the creation or escalation of possible suffering\. We position the framework relative to the closest existing approach, Butlin et al\.’s \(2023, 2025\) indicator\-property framework for AI systems\.
