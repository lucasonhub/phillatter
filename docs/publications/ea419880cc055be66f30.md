# EPOCH: Coverage\-Aware Evolution with Experiential Preference Optimization for LLM\-based Automated Heuristic Design

**Autores:** Oguzhan Gungordu; Ayse Tursucular; Siheng Xiong; Faramarz Fekri

**Data:** 2026-10-12 · **Tipo:** preprint

## Resumo

LLM\-based automated heuristic design \(AHD\) discovers heuristics for combinatorial optimization problems \(COPs\), where an LLM generates candidates in an evolutionary search\. Existing frameworks freeze the generator or fine\-tune it on a scalar fitness signal hiding which instances each heuristic covers\. Reflection\-based frameworks improve heuristics with natural\-language feedback, but it stays in the prompt and never reaches the generator&\#x27;s weights\. We propose EPOCH, which makes instance coverage the objective of the evolutionary search and fine\-tunes the generator to internalize reflection\. Parent selection, operator allocation, and stagnation recovery all optimize how well the heuristics jointly cover the training instances, so the search returns a complementary heuristic ensemble\. The generator learns from its own search by experiential preference optimization\. A teacher LLM returns a natural\-language insight on the generated heuristics, and the generator produces new heuristics with this insight\. These improvements join the preference pairs for direct preference optimization \(DPO\)\. Since DPO only teaches the generator to rank these improvements, a reflective self\-distillation \(RSD\) term makes it more likely to generate them on its own, and the gains accumulate over the long horizon of the search\. Across COPs and open\-source LLM backbones, EPOCH&\#x27;s heuristic ensembles outperform inference\-only and fine\-tuned baselines and generalize across problem scales\.
