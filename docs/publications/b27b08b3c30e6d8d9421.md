# Analisis Keberhasilan Implementasi Sistem Informasi Manajemen Rumah Sakit di Unit Rawat Inap RS Kasih Ibu Surakarta dengan Pendekatan Model for Mandatory Use of Software Technologies \(MMUST\)

**Autores:** Devieta Romadhon Saendardy; Arlette Suzy Puspa Pertiwi; Yuniati Lestari

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

Hospital Management Information Systems \(SIMRS\) are mandatory in Indonesian hospitals, but their implementation does not always ensure optimal utilization by healthcare professionals\. This study examines the success of SIMRS implementation in the inpatient unit of Kasih Ibu Hospital, Surakarta, using an adapted Model for Mandatory Use of Software Technologies \(MMUST\)\. We used an explanatory quantitative approach with a cross\-sectional design\. We collected data through Likert\-scale questionnaires and analyzed them using Partial Least Squares Structural Equation Modeling \(PLS\-SEM\)\. The measurement model met the reliability and convergent validity criteria\. The findings support all four main hypotheses: Information Quality positively influences Information Satisfaction, Performance Expectancy positively influences Attitude, Attitude positively influences Use, and Use positively influences Overall Satisfaction\. Exploratory analysis also reveals a positive direct effect of Information Quality on Attitude, whereas Information Satisfaction has no significant effect on Attitude\. The model demonstrates weak\-to\-moderate explanatory power\. These findings suggest that, in mandatory\-use systems, user attitudes remain a key determinant of usage depth, while information quality contributes to both information satisfaction and user attitudes\. Hospital management should therefore improve data quality while fostering positive attitudes toward SIMRS among healthcare professionals\.
