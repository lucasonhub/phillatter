# Performance Evaluation of Steganogan Using Hybrid Image Datasets and Statistical Quality Metrics

**Autores:** Metin Eken; İclal Çetin Taş

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

This study proposes a novel approach by employing SteganoGAN, a steganographic framework based on Generative Adversarial Networks \(GANs\)\. The impact of image categories with different semantic contents \(art, building, and nature\) on system performance was examined in detail using the SteganoGAN architecture\. A hybrid dataset composed of BossBase and USC\-SIPI images was utilized to conduct the experiments\. The influence of image quality, categorized by visual content, on performance was systematically analyzed\. In particular, changes in skewness and kurtosis values, as well as the widely used image quality metrics PSNR and SSIM, were investigated\. Experimental results demonstrated that nature images provided superior performance, achieving an SSIM value of 99\.59 and exhibiting the lowest skewness deviation from the original cover images\.
