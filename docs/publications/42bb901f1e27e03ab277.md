# EMPLOYEE PERFORMANCE ANALYSIS USING MACHINE LEARNING

**Autores:** EMERGING TRENDS IN DIGITAL TRANSFORMATION

**Data:** 2026-10-09 · **Tipo:** article

## Resumo

Evaluating employee performance is a central responsibility of human resource management, yet conventional appraisal methods depend heavily on subjective manager opinions and are slow, inconsistent and prone to bias\. This paper presents a machine learning based system that analyses historical employee records and predicts an employee&\#x27;s performance category \(Low, Medium or High\) from measurable attributes such as experience, training hours, projects completed, attendance, average working hours, peer review score and job satisfaction\. The workflow consists of data collection, cleaning, exploratory analysis, feature scaling, stratified train/test splitting, training of six classifiers \(Logistic Regression, Decision Tree, K\-Nearest Neighbours, Support Vector Machine, Gradient Boosting and Random Forest\), cross\-validation, hyper\-parameter tuning and comparison using accuracy, precision, recall, F1\-score and ROC\-AUC\. Random Forest gave the best overall balance on the held\-out test set with an accuracy of 87\.0% and a weighted F1\-score of 0\.871, with Gradient Boosting performing almost identically\. Feature importance analysis shows which factors influence performance most, making the predictions explainable to HR managers\. The trained model is exposed through a Flask web application with administrator and user modules\.
