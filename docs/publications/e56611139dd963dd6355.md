# Predictive Al for Enhancing Clinical Pathways in Children with Learning Disabilities using XGBoost

**Autores:** Sujitha V\.; Kishore P\.; Nevin Nehal R\.S\.; Afzal Khan M\.

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

Dyslexia screening in children involves computing techniques to analyse the learning patterns from the structured data generated by behaviour and language assessments\. This research work proposes a machine learning technique to classify dyslexic cases by implementing Random Forest and XGBoost on a publicly available dataset consisting of 3,644 observations and 196 features extracted from demographics and language tasks\. Steps in data pre\-processing involves the missing observations handling, categorical data encoding, non\-predictive columns elimination, and stratified splitting of training and testing datasets\. Hyperparameter tuning is performed via stratified cross\-validation, followed by independent testing of both ensemble models\. Random Forest attained 95\.1% accuracy with 94\.3% precision, 93\.8% recall, 94\.0% F1\-Score, and 0\.97 ROC\-AUC score, whereas XGBoost gave an accuracy of 91\.8% and ROC\-AUC of 0\.94\. Flask\-based prediction model was created for providing individualized screening predictions\. The platform shows how ensemble learning could be used in computational dyslexia screening and serves as an illustrative example of the decision support tool for preliminary screening\.
