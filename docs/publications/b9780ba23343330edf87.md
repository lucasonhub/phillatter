# AI\-Based Women Safety Clip: Literature Survey and Proposed System

**Autores:** Riddhima Patil, Tejal Chaudhari, Vaishnavi Zambare; Prof\. S\.S Momin Sanskruti Ahire

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

Women&\#x27;s safety systems have increasingly used wearable devices, IoT communication, sensors, cameras, and machine learning to provide faster emergency assistance\. This paper reviews existing research on wearable women safety systems, automatic activity detection, sensor\-based monitoring, camera\-based verification, and wireless alert communication\. Existing systems mainly depend on manual emergency activation or physiological monitoring, while some recent systems introduce AI\-based detection\. However, there is still a need for a compact wearable system that can automatically identify predefined unusual activity patterns and reduce false alarms through verification\. The proposed AI\-Based Women Safety Clip uses a camera and MPU6050 IMU connected to an ESP32\-based controller\. The collected data is processed and analysed using AI/ML techniques to classify activity as Normal or Unusual\. A verification stage is used before sending an alert through Wi\-Fi to a smartphone\. The smartphone obtains GPS location and shares the alert with a trusted contact\.
