# Beyond ICD Codes: Semantic IDs for Generative Medical Coding

**Autores:** Yihang Cheng; Qian Zhang;  Yonghui;  Huang; Baoshuo Kan; Junyi Shen

**Data:** 2026-10-13 · **Tipo:** preprint

## Resumo

Generative approaches to automatic International Classification of Diseases \(ICD\) coding use large language models \(LLMs\) to predict ICD codes from clinical documents\. However, original ICD code strings are not ideal generation targets because the ICD hierarchy does not always reflect clinical relationships, and LLMs struggle to interpret and generate these codes\. We introduce SemICD, a framework that trains LLMs to generate Semantic IDs \(SIDs\) instead\. SemICD constructs SIDs by hierarchically clustering embeddings of textual code profiles, allowing semantically related codes to share prefixes while each complete SID uniquely identifies one ICD code\. To align the SID tokens with clinical semantics, we employ two auxiliary tasks for bidirectional generation between textual code profiles and SIDs\. Experiments on MIMIC\-III and MIMIC\-IV with four LLMs show that SemICD outperforms direct code generation, improving Micro\-F1 by 1\.34\-8\.00 points\. Our code is available at https://github\.com/youwillbethebest/SemICD\.
