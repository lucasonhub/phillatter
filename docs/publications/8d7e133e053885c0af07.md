# Machine Learning\-based Ayurvedic Body Type Prediction with Suggestive System

**Autores:** Naganidhi U; Mrs\.Sowmya D; Varsha Dixit K G; Vikas T S; Vivek V\. Shet

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

Ayurveda, the ancient Indian system of medicine, classifies human beings into three primary body types, or Prakritis: Vata, Pitta, and Kapha\. These body types are determined by the balance of three fundamental biological energies called Doshas\. Understanding an individual&\#x27;s body type is crucial for recommending lifestyle habits, dietary preferences, and preventive healthcare strategies\. Traditional methods for determining Prakriti rely on subjective questionnaires and expert evaluation, which can often be inconsistent and time\-consuming\. This project aims to leverage machine learning techniques to predict an individual&\#x27;s Ayurvedic body type accurately and efficiently\. By analyzing physiological, psychological, and lifestyle data, the system can classify users into one or more dominant Doshas\. Furthermore, the project incorporates a suggestive system that provides personalized recommendations on diet, exercise, and daily routines based on the predicted Prakriti\. The integration of machine learning enhances prediction accuracy, provides a scalable solution, and bridges traditional knowledge with modern technology, making Ayurvedic health insights more accessible to the general population\.
