# AI\-BASED STUDENT PERFORMANCE MONITORING &amp; ALERT SYSTEM

**Autores:** R\. Mahesh Kumar; Sk\. Asma; T\. Nanda Kishore

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

This paper presents an AI\-based student performance monitoring and alert system designed to identify students who may be at academic risk\. The system uses machine learning to classify risk levels and provides dashboards, prediction explanations, reports, and alerts to support student monitoring\.
