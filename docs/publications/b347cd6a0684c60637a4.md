# An Improved DSC‐Based Fixed‐Time Resilient Tracking Control for Uncertain Nonlinear Systems With Full‐State Constraints

**Autores:** Bocheng Yan; Shuai Liu; Xianfu Zhang

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

ABSTRACT This article addresses the fixed‐time resilient tracking control problem for state‐constrained unknown nonlinear systems under deception attacks\. First, within the backstepping framework, a state‐dependent function is introduced at each design step to enforce asymmetric state constraints\. This approach eliminates the feasibility conditions on virtual controllers required by barrier Lyapunov function \(BLF\)‐based methods\. Second, an enhanced dynamic surface control \(DSC\) technique is proposed to circumvent the differentiation explosion inherent in backstepping while overcoming stability analysis challenges from state‐dependent function‐induced residual terms\. By integrating these components, a fixed‐time resilient control strategy is developed that \(1\) guarantees the fixed‐time convergence of the output tracking error; \(2\) ensures strict adherence to prescribed state constraints\. Numerical simulations validate the effectiveness of the proposed algorithm\.
