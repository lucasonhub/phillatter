# Enhanced Access Control Management System in an Edge Computing Environment Using Bimodal Biometrics Technique

**Autores:** Paul Ohia; Friday Eleonu Onuodu; Ugochi A\. Okengwu

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

This study presents an enhanced access control management system for edge computing environments using bimodal biometrics, contextual risk analysis, and Chinese Wall policy enforcement\. The work addresses a limitation in context\-only access control frameworks, namely their inability to confirm that the person requesting access is the genuine enrolled user\. To close this identity\-verification gap, the proposed system integrates face recognition, fingerprint recognition, and contextual decision support into a unified edge\-aware authentication workflow\. The implementation was developed in Python using Flask, with MySQL for transactional data storage and IPFS for content\-addressed storage of biometric\-related artifacts\. A hybrid dataset strategy was adopted\. Public datasets such as VGGFace2 and SOCOFing supported preliminary experimentation, while locally captured biometric samples were emphasized for operational training and evaluation in order to reduce domain mismatch\. A one\-dimensional convolutional neural network was used for contextual access analysis, while transfer\-learning\-based convolutional neural networks were used for face and fingerprint recognition\. The datasets were split into 70% training and 30% testing\. Experimental results showed strong performance for the biometric and contextual modules\. The face model achieved about 0\.96 accuracy, the fingerprint model achieved about 93\.36% classification accuracy with 95\.83% precision, recall, and F1\-score for the enrolled\-user fingerprint class, and the contextual Conv1D model achieved 84\.08% test accuracy\. System\-level testing further showed that integrating biometric evidence with contextual intelligence and policy enforcement improved access\-decision reliability over the earlier context\-only model\. The study concludes that combining bimodal biometrics with edge\-based contextual reasoning can provide stronger identity assurance, better real\-time responsiveness, and more dependable access control for distributed computing environments\.
