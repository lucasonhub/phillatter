# CartoVec: General\-Purpose Location Embeddings from Open Map Data

**Autores:** Furkan Gursoy

**Data:** 2026-10-12 · **Tipo:** preprint

## Resumo

Geographic coordinates are common inputs in applied machine learning, but latitude and longitude describe position rather than the surrounding environment\. Image\-grounded location encoders learn this context from satellite or ground\-level imagery; structured open map data offers another source of supervision whose utility for continuous coordinate encoders remains less explored\. We introduce CartoVec, a coordinate encoder trained to predict Overture\-derived land cover, land use, transportation, place and connectivity targets at multiple spatial scales, without image inputs or downstream\-task labels\. We evaluate frozen embeddings on Census outcomes, Airbnb prices and Philadelphia crime in the US Northeast using spatial block cross\-validation\. CartoVec has the highest mean performance on most Census outcomes and the highest average across the full suite, with several comparisons close across folds\. The findings support open map data as a practical source of reusable location representations with a coordinate\-to\-vector interface that requires no map lookup at inference\. The open\-weight model is available at https://huggingface\.co/gursoyfurkan/CartoVec\.
