# Integrating RUSLE and Machine Learning for Soil Erosion Susceptibility Mapping in the Central Indo\-Gangetic Plains: R Code and Sample Data

**Autores:** Syed Irtiza Majid

**Data:** 2026-10-12 · **Tipo:** book

## Resumo

This release contains the R scripts and sample data used to estimate the machine\-learning emulation of RUSLE\-derived soil erosion classes in Sultanpur district, Uttar Pradesh, India, using C5\.0 decision tree, support vector machine and multi\-layer perceptron neural network models under nested, spatially blocked cross\-validation\. The repository includes: 15,000 sample points extracted from the 30 m rasters archived on Zenodo Redundancy screening of the seventeen geo\-environmental variables \(association matrix, GVIF, overlap with the RUSLE factors\) Spatial blocking \(5 km blocks, five folds, 1\.2 km buffer\) Nested cross\-validation with inner spatial hyperparameter tuning for C5\.0 DT, SVM and MLPNN Comparison of variable sets with and without RUSLE\-derived predictors, and of strict and no\-gap training designs Performance evaluation with ROC\-AUC, PR\-AUC, Brier skill score, MCC, block\-bootstrap confidence intervals and paired model comparisons Permutation\-based variable importance across spatial folds Final susceptibility maps and class tables of the Set B models Full Changelog: https://github\.com/sirtiza34/Erosion\_RUSLE\_Machine\_Learning\_Sultanpur/commits/Erosion\_RUSLE\_Machine\_Learning\_Sultanpur
