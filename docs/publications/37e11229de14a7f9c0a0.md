# Potential of Metabolomic Machine Learning for Thyroid Cancer Screening and Diagnosis

**Autores:** Haibin Guan; Lauren  M\. Petrick; Maaike A\. G\. van Gerwen

**Data:** 2026-10-13 · **Tipo:** book

## Resumo

Potential of metabolomic machine learning for thyroid cancer screening and diagnosis — ML Prediction pipeline This script reproduces the association and prediction analyses, including covariate\-adjusted and conditional logistic regression, repeated nested cross\-validation \(PLS\-DA and comparator classifiers\), pathway over\-representation analysis, and all main and supplementary figures\. NOTE: Individual\-level patient data cannot be shared publicly for participant\-privacy reasons\. The data that support the findings are available from the corresponding author upon reasonable request and subject to the relevant institutional and ethical approvals\. This repository provides the analysis code only; the scripts therefore document the full analytical pipeline\.
