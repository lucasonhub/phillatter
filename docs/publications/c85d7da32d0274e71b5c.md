# Nonlinear electro\-chemo\-mechanical multiphysics model for high\-capacity PANI@MWCNT\-IPMC soft actuators

**Autores:** Jintao Zhao; Xiaowei Zhang; Yang Cao; Zhenjie Zhang; Yanqi Dong; Xinyang Wang

**Data:** 2026-10-11 · **Tipo:** article

## Resumo

Abstract This work achieves synergistic optimization of material performance, model accuracy and practicability for ionic polymer–metal composites \(IPMCs\)\. We fabricated a polyaniline/multi\-walled carbon nanotube core\-shell \(PANI@MWCNT\) electrode, which exhibits up to 9\.09\-fold higher charge storage capacity than homemade Ag electrodes under identical conditions\. Capacitance enhancement is positively correlated with actuation displacement improvement, confirming the core\-shell structure enhances IPMC performance via boosting charge storage capacity\. A nonlinear electro\-chemo\-mechanical coupling model was established, which clarifies the core actuation mechanism of the as\-prepared IPMC and explains the high\-voltage saturation of actuation response\. With experimentally measured key parameters and inversely identified coupling coefficient, the model predicts actuation displacement with an overall R²=0\.949, reaching 0\.987 in the medium\-high voltage range \(3–6 V\)\. This work demonstrates that the PANI@MWCNT core\-shell electrode significantly enhances IPMC performance, and the proposed model provides a reliable theoretical framework for predicting the quasi\-steady\-state actuation behavior of PANI@MWCNT\-IPMC in 3–6 V range\.
