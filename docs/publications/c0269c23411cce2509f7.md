# Dynamic Multi\-Mode Scheduling and Deployment with Early Exit Neural Network Integration

**Autores:** Jakob Matthias Stammler

**Data:** 2026-10-14 · **Tipo:** book

## Resumo

Vier zentrale Trends prägen die Architektur moderner Kraftfahrzeuge\. Diese Trends sind die Zentralisierung der Fahrzeugarchitektur, der verstärkte Einsatz von Software\-defined Vehicles, der steigende Einsatz von Hardware\-Abstraction\-Layern sowie die Nutzung von Machine\-Learning\-Methoden\. Die Entwicklung des Trends zur Hardwarezentralisierung verläuft von einer verteilten Architektur über eine domänenzentrierte Architektur hin zu einer Fahrzeug\-zentrierten Architektur\. In der domänenzentralisierten Architektur werden Domain Controller eingesetzt, um Subsysteme wie den Antriebsstrang, das Infotainmentsystem oder die Karosserie zentralisiert zu steuern\. Dieser Trend bilded das Umfeld dieser Dissertation\. Leistungsfähigere und komplexere Hardwareplattformen fördern diesen Trend, was wiederum komplexere Software\-Stacks erfordert und den Einsatz von Machine\-Learning\-Methoden ermöglicht\. Um die Mehrkerneigenschaften der eingesetzten Plattformen auszunutzen und gleichzeitig die Anforderungen des Automotive\-Bereichs zu erfüllen, wird ein Schedulingverfahren benötigt, welche funktionale Anforderungen berücksichtigt und dem Entwickler die Safety of the Intended Functionality gewährleistet\. Ein solcher Algorithmus muss in der Lage sein, Task Sets zu schedulen, die sowohl Machine\-Learning\-Methoden als auch periodische Tasks für Steuerungsfunktionen zentralisierter Architekturen umfassen\. Weiterhin muss das Modell Plattformen mit Peripherie, mehreren Kernen sowie Hardwarebeschleunigern unterstützen\. Domain Controller weisen zudem dynamische Betriebsmodi auf, zwischen welchen bei Fehlern oder Anomalien oder bei Aktivieren von Komponenten umgeschaltet wird\. Bestehende Arbeiten betrachten jeweils nur einen Teil der genannten Anforderungen, etwa die Unterstützung von Machine\-Learning\-basierten Tasks, ein aussagekräftiges Task\-Modell oder die dynamische Ausführung von Tasks\. Diese Dissertation verfolgt das Ziel, diese Anforderungen in einem holistischen Ansatz zu vereinen\. Zur Argumentation für eine sichere Ausführung wird innerhalb eines Time\-Triggered\-Scheduling\-Ansatzes ein Correct\-by\-Construction\-Argument verwendet\. Der Algorithmus modelliert die Ausführungszeit unter der Annahme, dass keine Verzögerungen durch zeitgleiche Zugriffe auf Speicher oder Peripherie auftreten\. Ist diese Annahme erfüllt, werden die Tasks innerhalb ihrer vorhergesagten Ausführungszeit ausgeführt\. Die Einbindung von Machine\-Learning\-Methoden in diesen Schedulingansatz erfolgt durch das Hinzufügen von Early Exits und einen Scheduling\-Algorithmus, der diese Early Exits ausführt, sobald Constraint\-Verletzungen vorhergesagt werden\. Die resultierenden Neuronalen Netze werden dann als Anytime Neural Networks bezeichnet und können sowohl innerhalb des Time\-Triggered\-Verfahrens als auch eigenständig eingesetzt werden\. Der dynamische Aspekt des eigentlich statischen Time\-Triggered Schedulings wird durch einen Mode\-Change\-Mechanismus unterstützt, der die Ausführung verschiedener Task Sets zur Laufzeit über entsprechende Modi und zusätzlich generierte Übergangs\-Schedules erlaubt\. Da die Komplexität des resultierenden Schedule\-Graphen mit der Anzahl der Modiübergänge exponentiell steigt, wird ein Verfahren zur Reduktion der Scheduleanzahl mittels Varianten bereits generierter Schedules eingeführt\. Neben benutzerdefinierten Modiübergängen kann der Mode\-Change\-Mechanismus auch durch einen Anomaly\-Detection\-Mechanismus ausgelöst werden, der dem System automatisch zur Designzeit hinzugefügt wird\. Die Evaluierung erfolgt durch zwei Use Cases\. Der erste enthält zwei neuronale Netze, die auf einem dedizierten Hardwarebeschleuniger in einem Mehrkernprozessor ausgeführt werden\. Der zweite Use Case basiert auf einer RoboRacer\-Plattform und schedult ein Task Set für autonomes Fahren sowohl auf einem Jetson Nano als auch auf einem AMD KR260\. Die Evaluation der Generalisierbarkeit erfolgt komponentenweise\. Synthetische Task Sets mit variierenden Parametern werden gescheduled und der Algorithmus hinsichtlich der Erfolgsrate sowie der Laufzeit evaluiert\. Die höchste Laufzeit liegt bei \\SI\{100\}\{\\minute\} für 100 Tasks, eine Auslastung von 100 %, einen Deadline\-Slack von 0,0 sowie acht Execution Units\. Dieses komplexeste Task Set wurde innerhalb einer angemessenen Zeit gescheduled und zeigt, dass der Ansatz für reale Anwendungsszenarien geeignet ist\. Zusätzlich wird der Anytime\-Neural\-Network\-Ansatz hinsichtlich seiner eigenständigen Einsetzbarkeit evaluiert\. Die Ergebnisse zeigen, dass der vorgestellte Scheduler einen temporären Anstieg der Utilization auf 250 % bei einer Absenkung der Accuracy auf das Niveau des frühesten Early Exits bewältigen kann\. Diese Dissertation präsentiert einen holistischen Schedulingansatz, der Machine\-Learning\-Methoden, periodische Tasks und dynamische Betriebsmodi vereint sowie einen Correct\-by\-Construction\-Ansatz für die sichere Ausführung von Tasks mittels Time\-Triggered Scheduling mit Mode\-Change\-Mechanismus unterstützt\.
