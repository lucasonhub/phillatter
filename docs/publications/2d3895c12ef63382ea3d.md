# SkillNEO: Non\-Elitist Evolutionary Optimization of Agent Skills

**Autores:** Enze Ma; Chunyu Miao; Yankai Chen; Jie Yang; Liancheng Fang; Kening Zheng; Hanrong Zhang; Muyao Xu; Xinle Yu; Chengze Li; Wei\-Chieh Huang; Ziwei Ren; Yunhao Du; Zhixiang Shen; Xue Liu; Philip S\. Yu; Zhen Wang

**Data:** 2026-10-14 · **Tipo:** preprint

## Resumo

Agent skills turn procedural knowledge into reusable artifacts, allowing LLM agents to accumulate and refine expertise through experience\. Building on this, skill evolution iteratively improves skills using execution feedback\. However, improvement may require several interdependent edits, so low\-reward versions can still be worth developing\. Requiring immediate reward gains can discard useful partial repairs before their benefits emerge\. Non\-elitist evolution allows new versions to receive further edits despite scoring below earlier ones\. For agent skills, this calls for evidence of what to preserve and repair next\. We introduce SkillNEO \(Non\-Elitist Evolutionary Optimization for Agent Skills\), which separately selects a version to use and versions to keep improving\. Comparing how related versions perform the same task reveals working steps to preserve and remaining failures to fix\. It can also revisit and revise earlier versions using later evidence\. Across 86 SkillsBench tasks in eight domains, including software engineering and office work, SkillNEO raises GPT\-5\.4 Mini&\#x27;s average reward from 49\.1% to 66\.4%, within GPT\-5\.5 and GPT\-5\.6 Luna&\#x27;s original\-skill range\. Mini executes tasks, proposes revisions, and edits skills; final evaluation uses the same task instances\. Gains span all eight domains\. The same skills improve stronger models without further editing\. On the 41 tasks with modified skills, reuse improves Luna by 10\.5 percentage points and places GPT\-5\.5 10\.6 points above its published original\-skill reference\. Execution records show these skills can benefit stronger models even when Mini still fails some task requirements\. Search histories also show lower\-scoring versions leading to skills ultimately selected for use\. Together, these findings show that skill evolution can turn a weaker model&\#x27;s partial progress into reusable procedural knowledge for improving more capable agents\.
