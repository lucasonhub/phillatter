# CareBridge AI: A Unified Web\-Based Healthcare Assistance Platform

**Autores:** Saniya Javid Shaikh; A\. N\. Pawar

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

Healthcare\-support information is often spread across separate services for treatment\-cost planning, government assistance discovery, hospital location search, and medical\-document review\. This can make navigation difficult for patients and families, particularly those seeking affordable care\. This paper presents CareBridge AI, a web\-based prototype that organizes selected healthcare\-support functions in one interface\. Developed using HTML, CSS, and JavaScript, the prototype provides interfaces for medical\-bill information, a funding\-gap calculator, medical\-report text review, scheme discovery, a hospital finder, and chat\-style support\. The funding\-gap module estimates the remaining amount from user\-entered treatment cost, available funds, expected assistance, and other contributions\. The current implementation uses browser\-side logic and demonstration storage\. It does not demonstrate a trained or clinically validated AI/ML model, a production\-grade patient database, or an IoT deployment\. A qualitative comparison identifies integration and navigation as the main design opportunity\. A proposed evaluation plan covers calculation correctness, official\-link validity, usability, privacy, and future AI validation\. No clinical or performance improvement is claimed without measured testing\.
