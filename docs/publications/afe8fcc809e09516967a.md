# HyCo: Hybrid Drafting for Cost\-Efficient Mobile\-Cloud Speculative Decoding

**Autores:** Hanbin Bae; Heejin Choi; Joohyung Lee; Byoung Jin Choi; Sangjun Park; Hoon\-Young Cho

**Data:** 2026-10-15 · **Tipo:** preprint

## Resumo

Device\-cloud speculative decoding reduces server computation, but growing a deep draft tree with a small language model \(SLM\) requires repeated passes on a mobile neural processing unit \(NPU\)\. We present HyCo, which assigns depth to the server model&\#x27;s native multi\-token prediction \(MTP\) head, executed on the device, and alternative branches to one SLM pass\. The server returns the hidden state, input embedding, and key\-value entries needed by the head instead of executing its sequential steps\. Quantization, a restricted vocabulary, and a 1K\-token window fit both drafters to the NPU\. An ε\-threshold rule additionally relaxes exact preservation of the verifier&\#x27;s sampling distribution\. In single\-client runs with a Galaxy S26 Ultra over LTE/5G, HyCo reduces server GPU time per output token relative to server\-side MTP self\-speculation by 38\.6% on Spec\-Bench and 29\.2% on 32K\-token summarization\. With the same acceptance rule, three Spec\-Bench runs per system show 9\.0 percentage points more saving and 1\.9x delivery speed than an SLM\-only drafter\. HyCo differs from Cloud\+MTP by \+0\.2 judge\-score points \(paired 95% CI: \-0\.9 to \+1\.3\); exploratory translation favors SpecEdge\-ε\. Without relaxation, HyCo exact saves 27\.7% and 11\.9% on the two datasets\.
