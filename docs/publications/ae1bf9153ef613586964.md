# Development of a dynamic calculation method for the smart readiness indicator using genetic programming

**Autores:** Mitja Beras

**Data:** 2026-10-15 · **Tipo:** dissertation

## Resumo

Izhodišča: Kazalnik pripravljenosti na pametne rešitve \(SRI\) je nov instrument Evropske unije za spodbujanje digitalizacije in energetske učinkovitosti stavb\. Uradna metodologija zahteva ocenjevanje 54 kategorij in zbiranje 228 podatkovnih točk \(ali vhodnih podatkov\), kar je zamudno in podvrženo subjektivnosti\. Namen doktorske disertacije je bil razviti inovativni, dinamični, podatkovno podprti način določanja ocen SRI z uporabo genetskega programiranja \(GP\)\. Metode: V eksperimentalni del raziskave je bilo vključenih 223 stavb, pri katerih so bili po originalni metodologiji SRI ocenjeni njihovi tehnični sistemi\. Iz zbranih podatkov je bilo z genetskim modeliranjem razvitih 7 modelov za napovedovanje ocen domen\. Ti modeli so bili nadgrajeni z linearno regresijo \(LR\) za modeliranje ocen faktorjev vplivanja in skupne SRI ocene zgradbe\. Za razvoj dinamičnega, avtomatiziranega, podatkovno podprtega vrednotenja smo uporabili model LLM \(angl\. large language model\), ki bere podatke iz SQL \(angl\. Structured Query Language\) baz centralnega nadzornega sistema \(CNS\) in samodejno podaja ocene »pametnih« storitev\.
