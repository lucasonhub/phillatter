# Binary Classifier Wire\-Resistance Attack on KLJN: Bayes\-Optimal Limit at a Narrow Resistor Gap

**Autores:** MEHMET YILDIRIM; Fahrettin Ay; László B\. Kish

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

Machine learning is shown not to increase Eve’s successful bit\-guessing probability in the binary\-classifier\-based wire\-resistance attack on the Kirchhoff Law\-Johnson Noise \(KLJN\) key exchange when the resistor gap is narrow\. Using time\-domain simulations of a non\-ideal KLJN loop with \[Formula: see text\] k\[Formula: see text\], \[Formula: see text\] k\[Formula: see text\] and wire resistances from 0 to 3200 \[Formula: see text\], we generate 3000 secure bits per wire resistance and evaluate the mean\-square noise voltages at both ends over 100\-sample bit exchange periods \(BEPs\)\. This probability \[Formula: see text\] is evaluated for the sign rule, the nearest\-line rule, logistic regression, support vector machine \(SVM\), \[Formula: see text\]\-nearest neighbors, random forest and gradient boosting\. The sign rule gives \[Formula: see text\] at 50 \[Formula: see text\] and 0\.682 at 3200 \[Formula: see text\]\. The nearest\-line rule, logistic regression and SVM stay close to it and the other classifiers perform worse\. For Gaussian noise, the likelihood ratio between the HL and LH cases depends only on the difference of the two mean\-square voltages, so the sign rule is Bayes\-optimal\. The resulting \[Formula: see text\] reproduces the measured values and predicts that about 900 to 1200 samples per bit are needed for \[Formula: see text\]\. This difference carries about 0\.19 bit per secure bit, 1\.5 times the hard\-decision value\.
