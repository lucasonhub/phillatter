# Barcode\-Based Student Memorization Monitoring System Using Extreme Programming

**Autores:** Ibrahim Kayyis; Dwi Fatrianto Suyatno

**Data:** 2026-10-10 · **Tipo:** article

## Resumo

Luqman Al Hakim Islamic Boarding School in Surabaya faces inefficiency in recording halaqoh attendance and monitoring students&\#x27; memorization progress due to reliance on manual paper\-based methods and Mutaba&\#x27;ah Yaumiyyah books\. This reliance leads to a high risk of data loss, slow recapitulation, and a lack of real\-time transparency for parents\. This study aims to develop a mobile\-based information system using the Flutter framework to address these issues\. The Extreme Programming \(XP\) method is applied, focusing on iterative system development through planning, designing, coding, and testing phases\. The system utilizes barcode scanning using the Student Identification Number \(NIS\) for accurate attendance tracking\. Furthermore, the application integrates the Hive local database and Firebase Cloud Firestore to provide offline\-first capabilities\. This feature ensures teachers can input data without an internet connection, automatically synchronizing it once the network is available\. Functional testing using the Black Box method demonstrates that all features for the Admin, Halaqoh Teacher, Parent, and Superadmin roles operate at 100% validity\. In conclusion, this application successfully digitalizes boarding school administration, secures data records, and provides transparent memorization monitoring for parents\.
