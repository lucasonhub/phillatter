# KhelSaarthi: An AI\-Based Sports Talent Identification System Using Flutter and Firebase

**Autores:** Nikita Avinash Machale; Anushree Sharad Ashtul

**Data:** 2026-10-14 · **Tipo:** article

## Resumo

The KhelSaarthi mobile app is a sports assessment and training system that uses Artificial Intelligence \(AI\) technologies to enhance the performance of athletes by providing them with smart feedback about their movements\. The proposed model combines technologies such as artificial intelligence, camera\-based motion tracking and Firebase cloud services to assess the performance of the users in different sports activities\. The app allows conducting automated fitness test assessments, recording the performance of the users and providing them with tips for improving their skills\. The app uses the machine learning technology for analyzing the movements and providing performance scores\. The app provides secure authentication and data storing with the help of Firebase integration\. The proposed system is developed using Flutter technology to provide cross\-platform functionality\.
