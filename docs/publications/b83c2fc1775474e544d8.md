# NFMap: Topographic 2D Manifold Learning with Invertible Normalizing Flows

**Autores:** Héléna Alexandra Gaspar

**Data:** 2026-10-12 · **Tipo:** preprint

## Resumo

We present NFMap, a dimensionality reduction method for 2D visualisation that extends Generative Topographic Mapping \(GTM\) with a bijective normalizing flow\. Like GTM, NFMap places a fixed mixture grid prior over a 2D latent map, giving a parametric embedding, an explicit likelihood, and the ability to project new points onto an existing map; the likelihood is an effective out\-of\-distribution signal on chemical datasets\. Unlike GTM, whose latent\-to\-data mapping is an RBF network of bounded flexibility, NFMap&\#x27;s mapping is a normalizing flow, and is therefore fully invertible: any location on the map can be carried back to data space\. To alleviate map crowding on large datasets, NFMap additionally supports heavy\-tailed Student\-t mixture components\. NFMap maps data to a latent space of the same dimension, split into a 2\-dimensional navigable map and an off\-manifold residual\. Because the flow is bijective and its objective penalises volume contraction, variance squeezed out of the residual must reappear in the navigable map\. The residual scale is the main control between local neighbourhood fidelity and global distance fidelity; its effect depends on the dimensionality of the data and is coupled to the extent of the latent grid\.
