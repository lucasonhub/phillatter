# POLVIZX: un prototipo multiplataforma para la construcción y la exploración de árboles de posturas

**Autores:** Tobías Afonso; Gabriela Andrea Diaz; Carlos Iván Chesñevar; Ana Gabriela Maguitman

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Opinion polarization in social media challenges public discourse and informed decision\-making\. POLVIZ, a prior web prototype, analyzed polarized opinions through stance detection, topic modeling, argument synthesis, and visual analytics\. This paper presents POLVIZX, a cross\-platform extension offering both desktop web and mobile applications for exploring polarized opinion spaces on any dataset\. POLVIZX organizes opinions into hierarchical stance trees, grouping arguments by topic and stance \(pro/anti\), to help users navigate debates and identify polarization patterns, with a pipeline supporting partial execution and reuse of intermediate results for iterative analysis\. Each application offers interaction and visualization strategies suited to its platform, while Firebase\-based authentication enables cross\-device synchronization, stance tree sharing, and collaborative exploration\. This extension broadens access to opinion polarization tools and supports emerging e\-deliberation scenarios\.
