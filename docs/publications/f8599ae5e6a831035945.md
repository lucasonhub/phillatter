# Graphlet\-based Decentralized Finance Transaction Method Classification

**Autores:** Célestin Coquidé; Alessio Brini; Natkamon Tovanich

**Data:** 2026-10-16 · **Tipo:** preprint

## Resumo

Decentralized Finance \(DeFi\) transactions involve complex interactions among accounts, smart contracts, and tokens\. We investigate whether network topology can identify transaction methods that describe DeFi operations\. We extract directed graphlet features to classify the 30 most frequent methods\. Our results show that graphlet features complement event log counts in improving classification performance\. Using SHapley Additive exPlanations \(SHAP\), we further derive model explanations that reveal method\-specific graphlet structural patterns\.
