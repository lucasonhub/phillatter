# Machine Learning of Echocardiographic Left Ventricular Myocardial Radiomics for Identification of Transthyretin Amyloid Cardiomyopathy

**Autores:** Ali A Elzieny; Rabah S Alreshq; Ikram Ullah; Denise Fine; Sergio Teruya; STEPHEN HELMKE; CESIA GALLEGOS; Edward J\. Miller; Jeremy A\. Slivnick; Mathew S\. Maurer; Baojun Li; Frederick L\. Ruberg

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

BACKGROUND: Transthyretin amyloid cardiomyopathy \(ATTR\-CM\) is an important cause of heart failure \(HF\) with increased left ventricular \(LV\) wall thickness that can be challenging to distinguish from other LV hypertrophic processes\. Echocardiographic myocardial radiomic texture analysis may identify imperceptible amyloid\-induced structural changes\. OBJECTIVES: The study aims to develop and validate an echocardiography\-based machine learning model using myocardial radiomics to identify ATTR\-CM\. METHODS: In this retrospective and prospective multicenter study, 854 echocardiographic scans were analyzed\. Conventional and novel radiomic features were extracted from parasternal short\-axis views at basal, mid, and apical LV levels, with incorporated age and sex from echocardiogram metadata\. A machine learning pipeline was developed using a balanced training set \(150 ATTR\-CM, 150 nonamyloid HF\)\. Performance was evaluated on an independent internal validation set \(50 ATTR\-CM, 399 nonamyloid HF\) and an external validation set \(10 ATTR\-CM, 10 immunoglobulin light\-chain\-amyloid, 10 hypertrophic cardiomyopathy, 75 nonamyloid HF\)\. RESULTS: In internal validation, the model achieved 86% sensitivity \(95% CI: 73\.8%\-93%\), 92% specificity \(95% CI: 88\.9%\-94\.3%\), 57\.3% positive predictive value \(95% CI: 46\.1%\-67\.9%\), 98\.1% negative predictive value \(NPV\) \(95% CI: 96\.2%\-99\.1%\), and receiver operating characteristic\-area under the curve 0\.938 \(95% CI: 0\.891\-0\.985\)\. Performance was consistent in the external validation \(100% sensitivity, 78\.9% specificity, 33\.3% positive predictive value, 100% NPV, and receiver operating characteristic\-area under the curve of 0\.917\)\. The model correctly classified 77\.3% of nonamyloid HF, 70% of AL\-amyloid cases, and 100% of hypertrophic cardiomyopathy cases as non\-ATTR in subgroup analysis\. CONCLUSIONS: We developed an echocardiographic radiomics\-based tool to identify ATTR\-CM with excellent discrimination and very high NPV in a cohort that approximates clinical experience\. These preliminary findings require validation in larger, more diverse cohorts\.
