# A Comparative Study of Machine Learning Models for Pan\-Cancer Prediction and Explainable Feature Analysis

**Autores:** N Lokesh; L\. Thara; R\. Kumuthaveni

**Data:** 2026-10-11 · **Tipo:** article

## Resumo

Cancer classification based on molecular information is a more complex multiclass learning problem, as tumors from different tissues can present with different expression profiles and cancers with similar molecular characteristics can occur in different tissues\. The Cancer Genome Atlas \(TCGA\) gene\-expression data is used to create a practical pan\-cancer classification framework that is described in this paper\. The working dataset consisted of 11,062 labelled samples representing 33 cancer types, after preparation and labelling\. Representation of the input was reduced to 500 gene\-expression features using a feature\-selection stage\. A single XGBoost multiclass classifier was then trained to understand the relationship between the chosen expression profile and the 33 cancer classes\. The implementation performed with an accuracy of 94\.49%, precision of 94\.66%, recall of 94\.49%, and F1 score of 94\.27% on held\-out test data\. To make the model easier to inspect, a feature\-importance analysis based on SHAP was added\. The trained model was deployed into a Streamlit dashboard, with a FastAPI backend to upload a gene\-expression sample and display the predicted cancer type, probabilities of cancer classes and explanation information\. The system is a research and educational prototype, not a clinically validated diagnostic system; an independent validation should be required before clinical interpretation\.
