# Cyber Threat Detection and Forensics for Ethereum Cryptocurrency Transactions

**Autores:** Bhairab Sarma; Anupam Dutta; Prazna Lahkar; Chayanika Sarmah; Sangita Das

**Data:** 2026-10-18 · **Tipo:** article

## Resumo

Objectives: To detect suspicious fraudulent activities in Ethereum wallet transactions using a graph\-based machine learning and anomaly detection techniques\. Method: From the Ethereum transaction graph, graph structure signals, timing cues, and node level attributes, have been analyzed using unsupervised models like Isolation Forest, Local Outlier Factor, and One\-Class SVM to flag irregular wallet patterns\. Finally, based on the transaction tracing pattern, illicit transactions are figure out for forensics actions\. Findings: This work successfully found some suspicious Ethereum wallet behaviors by mixing graph analytics with unsupervised anomaly detection techniques\. Graph\-based signals such as PageRank, clustering coefficient, transaction frequency and entropy, boosted the capture of strange transaction behaviors that point out as suspicious operation\. Isolation Forest did well at isolating the most extreme outliers, while LOF and One\-Class SVM highlighted wallets with odd local density, plus a clear behavioral mismatch observed\. Overall, the framework worked with the Ethereum transaction dataset from Kaggle, where wallet addresses\. Out of 4000 transaction history, top 20 are figure out as may be fraudulent transaction based on their behaviors\. Novelty: The study integrates graph analytics, blockchain forensics, and unsupervised machine learning to detect anomalous Ethereum wallet behavior without requiring labeled cryptocurrency fraud datasets\. Here, only 0\.5 percent Ethereum transaction are categorized as suspicious on this study\. Keywords: Blockchain Tracing, Cryptocurrency Transactions, Ethereum, Fraud Detection, Graph Neural Network \(GNN\)
