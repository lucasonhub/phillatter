# A Structural and Behavioral Hybrid Framework for Detecting AI\-Generated Code in Programming Education

**Autores:** Arockia Irudayaraja M\.; Rexton George R\.; Nishanth K\.; Sakthivel P\.

**Data:** 2026-10-17 · **Tipo:** article

## Resumo

The Large Language Models \(LLMs\) for generating source code creates a need for code\-aware detection mechanisms capable of analyzing characteristics beyond token\-level statistics\. This research proposes CodeGuardX, a hybrid framework of structure and behavior, which combines Abstract Syntax Tree inspection, runtime sandboxing, and lexical stylometry in the detection of AI\-generated codes\. A vector of 33 dimensions containing 17 structural, 6 behavioral, and 10 stylometric features is used for classification using XGBoost with probability calibration and threshold optimization based on F1 metric\. Evaluation of the model is performed using 6,800 code samples from the domains of Python, Java, C, and C\+\+; a test set of 1,200 code samples is used for testing purposes\. CodeGuardX achieves an accuracy score of 93\.8% and F1 score of 92\.9%\. Ablation study demonstrates increasing F1 scores of 77\.8%, 87\.3%, and 92\.9%\. The combination of source code obfuscation, the framework retains 89\.4% F1\-score, demonstrating the robustness to lexical transformations\.
