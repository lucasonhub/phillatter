# Sistem Kendali Presisi DO dan CO2 pada Smart Greenhouse Berbasis ESP32

**Autores:** Arif Rahmadhani; Dodi Yudo Setyawan; Nurfiana Nurfiana; Refi Arioen

**Data:** 2026-10-17 · **Tipo:** article

## Resumo

Pengelolaan iklim mikro greenhouse secara konvensional sering mengalami kendala keterlambatan respons dan ketidakstabilan kondisi lingkungan\. Penelitian ini bertujuan untuk mengevaluasi alur telemetri dan logika kendali ambang batas bertingkat \(cascading threshold logic\) pada sistem Agro Ino Farm berbasis arsitektur server\-centric thin\-edge \(dual\-node ESP32 dan ESP8266\) yang terintegrasi secara real\-time dengan platform Web Dashboard\. Metodologi penelitian dievaluasi menggunakan skenario simulasi dataset iklim mikro harian \(24 jam\) yang mencakup parameter suhu udara, kelembapan, intensitas cahaya, dan kadar CO2\. Eksekusi logika kendali diuji pada tiga mode operasional: manual berfitur timer, otomatis berbasis ambang batas sensor, dan penjadwalan\. Hasil simulasi menunjukkan bahwa transmisi data melalui protokol REST API \(HTTP POST\) berjalan secara konsisten dan server mampu mengeksekusi perintah biner relay secara stabil\. Penerapan algoritma debounce serta batas minimum waktu tahan relay \(minimum hold time\) terbukti efektif mencegah terjadinya osilasi switching pada relay akibat fluktuasi data sensor skala kecil\. Arsitektur terpisah \(decoupling\) ini berhasil menghasilkan cetak biru \(blueprint\) IoT benchtop hardware prototype yang solid untuk tahap implementasi perangkat keras fisik skala greenhouse riil selanjutnya\.
