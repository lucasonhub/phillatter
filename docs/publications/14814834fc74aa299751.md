# PopGen: Generating Semantically Diverse Populations for Zero\-Shot Coordination

**Autores:** Paul Teiletche; Kanghyun Ryu; Kyungjoon Park; Dhruva Tirumala; Markus Wulfmeier; Negar Mehr

**Data:** 2026-10-11 · **Tipo:** preprint

## Resumo

In multi\-agent reinforcement learning, exposing a cooperator to partners with diverse strategies during training is key to better collaboration at test time\. However, existing methods typically rely on trajectory\-level proxies to measure diversity, which may label two distinct trajectories of the same strategy as diverse\. Instead, our key insight is to leverage LLMs&\#x27; ability to describe behaviorally distinct agents in environments, similar to how humans can recognize high\-level strategies\. To this end, we introduce PopGen, a framework that synthesizes semantically diverse agents from scratch using LLMs\. PopGen first generates a diverse set of textual descriptions of agent behaviors, then translates each behavior into a code policy that can be executed within the environment\. We show that cooperators trained against PopGen populations achieve robust zero\-shot cooperation with unseen partners, outperforming population\-play baselines across four collaborative environments\. We further show that semantic diversity scales with PopGen population size, improving the cooperator&\#x27;s worst\-case performance, and we identify design choices that preserve population quality while maximizing diversity\. Our code is available at https://github\.com/labicon/PopGen\.
