# Grid or Nodes? Probing Object Memory in World Models Under Partial Observability

**Autores:** Justin McMillen; Yasin Yilmaz

**Data:** 2026-10-13 · **Tipo:** preprint

## Resumo

A robot&\#x27;s world model must remember objects that leave the camera&\#x27;s view\. FloWM, a learned world model, keeps them in a spatial grid of features that it moves with five built\-in velocities\. A node memory instead keeps each object&\#x27;s position and velocity as numbers\. We compare them in FloWM&\#x27;s own block world, with an oracle\-fed Kalman tracker as the node memory\. How the grid is read changes its score: a single\-cell probe finds 66% of out\-of\-view blocks, while FloWM&\#x27;s own probe 89%\. FloWM also scores 8 points higher in view although no frame is shown, which we attribute to its write\-back of its own predictions\. Out of view, the tracker reaches FloWM&\#x27;s range in 14KB against 5\.6MB, with no probe\. On diagonal motion, outside its five velocities, FloWM finds 11% of blocks even after fine\-tuning, while the unchanged tracker keeps 93%\. Faster blocks defeat both until one more allowed speed takes the tracker to 94%, where FloWM&\#x27;s built\-in shifts would need 25 copies of its grid\. A learned node memory must still replace the oracles and handle velocity under noise, long gaps, and the bounce\.
