# Electromagnetic Optimization of Electric Machines Using Machine Learning Metamodeling

**Autores:** Nuo Chen

**Data:** 2026-10-13 · **Tipo:** book

## Resumo

In der Phase der Designoptimierung von elektrischen Maschinen wird datengetriebenes Metamodellieren weit verbreitet eingesetzt, um wichtige Leistungsindikatoren \(KPIs\) wie Leistung, Drehmoment und Drehmomentwelligkeit vorherzusagen\. Es kann rechenintensive Simulationen durch die Erstellung von Metamodellen mit geringeren Rechenkosten ersetzen\. Dennoch stehen datengetriebene Methoden vor Herausforderungen, darunter hohe Komplexität bei großer Eingabedimension, zeitaufwändige Datensammlung und reduzierte Vorhersagezuverlässigkeit bei begrenzten Daten\. In dieser Dissertation werden erstmals mehrere auf maschinellem Lernen basierende Ansätze und Optimierungsstrategien vorgeschlagen, um die aktuellen Hindernisse zu überwinden\. Zunächst wird ein deterministisches neuronales Netzwerk auf Basis von Transferlernen vorgeschlagen, um das Problem der Reparametrisierung zu lösen, das bei der parametrischen Modelltraining auftritt\. Dieser Ansatz umgeht die Erfordernis, das Modell von Grund auf neu zu trainieren, und erzielt simultan eine gesteigerte Vorhersagegenauigkeit, indem die vortrainierten Gewichte aus dem ursprünglichen Netzwerk dynamisch übertragen werden\. Zweitens wird eine neuartige, auf Unsicherheitsquantifizierung basierende Optimierungsmethode unter Verwendung probabilistischer Metamodellierung vorgestellt\. Diese Methode ermöglicht es den Anwendern, optimale Design\-KPIs präzise vorherzusagen, indem sie zusätzliche Unsicherheitsinformationen berücksichtigt\. Darüber hinaus bildet sie die Grundlage für die probabilistische Vorhersage von KPIs mittels Metamodellierung und die unsicherheitsbasierte Optimierung im Bereich elektrischer Maschinen\. Zur Lösung des Problems des zeitaufwändigen Samplings werden in dieser Dissertation zwei neuartige, auf Unsicherheit basierende, dateneffiziente Lernansätze präsentiert\. Zunächst wird ein Rahmenwerk für das Selbsttraining vorgestellt, das die kontinuierliche Generierung von Daten mit Pseudobeschriftungen ermöglicht, um den Datensatz zu erweitern und somit das Modelltraining zu optimieren\. Im Anschluss werden verschiedene Optimierungsstrategien auf Basis des aktiven Lernens entwickelt\. Diese Strategien können unter Bedingungen mit kleinen Daten iterativ wichtige Daten zum ursprünglichen Datensatz hinzufügen und dadurch die Vorhersageleistung des Modells steigern\.
