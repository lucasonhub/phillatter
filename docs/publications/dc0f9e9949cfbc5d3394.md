# MPE\-YOLO11:Underwater Object Detection Algorithm Based on Improved YOLO11n

**Autores:** Linpu Li; Xiuxiu Liu; Chunhong Kong; Junqi Cheng

**Data:** 2026-10-09 · **Tipo:** article

## Resumo

Abstract Underwater images commonly suffer from low contrast, large object scale variations, and background interference\. These factors can lead to insufficient object feature representation, inadequate utilization of shallow details, and interference from background noise\. To address these problems, we propose an underwater object detection algorithm named MPE\-YOLO11 based on YOLO11n\. Firstly, we design a multi\-scale adaptive feature enhancement \(MAFE\) module to construct the novel C3k2\_MAFE module\. This module augments the algorithm&\#x27;s feature representation capability for multi\-scale objects\. Secondly, we improve the structure of the P2 detection head to enhance the algorithm&\#x27;s performance in small object detection\. Meanwhile, this structural improvement reduces the computational overhead introduced by the extra detection head\. Finally, we design the improved convolutional block attention module \(ICBAM\) and integrate it into the neck network\. It enhances object\-related feature representation and suppresses complex background interferences\. On the URPC2020 dataset, MPE\-YOLO11 outperforms the original YOLO11n by 2\.3%, 2\.6%, 1\.6%, and 1\.6% in terms of precision, recall, mAP@0\.5, and mAP@0\.5:0\.95, respectively\. Meanwhile, the number of parameters of MPE\-YOLO11 increases by only 0\.1M\. Furthermore, to further evaluate the performance of the proposed algorithm, we conduct experiments on the DUO, UTDAC2020, and RUOD datasets, which differ in category composition, object\-scale distribution, and image degradation characteristics\. On these datasets, MPE\-YOLO11 improves mAP@0\.5 and mAP@0\.5:0\.95 by approximately 0\.7% and 0\.8% on average compared with YOLO11n, respectively\. The experimental results show that MPE\-YOLO11 achieves consistent performance gains across diverse object categories and underwater scenes, demonstrating good detection performance and adaptability\.
