# Learning to Select Features with Manifold Deep Unfolding PCA

**Autores:** Jingjing Liu; Pei Tai; Xianchao Xiu; Wanquan Liu

**Data:** 2026-10-14 · **Tipo:** preprint

## Resumo

Unsupervised feature selection \(UFS\) is of great significance in image processing and pattern recognition\. Nevertheless, existing model\-based methods often rely on manually tuned hyperparameters, while deep learning\-based methods generally require massive training data\. To address these issues, this paper proposes an efficient manifold deep unfolding feature selection network \(MDUFS\-Net\)\. Technically, we first incorporate the $\\ell\_\{2,0\}$\-norm into the classic principal component analysis \(PCA\) framework, then unfold the alternating direction method of multipliers \(ADMM\)\-based iterative algorithm into an end\-to\-end trainable network, thereby enabling automatic parameter learning\. Moreover, a manifold optimization strategy is developed to improve the numerical robustness\. On this basis, we further extend MDUFS\-Net into an enhanced variant called MDUFS\-Net\+ by introducing the $\\ell\_\{0\}$\-norm for more discriminative feature representations\. Extensive experiments validate that our proposed MDUFS\-Net and MDUFS\-Net\+ outperform state\-of\-the\-art methods in the UFS task, with promising performance in clustering\. Our code is available at https://github\.com/xianchaoxiu/MDUFS\.
