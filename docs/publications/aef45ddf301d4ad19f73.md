# Hallucination Detection Middleware using RAG Based Model

**Autores:** Lakshmanan A; S Nithyanandh; Mohanapriya D

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

Retrieval\-augmented generation \(RAG\) gives a language model access to external evidence, but retrieval alone does not ensure that a generated answer is supported by that evidence\. This paper presents VeriRAG, a middleware\-oriented design that separates query screening and evidence retrieval from answer verification\. According to the supplied project documentation, the first stage handles conversational or unsuitable requests and retrieves records through a TF–IDF index with unigram–bigram features, cosine similarity, content\-word overlap, and a small set of attribute\-specific rules\. The second stage compares retrieved evidence with a candidate answer and returns a binary support decision, confidence, explanation, and interface status\. The documented knowledge base contains 10,000 evidence–question–answer triplets, reported as equally divided between sUPPoRTED and HALLUcInATED labels\. The system is exposed through FastAPI middleware and a Streamlit interface designed around progressive disclosure: an answer is shown first and supporting evidence and verification details are revealed on demand\. The principal contribution is an inspectable division of responsibility between scope control, retrieval, and evidence\-grounded classification rather than a claim that retrieval eliminates hallucination\. Because the source archive, dataset, serialized estimators, Transformer checkpoint, and executable tests were not supplied, model priority, training history, dataset provenance, predictive accuracy, and latency could not be independently audited\. Consequently, this study reports the documented architecture and a reproducible evaluation plan while treating artifact\-level figures as project\-reported values rather than experimental findings\.
