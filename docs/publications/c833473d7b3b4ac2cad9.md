# PREDIKSI KEBUTUHAN OBAT PADA INSTALASI FARMASI RUMAH SAKIT MENGGUNAKAN METODE RANDOM FOREST BERBASIS DATA HISTORIS TRANSAKSI OBAT

**Autores:** Ahmad Junaidi; Yeviki Maisyah Putra

**Data:** 2026-10-17 · **Tipo:** article

## Resumo

Abstract: Effective drug inventory management in hospital pharmacies requires accurate demand planning to minimize the risks of drug shortages and excess inventory\. Historical drug transaction data stored in a Hospital Information System \(SIMRS\) can be utilized as a basis for predicting drug requirements for subsequent periods\. This study aims to develop a drug demand prediction model using the Random Forest Regression method based on historical drug transaction data from a hospital pharmacy\. The dataset consists of drug transaction records from August 2024 to December 2025 obtained from the hospital information system\. The data were processed through preprocessing stages, including data cleaning, missing\-value checking, duplicate detection, transaction validation, and monthly aggregation of drug usage\. Subsequently, feature engineering was performed by generating historical usage features in the form of lag variables and moving averages as model inputs\. The dataset was divided chronologically into training and testing sets to prevent data leakage\. The Random Forest Regression model was employed to predict drug requirements for the subsequent period and evaluated using Mean Absolute Error \(MAE\), Root Mean Square Error \(RMSE\), and Weighted Absolute Percentage Error \(WAPE\)\. The results indicate that a historical transaction\-based approach can be used to estimate drug requirements and provide supporting information for inventory planning in hospital pharmacies\.
