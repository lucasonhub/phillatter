# Development of a Framework Model Using Pattern Matching Approach to Detect and Prevent SQL Injection Attacks

**Autores:** Khalid Mohammed Osman Saeed; Mohamed Musa Ali Eisa; Tagwa Ismail Khalifa; Alshafie Gafaar Mahmoud Mohammed

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

This article developed a framework model to deal with statements and SQL queries which is compared with a dataset based on pattern matching to prevent and detect whether they are containing SQL injections or not\. The proposed developed framework model exists in between the application interface and the database to verify the statements and which of them is permitted to pass or not; it works by checking the entering statement for any suspicious contents before the statement pass to the database for execution\. The proposed framework model is tested, and the findings indicate that on the false reject rate scale of a 99% of accuracy rate and on the false accept rate of a 98% of accuracy are achieved and the attacker’s data is recorded too which can be used for trigger update the dataset\. Keywords: SQL Injection, Security Vulnerabilities, Security Attacks, SQL Statement
