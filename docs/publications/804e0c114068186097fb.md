# Integrating Unplugged Coding into Experiential Learning: Its Impact on Elementary Students&\#x27; Mathematical Conceptual Understanding

**Autores:** Nurul Hasna Haifa; Hafiziani Eka Putri; Alfiana Nurussama; Teten Ginanjar Rahayu

**Data:** 2026-10-12 · **Tipo:** article

## Resumo

The integration of coding into Indonesia&\#x27;s elementary curriculum is often constrained by limited technological infrastructure, while students&\#x27; understanding of number\-related concepts remains low\. This study examined the effectiveness of an experiential learning model based on unplugged coding in improving elementary students&\#x27; conceptual understanding of numbers\. Using a quantitative quasi\-experimental approach with a Nonequivalent Control Group Design, 48 third\-grade students from Purwakarta Regency \(2025/2026 academic year\) were purposively selected and divided into an experimental group \(24 students\), taught with the unplugged\-coding\-based experiential model, and a control group \(24 students\), taught using Problem\-Based Learning\. Conceptual understanding was measured through a descriptive test covering four indicators, with data analyzed via normality, homogeneity, and independent\-sample t\-tests, and N\-Gain calculations using SPSS\. Results showed a statistically significant difference between groups \(p = 0\.005\), with the experimental group scoring higher than the control group\. The N\-Gain analysis revealed an average improvement of 60\.34% \(moderately effective\) in the experimental group versus 42\.83% \(least effective\) in the control group\. These findings confirm that the unplugged\-coding\-based experiential learning model effectively enhances students&\#x27; understanding of number concepts, offering a practical, technology\-independent strategy for resource\-limited educational settings\.
