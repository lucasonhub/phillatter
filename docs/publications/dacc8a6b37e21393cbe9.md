# Multimodal Deepfake Detection using Meso4 CNN for Spatial Image Analysis and LRCN for Temporal Video Analysis

**Autores:** Mahalakshmi K\.; Lavanya A\.; Kiruthika R\.; Kannamma R\.

**Data:** 2026-10-13 · **Tipo:** article

## Resumo

Generative artificial intelligence technology has resulted in the creation of deepfakes, highly realistic forged images and videos, posing major automated media authentication challenges\. This research proposes a multimodal approach for deepfake recognition based on Meso4 CNN and Long Short\-Term Convolutional Recurrent Network \(LRCN\)\. The proposed approach includes input validation, resizing, normalization, and data augmentation followed by feature extraction and real\-fake classification for each modality\. While Meso4 CNN is responsible for extracting mesoscopic facial features from images, LRCN analyzes the temporal inconsistencies in a sequence of video frames\. The proposed system was tested on the FaceForensics\+\+ dataset and analysed the performance metrics such as accuracy, precision, and recall\. The proposed system has resulted in 94\.1% accuracy, 93\.5% precision, and 94\.6% recall\.
