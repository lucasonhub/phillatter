# A GB\-SAR slope displacement interval prediction method based on FA\-VAG feature transfer and an improved sparrow search algorithm

**Autores:** Y\. Dai; ZiWei Zhao; XiaoDong Gan; Songlin Liao

**Data:** 2026-10-15 · **Tipo:** article

## Resumo

Slope displacement interval prediction quantifies uncertainty in future deformation and supports slope monitoring and early warning\. This study extends the point\-prediction FA\-VAG backbone previously reported by Gan et al\. rather than presenting that backbone as a new model\. The new contribution is an interval\-prediction layer that transfers the pretrained FA\-VAG hidden states, reduces them by Principal Component Analysis \(PCA\), fuses them with multi\-step point forecasts, and maps the fused representation to non\-crossing bounds using a Random Vector Functional Link Network \(RVFLN\)\. A prior\-informed improved Sparrow Search Algorithm \(SG\-ISSA\) then optimizes the RVFLN output weights\. For the prespecified target point 7, the framework achieved PICP/MPIW/CWC values of 0\.90/5\.97/5\.97 for five\-step prediction and 1\.00/8\.74/8\.74 for seven\-step prediction\. Independent external validation yielded 0\.90/58\.82/58\.82 for five\-step prediction\. These results support the interval\-extension framework on the two evaluated datasets; additional probabilistic baselines and harmonized reruns of the ablation study remain necessary\.
