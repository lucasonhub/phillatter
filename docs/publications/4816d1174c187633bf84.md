# On the Monitorability of Natural Language Autoencoders: Identification vs Discrimination

**Autores:** Kevin Yandoka Denamganaï

**Data:** 2026-10-13 · **Tipo:** preprint

## Resumo

Natural Language Autoencoders \(NLAs\) are proposed as oversight tools for language models: an Activation Verbaliser \(AV\) writes an English explanation of an activation vector, and an Activation Reconstructor \(AR\) maps the explanation back to a vector\. Their value for oversight depends on a human monitor being able to tell a true account of an activation from a false one, given the Av&\#x27;s explanation\. We formalise NLA training and NLA oversight deployment as two different referential games from Emergent Communication: training is a generative referential game, while oversight is a discriminative, multi\-modal, partially\-observable referential game played over a many\-to\-many relation between the monitored language model&\#x27;s activations and the accounts that are true of them\. The gap between the two games predicts that AV&\#x27;s explanations will identify which activation they describe without discriminating its true account from closely matched false ones, since training never asks explanations to rule anything out\. Using the NLA&\#x27;s own AR as a maximally\-sympathetic surrogate monitor model, we experimentally confirm this theoretical insight on one released checkpoint: true accounts beat accounts of other activations in all 320 comparisons, but beat fluent rivals differing in a single claim only 60\.2% of the time \(std\.err\. 6\.7%, chance at 50%, $n = 35$\)\. A meaning\-preserving rewrite by an uninvolved model costs only 2\.1% of the distance to another activation&\#x27;s account, so the failure is not due to the NLA pair having developed private conventions in the AV&\#x27;s explanations\. Our rival accounts test only transcript\-level truths, which the monitored language model&\#x27;s conversation settles, so these results bound the easiest case and leave claims about the monitored model&\#x27;s own processing untested\. We state conjectures that would make both results consequences of the framework\.
