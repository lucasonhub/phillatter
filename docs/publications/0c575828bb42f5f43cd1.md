# GRU\-KAN: A Hybrid Recurrent–Kolmogorov–Arnold Network for Low\-latency 3D Hand Gesture Classification Using Direct Kinematic Features from Skeletal Data

**Autores:** Israa F\. Fatih; Wisam S\. Hacham; Muhannad K\. Sabir

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

The conventional hand\-gesture recognition method is based on complicated signal processing, such as Kalman filtering and Fast Fourier Transform \(FFT\), and the Electromyography \(EMG\) / Inertial Measurement Unit \(IMU\) based method has the disadvantages of handcrafting and latency\.In this paper, a vision\-based framework is proposed that operates directly on raw 3D skeletal streams, avoiding the classic pre\-processing steps, and allows the extraction of 14 kinematic descriptors in a lightweight manner\.To achieve gesture recognition, a hybrid Gated Recurrent Unit\-Kolmogorov\-Arnold Network \(GRU\-KAN\) architecture is proposed in which the temporal model is built using a Gated Recurrent Unit and the non\-linear classification model is a Kolmogorov\-Arnold Network, whose learnable B\-spline activations do not cause vanishing gradients when using skip connections\.The model achieves a test accuracy of 90\.0% on a held\-out test set of 70 sequences \(10 per gesture\), drawn from a total dataset of 350 sequences across seven gestures\.The latency\-optimized CPU configuration achieves this accuracy with an inference latency of 57\.06 ms per pre\-segmented sequence, suitable for edge deployment\.The proposed GRU\-KAN outperforms a controlled GRU\-MLP baseline \(85\.71%\) by \+4\.29 percentage points under identical encoder and training conditions\.On the FPHA public benchmark \(45 classes, 1,175 sequences, variable\-length\), GRU\-KAN achieves 66\.81% versus 64\.68% for the matched GRU\-MLP baseline, confirming the KAN classifier&\#x27;s consistent advantage under an identical recurrent encoder and training protocol\.The results demonstrate that GRU\-KAN exhibits better convergence stability and classification accuracy than a matched GRU\-MLP baseline under identical encoder and training protocols\.
