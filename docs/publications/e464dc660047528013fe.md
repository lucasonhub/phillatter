# Reconstruction of daily snow depth at 0\.25° resolution over the arid regions of Central Asia from 1980 to 2023 using machine learning

**Autores:** Liancheng Zhang; Guli Jiapaer; Tao Yu; Jie Bai; Xiapeng Jiang; Hongwu Liang; Pingping Feng; Tongwei Ju; Philippe De Maeyer; Tim Van de Voorde

**Data:** 2026-10-16 · **Tipo:** article

## Resumo

Arid regions of Central Asia \(CA\) depend heavily on snowmelt, but limited monitoring stations and unreliable snow depth \(SD\) data hinder effective snow monitoring\. In this study, we applied XGBoost \(XGB\) and random forest \(RF\) machine learning models to integrate multiple SD products with covariates—including geospatial, snow\-related, meteorological, land cover, and time data—along with in situ SD measurements, to enhance SD monitoring in CA\. Two modeling approaches were tested: segmented modeling based on snow development stages and whole\-period modeling for the entire snow season\. The results showed that segmented fusion modeling outperformed whole\-period modeling, with XGB\-based models capturing SD variations more effectively than RF\-based models and existing SD products\. Notably, the XGB\-based fusion models markedly improved the SD estimates for complex high\-elevation terrain\. Model performance analysis revealed that accuracy increased with the increasing number of integrated SD products\. Moreover, the models incorporating ERA5\-Land outperformed those that used the other datasets\. While all covariate types enhanced the model performance, geospatial features made the most significant contributions\. Ultimately, using the XGB\-segmented fusion model, we developed a 0\.25° daily SD dataset for CA spanning 1980–2023, providing a reliable resource for snow monitoring in the region\.
