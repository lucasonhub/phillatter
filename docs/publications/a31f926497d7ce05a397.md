# Against Structuralist Theories of Computational Implementation

**Autores:** Michael Rescorla

**Data:** 2012-10-03 · **Tipo:** article

## Resumo

Under what conditions does a physical system implement or realize a computation? Structuralism about computational implementation, espoused by Chalmers and others, holds that a physical system realizes a computation just in case the system instantiates a pattern of causal organization isomorphic to the computation’s formal structure\. I argue against structuralism through counter\-examples drawn from computer science\. On my opposing view, computational implementation sometimes requires instantiating semantic properties that outstrip any relevant pattern of causal organization\.
