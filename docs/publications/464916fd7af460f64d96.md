# Efficient Resource\-Shiftable RL Post\-training with Generative Rewards

**Autores:** Yanfeng Zhao; Haoyang Li; Sheng Lin; Yuming Zhou; Jiawei Jiang; Bin Cui; Fangcheng Fu

**Data:** 2026-10-12 · **Tipo:** preprint

## Resumo

Reinforcement learning \(RL\) post\-training with generative reward models \(GenRM\) has become a central recipe for improving large language models \(LLMs\), and it is also increasingly resource\-intensive: policy rollout, GenRM\-based reward evaluation, and policy training all compete for GPU resources\. However, existing colocated and disaggregated systems rely on static resource allocation for these roles\. Such allocation cannot adapt as each role&\#x27;s workload changes during RL and therefore leaves a role&\#x27;s resources underutilized\. We present PivotRL, an RL post\-training system that dynamically shifts resources among different roles according to their runtime demands\. PivotRL introduces a resource\-shiftable runtime built on a Global Parameter Storage, together with a unified mechanism that efficiently shifts role\-specific context\. A shift\-aware scheduler enables sequence migration upon a shift, while a planner considers the aggregate throughput benefit and the shift overhead to determine when and how to shift\. We evaluate PivotRL on a 128\-GPU cluster using four model groups spanning dense and mixture\-of\-experts models\. PivotRL enables resource shifting within seconds and improves end\-to\-end throughput by 1\.81\-2\.05 times over colocated deployment and 1\.50\-1\.95 times over disaggregated deployment, while preserving RL convergence\.
